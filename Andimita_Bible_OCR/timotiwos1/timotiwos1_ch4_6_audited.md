| **ክፍል** | **ክፍል ፬ ፡ በእንተ ነባብያነ ሐሰት ።** | **ክፍል ፬ ፡ ሐሰትን ስለሚናገሩ ።** |
| ፩ | ወመንፈስ ገሀደ ይነግር ከመ በደኃሪ መዋዕል የዐልዉ ሃይማኖቶሙ ብዙኃን ፤ ወይተልውዎሙ ለአጋንንት እኩያን ወመስሕታን ወትምህርተ ሰይጣን ዘያናፍቅ ። | በኋላ ዘመን ብዙ ሰዎች የሚያስቱትን ክፉዎች አጋንንት የሚያጠራጥረውንም የሰይጣን ትምህርት ተከትለው ሃይማኖታቸውን እንደሚለውጡ ፤ መንፈስ ቅዱስ በግልጽ ይናገራል ። |
| ፪ | ነባብያነ ሐሰት ፤ እለ ንዱዳን በሕሊናሆሙ ። | ሐሰትን የሚናገሩ ፤ በሐሳባቸው የሚቃጠሉ ። |
| ፫ | እለ የሐርሙ አውስቦ ፤ ወይከልኡ መባልዕተ ዘእግዚአብሔር ፈጠረ ለምእመናን ከመ ይሴሰዩ ወያእኵቱ እለ የአምርዋ ለጽድቅ ። | ጋብቻን እርም ነው የሚሉ ጽድቅን የሚያውቋት በልተው ያመሰግኑት ዘንድ እግዚአብሔር ለምእመናን የፈጠረውን ምግብ የሚከለክሉ ። |
| ፬ | እስመ ኵሉ ተግባረ እግዚአብሔር ሠናይ ወአልቦ ግዱፍ ወኢምንትኒ ለእመ ተወክፍዎ እንዘ የአኵቱ ። | እግዚአብሔር የፈጠረው ፍጥረት ሁሉ መልካም ነውና እያመሰገኑ ቢመገቡት ምንም የሚጣል የለበትምና ። |
| ፭ | እስመ ይትቄደስ በቃለ እግዚአብሔር ወበጸሎት ። | በእግዚአብሔር ቃልና በጸሎት ይከብራልና ። |
| ፮ | ወዘንተ መሀሮሙ ለአኀዊከ ወትከውን ኅሩየ ላእከ ኢየሱስ ክርስቶስ ፤ እንዘ ትሴስዮሙ ቃለ ሃይማኖት ወሠናየ ትምህርተ ዘተምהרከ ። | ለወንድሞችህ ይህን አስተምራቸው ፤ የተማርከውን በጎ ትምህርትና የሃይማኖትን ነገር ብታስተምራቸው የኢየሱስ ክርስቶስ ምርጥ አገልጋይ ትሆናለህ ። |
| ፯ | ለመኃድምተ ዕቤራትሰ ርኩስ እበዮ ፤ ወአግርር ርእሰከ ለጽድቅ ። | የረከሰውን የባልቴት ተረት ግን ተወው ፤ ራስህን ለጽድቅ አስገዛ ። |
| ፰ | እስመ ግረትሰ በሥጋ ለኅዳጥ ዘመን ትበቍዕ ወጽድቅሰ ታሠልጥ በኵሉ ፤ ወባቲ ተስፋ ሕይወት በዝንቱ ዓለም ወበዘይመጽእ ። | በሥጋ መገዛት ለጥቂት ዘመን ትጠቅማለች ፤ ጽድቅ ግን በሁሉም ግዳጅ ትፈጽማለች ፤ በዚህም ዓለም በሚመጣውም የሕይወት ተስፋ አላት ። |
| ፱ | እሙን ነገሩ ወርቱዕ ይትወከፍዎ በኵሉ ። | እውነት ነው በሁሉም ሊቀበሉት ይገባል ። |
| ፲ | እስመ በእንተዝ ንሠርሕ ወንትከየል እስመ ተወከልነ በእግዚአብሔር ሕያው ወማሕየዊ ለኵሉ ሰብእ ወፈድፋደሰ ለመሃይምናን ። | ስለዚህ ለሰው ሁሉ ይልቁንም ለምእመናን አዳኝና ሕያው በሆነው በእግዚአብሔር ስም እንደክማለን እንሰደባለን ። |
| ፲፩ | ከመዝ መሀር ወገሥፅ ። | እንዲህ ምከር አስተምር ። |
| ፲፪ | ወአልቦ ዘያስተዐብዳ ለውርዙትከ ወኩኖሙ አርአያ ወአምሳለ ለመሃይምናን በቃልክ ወበምግባርከ በፍቅር ወበሃይማኖት ወበንጽሕ ። | ወጣትነትህን የሚያቃልላት አይኑር ፤ በፍቅር በሃይማኖት በንጽሕና ፀንተህ በቃልህም በሥራህም ለምእመናን ምሳሌ አብነት ሁናቸው ። |
| ፲፫ | ወተዐቀብ እስከ እመጽእ በአንብቦ ወበምሂር ወበገሥፆ ወበጸልዮ ። | እስክመጣ ድረስ በማንበብ በማስተማር በመምከር በመጸለይ ፀንተህ ኑር ። |
| ፲፬ | ወኢታስትት ጸጋሁ ዘላዕሌከ ዘተውህበከ ምስለ ተነብዮ ወምስለ ሢመተ እደዊሆሙ ለጳጳሳት ። | ትንቢት ከመናገርና በጳጳሳት እጅ ከተሾምከው ሹመት ጋር የተሰጠህን ባንተ ላይ ያደረገውን የእግዚአብሔርን ጸጋ አታቃልል ። |
| ፲፭ | ዘንተ አንብብ ወበዝ ሀሉ ከመ ይትዐወቅ ፍጻሜከ በኵሉ ። | ፍጹምነትህ በሁሉ ይታወቅ ዘንድ ይህን አንብብ ፤ በዚህም ጸንተህ ኑር ። |
| ፲፮ | ዑቅ እንከ ርእሰከ በእንተ አንብቦ ወዘልፈ ሀሉ ባቲ ፤ ወእመሰ ዘንተ ገበርከ ርእሰከሂ ታድኅን ወዘሂ ይሰምዐከ ። | ከእንግዲህ መጽሐፍን ስለ ማንበብ ራስህን ዕወቅ ፤ ዘወትር በዚያው ፀንተህ ኑር ፤ ይህን ብታደርግ ራስህንም የሚሰማህንም ታድናለህ ። |

| **ክፍል** | **ክፍል ፭ ፡ በእንተ አክብሮ ልሂቃን ።** | **ክፍል ፭ ፡ ሽማግሌዎችን ስለ ማክበር ።** |
| ፩ | ሊቃናተ ኢታመይዕ ተአዘዝ ከመ ዘለአቡከ ፤ ወለንኡሳን ከመ ዘለአኀዊከ ። | ሽማግሌዎችን አታዋርድ ፤ ለአባትህ እንደምትታዘዝ ታዘዝ እንጂ ፤ ለታናናሾችም ለወንድሞችህ እንደምትታዘዝ ታዘዝ ። |
| ፪ | ወለልሂቃትሂ ከመ ዘለእምከ ወለንኡሳትሂ ከመ ዘለአኀቲከ በኵሉ ንጽሕ ። | ለባልቴቶችም ለእናትህ እንደምትታዘዝ ታዘዝ ፤ ለታናናሾችም ለእህቶችህ እንደምትታዘዝ በፍጹም ንጽሕና ሆነህ ታዘዝ ። |
| ፫ | ወአክብር ዕቤራተ በጽድቅ ። | ባልቴቶችን በእውነት አክብር ። |
| ፬ | ወእመቦ እምኔሆሙ ዕቤር እንተ ባቲ ውሉድ አው ደቂቀ ውሉድ ይትመሀሩ ቅድመ አሠንዮ ለቤቶሙ ፤ ወይሴስዩ አዝማዲሆሙ እስመ ከማሁ ሠናይ ወሥሙር በቅድመ እግዚአብሔር ። | ከእነሱ ወገን ልጅ ወይም የልጅ ልጅ ያላት ባልቴት ብትኖር አስቀድሞ ለቤታቸው በጎ ማድረግን ይማሩ ዘመዶቻቸውንም ይርዱ ፤ እንዲህ ያለው በእግዚአብሔር ፊት ያማረና የተወደደ ነውና ። |
| ፭ | ወእንተሰ ዕቤር በአማን ንጽሕት እንተ ባሕቲታ ትነብር እስመ ትውክልታ እግዚአብሔር ባሕቲቱ ትትመድ ጸሎተ ወትስእል መዓልተ ወሌሊተ ። | ብቻዋን የምትኖር በእውነት ንጽሕት የሆነች ባልቴት ግን ተስፋዋ እግዚአብሔር ብቻ ነውና ለጸሎት ጽምድት ትሆናለች ፤ በመዓልትም በሌሊትም ትለምናለች ። |
