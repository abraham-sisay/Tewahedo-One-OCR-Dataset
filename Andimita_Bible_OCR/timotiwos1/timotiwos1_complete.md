## ምዕራፍ ፩

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፩ ፡ ዘከመ ኢይደሉ ዛውዐ ነገር ።** | **ክፍል ፩ ፡ ዋዛ ፈዛዛ መናገር ስለማይገባ ።** |
| **፩** | እምጳውሎስ ሐዋርያሁ ለእግዚእነ ኢየሱስ ክርስቶስ በትእዛዘ እግዚአብሔር መድኃኒነ ወኢየሱስ ክርስቶስ ተስፋነ ። | መድኃኒታችን በሆነው በእግዚአብሔር አለኝታችን በሆነው በኢየሱስ ክርስቶስ ትእዛዝ የጌታችን የኢየሱስ ክርስቶስ ሐዋርያ ከምሆን ከእኔ ከጳውሎስ የተላከ መልእክት ። |
| **፪** | ለጢሞቴዎስ ወልድየ ዘአፈቅር በሃይማኖት ፤ ሰላም ለከ ወሣህል ወጸጋሁ ለእግዚአብሔር አቡነ ወእግዚእነ ኢየሱስ ክርስቶስ ። | በሃይማኖት ለምወደው ልጄ ለጢሞቴዎስ ትድረስ ፤ ሰላም ላንተ ይሁን ይቅርታም ይደረግልህ የአባታችን የእግዚአብሔር የጌታችን የኢየሱስ ክርስቶስ ጸጋ ይደርብህ ። |
| **፫** | እስመ አስተብቋዕኩክ ትንበር ኤፌሶን አመ አሐውር መቄዶንያ ከመ ትገሥፆሙ ከመ ኢያምጽኡ ካልአ ትምህርተ ። | ወደ መቄዶንያ በሄድኩ ጊዜ በኤፌሶን እንድትቀመጥ ለምኜህ ነበር ሌላ ትምህርት እንዳያመጡ ትገሥጻቸው ዘንድ ። |
| **፬** | ወኢያምጽኡ መኃድምተ ወዛውዐ ነገር ዘይፈጥሩ በዘያስሕቱ ወያመጽኡ ተኀሥም ወየኀድጉ ሕገ እግዚአብሔር ዘሃይማኖት ። | ተረትን እንዳያመጡ ሰውን በሚያስቱ ገንዘብ ፈጥረው የሚናገሩትን ዋዛ ፈዛዛ እንዳያመጡ ፤ ክርክርን ያመጣሉ የታመነውን የእግዚአብሔርን ሕግ ትተው ጸብ ክርክርን እንዳያመጡ ። |
| **፭** | ወማኅለቅቱሰ ለትእዛዝ ተፋቅሮ በንጹሕ ልብ ፤ ወበሠናይ ግዕዝ ፤ ወሃይማኖት ዘአልቦ ኑፋቄ ። | የትእዛዝስ ፍጻሜው በንጹሕ ልብ ፤ በበጎ ምግባር ፤ ጥርጥር በሌለበት ሃይማኖት ሆኖ መዋደድ ነው ። |
| **፮** | እስመ ቦ እለ አውከኩ ወገብኡ ውስተ ነገረ ከንቱ ። | ከዚህ ወጥተው ወደ ከንቱ ነገር የተመለሱ አሉና ። |
| **፯** | ወእንዘ ይፈቅዱ መምህራነ ይኩኑ ኢየአምሩ ዘለሊሆሙ ይነብቡ ። | መምህራን ሊሆኑ ሲወዱም ራሳቸው የሚናገሩትን አያውቁም ። |
| **፰** | ነአምር ከመ ሠናይ ውእቱ ኦሪት ለዘይገብሮ በሕጉ ። | ኦሪት በሕጉ ፀንቶ ለሚፈጽመው መልካም እንደ ሆነ እናውቃለን ። |
| **፱** | ወነአምር ዘኒ ከመ አኮ ለጻድቃን ዘይሠራዕ ሕግ ዘእንበለ ለኃጥአን ወለጽልሕዋን ወለዝሉፋን ወለውፁአን እምጽድቅ ወለርኩሳነ ልብ ፤ ወቀተልተ አበዊሆሙ ወእሞሙ ፤ ወቀተልተ አዝማዲሆሙ ወቀተልተ ነፍስ ። | ይህንም እናውቃለን ፤ ሕግ የሚሠራው ለጻድቃን እንዳይደለ ለኃጢአተኞች ለከዳተኞች ኃጢአትን ለሚያዘወትሩ ከጽድቅ ለወጡ ሐሳባቸው ለረከሰ ፤ አባቶቻቸውን እናቶቻቸውን ዘመዶቻቸውን ለማይረዱ ለነፍሰ ገዳዮች ነው እንጂ ። |
| **፲** | ዘማውያን ወእለ የሐውሩ ብእሲተ ብእሲ ሰረቅተ ሰብእ ፤ ሐሳውያን ወእለ ይምሕሉ በሐሰት ። | ለአመንዝሮች ወደ ጎልማሳ ሚስት ለሚሄዱ ሰውን እያፈኑ ለሚሸጡ ፤ ለሐሰተኞች በሐሰት ለሚምሉ ነው እንጂ ። |
| **፲፩** | ወቦ ባዕድኒ ዓዲ በዘይትቃወምዋ ለትምህርተ ሕይወት ዘወንጌለ ስብሐቲሁ ለብፁዕ እግዚአብሔር ዘአነ ተአመንኩ ቦቱ ። | እኔ ያመንኩበት ንዑድ ክቡር የሚሆን እግዚአብሔር የጌትነቱ ወንጌል የምትናገረውን የሕይወት ትምህርት በሚቃወሙ ሰዎች ላይ የተሠራም ሕግ አለ ። |
| **፲፪** | አእኵቶ ለዘተአመነኒ ወአጽንዐኒ በክርስቶስ ኢየሱስ እግዚእነ እስመ ምእመነ ረሰየኒ ለመልእክቱ ። | የተማመነኝ በጌታችን በኢየሱስ ክርስቶስም ያጸናኝ እግዚአብሔርን አመሰግነዋለሁ ፤ ለመልእክቱ ታማኝ አድርጎኛልና ። |
| **፲፫** | እንዘ ቀዲሙ ጸራሬ አነ ወሰዳዲ ወጸአሊ ፤ ወባሕቱ ተሣሀለኒ እስመ በኢያእምሮ ገበርኩ በኢአሚን ። | እኔ ቀድሞ እሱን የምሰድብ ያመኑበትን የማሳድድ ሕጉን የምነቅፍ ስሆን ነገር ግን ባለማወቅ ባለማመን አድርጌዋለሁና ይቅር አለኝ ። |
| **፲፬** | ወፈድፈደ ጸጋሁ ለእግዚአብሔር በላዕሌየ ፤ ወሃይማኖቱ ወፍቅሩ ለኢየሱስ ክርስቶስ እግዚእነ ። | የእግዚአብሔር ጸጋው በእኔ ላይ በዛ ፤ የጌታችን የኢየሱስ ክርስቶስ ፍቅሩና ሃይማኖቱም በኔ ላይ ፀንቷልና ይቅር አለኝ ። |
| **፲፭** | እሙን ነገሩ ወርቱዕ ይትወከፍዎ በኵሉ እስመ ኢየሱስ ክርስቶስ መጽአ ውስተ ዓለም ከመ ያድኅኖሙ ለኃጥአን ዘአነ ቀዳሚሆሙ ። | ነገሩ የታመነ ነው በሁሉም ሊቀበሉት የሚገባ ነው ፤ ኢየሱስ ክርስቶስ እኔ ፊትውራሪያቸው የምሆን ኃጥአንን ሊያድናቸው ወደዚህ ዓለም መጥቷልና ። |
| **፲፮** | ወባሕቱ ተሣሀለኒ ከመ ያርኢ ተአምራቲሁ በላዕሌየ ኢየሱስ ክርስቶስ ወብዝኀ ትዕግሥቱ ወእኩኖሙ አርአያ ለእለ የአምኑ ቦቱ ለሕይወት ዘለዓለም ። | ነገር ግን ኢየሱስ ክርስቶስ ተአምራቱን የትዕግሥቱንም ብዛት በኔ ላይ ይገልጽ ዘንድ የዘለዓለም ድኅነትን ለማግኘት ለሚያምኑበትም አብነት እሆናቸው ዘንድ ይቅር አለኝ ። |
| **፲፯** | ንጉሥ ዘለዓለም ዘኢይመውት ወኢያስተርኢ አምላክ ባሕቲቱ ፤ ዘሎቱ ክብር ወስብሐት ለዓለመ ዓለም ፤ አሜን ። | የዘለዓለም ንጉሥ የማይሞት እሱ ብቻ የማይታይ አምላክ እንደ ሆነ ለሚያምኑ ለዘለዓለሙ ክብር ምስጋና የሚገባው በእውነት ፤ አሜን ። |
| **፲፰** | ዘንተ ትእዛዘ አማኅፀንኩከ ወልድየ ጢሞቴዎስ ፤ በከመ ተነብዮ ዘላዕሌከ ከመ ትጽናዕ በኵሉ ገድል ሠናይ ። | ልጄ ጢሞቴዎስ! ባንተ እንደ ተነገረው ትንቢት መጠን ሃይማኖትን ይዘህ በበጎ ገድል ትፀና ዘንድ ይህን ትእዛዝ አደራ ብዬሃለሁ ። |
| **፲፱** | እንዘ ብከ ሃይማኖት ወሠናይ ግዕዝ ፤ እስመ ሀለዉ እለ አውከኩ እምሃይማኖት ወተሰብሩ ። | ሃይማኖትና መልካም ጠባይ ያለህ ሆነህ ከሃይማኖት ወጥተው ድል የተነሡ አሉና ። |
| **፳** | እለ ሄሜኔዎስ ወእለ እስክንድሮስ እለ መጠውክዎሙ ለሰይጣን ይትኰነኑ ኢይልመዱ ፀሪፈ ። | ስድብን እንዳይለምዱ ይቀጡ ዘንድ ለሰይጣን አሳልፌ የሰጠኋቸው እነ ሄሜኔዎስ ፤ እነ እስክንድሮስ ናቸው ። |

| **፲፮** | ውእቱ ባሕቲቱ ዘኢይመውት ወቦቱ ብርሃን ዘኢይጠፍእ እምቅድመ ዓለም ፤ ዘአልቦ ዘርእዮ ሰብእ ወአልቦ ዘይክል ርእዮቶ ፤ ዘሎቱ ክብር ወስብሐት ወኃይል ለዓለመ ዓለም ፤ አሜን ። | እርሱ ብቻ የማይሞት የማይሻር ብርሃን ገንዘቡ የሚሆን ዓለም ሳይፈጠር የነበረ ያየው ሰው የሌለ ሊያየውም የሚችል የሌለ ክብር ምስጋና ከሃሊነት ገንዘቡ የሚሆን እርሱ ለዘለዓለሙ ፤ አሜን በእውነት ። |
| **፲፯** | ለአብዕልተ ዝንቱኒ ዓለም አዝዞሙ ከመ ኢይትዐበዩ ፤ ወኢይትአመንዎ ለብዕሎሙ ኃላፊ ፤ ዘእንበለ በእግዚአብሔር ሕያው ዘውእቱ ይሁበነ በብዝኀ ብዕሉ ኵሎ ከመ ንትፈሣሕ ። | የዚህን ዓለም ባለጠጎችም ደስ ይለን ዘንድ በባለጠግነቱ ብዛት ሁሉን በሚሰጠን በሕያው እግዚአብሔር እንጂ በኃላፊው ሀብታቸው እንዳይታመኑና እንዳይታበዩ እዘዛቸው ። |
| **፲፰** | ከመ ይግበሩ ግብረ ሠናየ ወይብዐሉ በገቢረ ጽድቅ ፤ ወይኩኑ ራትዓነ ወጸጋውያነ ወሱቱፋነ ። | በጎ ሥራ እንዲሠሩ የእውነትን ሥራ በመሥራት እንዲከብሩ ቅኖች ለጋሶች ተባባሪዎች እንዲሆኑ እዘዛቸው ። |
| **፲፱** | ወይሣርሩ ለርእሶሙ መሠረተ ሠናየ ለዘይመጽእ ዓለም ፤ ከመ ይርከቡ ሕይወተ ዘበአማን ። | እውነተኛውን ሕይወት ያገኙ ዘንድ ለሚመጣው ዓለም ለራሳቸው በጎ ተግባርን ይሠሩ ዘንድ እዘዛቸው ። |
| **፳** | ኦ ጢሞቴዎስ ዕቀብ ማኅፀንተከ ፤ ተገኃሦሙ ለርኩሳን እለ ያመጽኡ ነገረ ከንቶ ፤ ወያሴስልዋ ለጽድቅ በሐሰት ። | ጢሞቴዎስ ሆይ! አደራህን ጠብቅ ፤ ከንቱ ነገር የሚያመጡትን እውነትን በሐሰት የሚለውጡትን ተለያቸው ። |
