## ምዕራፍ ፯

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፲ ፡ ዘከመ ዐሠረ አብርሃም ለመልከ ጼዴቅ ።** | **ክፍል ፲ ፡ አብርሃም ለመልከ ጼዴቅ ዐሥራት እንደ ሰጠ ።** |
| ፩ | ወመልከ ጼዴቅሰ ንጉሠ ሳሌም ካህኑ ለእግዚአብሔር ልዑል ውእቱ ፤ ዘመጽአ ወተራከቦ ለአብርሃም አመ ተመይጠ እምኀበ ተቃትሎቶሙ ለነገሥት ወባረኮሂ ። | መልከ ጼዴቅም የሳሌም ንጉሥ የልዑል እግዚአብሔር ካህን ነበር ፤ ነገሥታቱን ወግቶ በተመለሰ ጊዜ አብርሃምን የተቀበለው የባረከውም ነው ። |
| ፪ | ወከፈሎ አብርሃም ዐሥራተ እምኵሉ ፤ ቀዳሚ ትርጓሜ ስሙ ንጉሠ ጽድቅ ፤ ወእምዝ ንጉሠ ሳሌም ንጉሠ ሰላም ብሂል ። | አብርሃምም ከገንዘቡ ሁሉ ካሥር አንድ ሰጠው ፤ መጀመሪያ የስሙ ትርጓሜ የጽድቅ ንጉሥ ነበር ፤ ሁለተኛውም የሳሌም ንጉሥ ማለት የሰላም ንጉሥ ነው ። |
| ፫ | አልቦ ዘዘከረ ሎቱ አበ ወኢእመ ፤ ወአልቦ ጥንተ ለመዋዕሊሁ ወኢማኅለቅተ ለሕይወቱ ፤ በአምሳሊሁ ለወልደ እግዚአብሔር ይነብር ክህነቱ ለዝሉፉ ። | አባት እናት አለው ብሎ የተናገረለት የለም ፤ ይህን ጊዜ ተወለደ ይህን ጊዜ ሞተ አይባልም ፤ ክህነቱ የወልደ እግዚአብሔር ምሳሌ ሆኖ ለዘለዓለም ይኖራል ። |
| ፬ | ትሬእዩኑ ዕበዮ ለዝንቱ ዘወሀቦ አብርሃም ዐሥራተ እምኵሉ ዘይኄይስ ፤ ወርእሶሙ ለአበው ውእቱ ። | ጥንታቸው የሚሆን አብርሃም ከገንዘቡ ከሁሉ የሚበልጠውን ካሥር አንድ የሰጠው የዚህን ካህን ክብሩን ታያላችሁን ? |
| ፭ | ወደቂቀ ሌዊሰ ሶበ ይነሥኡ ክህነተ ቦሙ ሥርዓተ ትእዛዝ እምኦሪት ከመ ይንሥኡ ዐሥራተ እምሕዝብ ፤ በከመ ሥርዓተ ሕጎሙ እምላዕለ አኀዊሆሙ እለ ወፅኡ እምሐቋሁ ለአብርሃም ። | የሌዊ ልጆች ግን ክህነትን በተቀበሉ ጊዜ ከሕዝብ ዐሥራት እንዲቀበሉ በኦሪት የታዘዘ ሥርዓት ነበር ፤ እንደ ሕጋቸው ሥርዓት ከአብርሃም ባሕርይ ከተገኙ ከወንድሞቻቸው ነው ። |
| ፮ | ወለዘኢኮነስ እምዘመዶሙ ወሀቦ አብርሃም ዐሥራተ ፤ ወባረኮ ለአብርሃም ዘሎቱ ተስፋ ። | ከወገናቸው ላልሆነ ለዚህ ግን አብርሃም ከዐሥር አንድ ሰጠው ፤ እርሱም ተስፋ የተነገረለት አብርሃምን ባረከው ። |
| ፯ | ወይትዐወቅ ባሕቱ ዘእንበለ ክሕድ ከመ ዘየዐቢ ይባርኮ ለዘይንእስ ። | እንኪያስ ታላቁ ታናሹን እንደሚባርከው ያለ ጥርጥር ይታወቃል ። |
| ፰ | ወበዝየሰ ሰብእ መዋቲ ይነሥእ ዐሥራተ ፤ ወበከሐሰ ለሊሁ ይነሥእ ዘሰማዕቱ መጽሐፍ ከመ ሕያው ውእቱ ። | በዚህ መዋቲ ሰው ዐሥራትን ይቀበላል ፤ በወዲያ ግን ሕያው እንደ ሆነ መጽሐፍ የሚመሰክርለት እርሱ ይቀበላል ። |
| ፱ | ወተብህለ በእንተ አብርሃም ከመ ወሀቦ ዐሥራተ ፤ ወሌዊ ዘይነሥእ ዐሥራተ ውእቱኒ ዐሠረ ። | ዐሥራት እንደ ሰጠ ስለ አብርሃም ተነገረ ፤ ዐሥራትን የሚቀበል ሌዊ እርሱ ስንኳን ዐሥራት ሰጠ ። |
| ፲ | እስመ ዓዲሁ ሀሎ ውስተ ሐቌ አብርሃም አቡሁ አመ ተራከቦ መልከ ጼዴቅ ። | መልከ ጼዴቅ አብርሃምን በተገናኘው ጊዜ በአባቱ በአብርሃም ባሕርይ ነበርና ። |
| ፲፩ | ወእመሰ ይትፌጸም በክህነቶሙ ለሌዋውያን ዘይገብሩ ለሕዝብ በከመ ተሠርዐ ፤ ለምንት እንከ ይትፈቀድ ይሠየም ካልእ ካህን ዘከመ መልከ ጼዴቅ ሢመቱ ፤ ዳእሙ ዘእምይቤ ከመ ሢመተ አሮን ። | እንደ ታዘዘው ሌዋውያን ለሕዝብ በሚያደርጉት ክህነት የሚፈጸምማ ቢሆን ኖሮ ፤ ሹመቱ እንደ መልከ ጼዴቅ ያለ ሌላ ካህን ይሾም ዘንድ እንግዲህ ለምን ይፈለጋል ? ሹመቱ እንደ አሮን የሆነ ባለ ነበረ እንጂ ። |
| ፲፪ | እስመ ሀለዋ ትፍልስ ክህነቶሙ ፤ ወእምከመሰ ፈለሰት ክህነቶሙ ትፈልስ ኦሪቶሙ ። | ክህነታቸው ታልፍ ዘንድ ነበራትና ፤ ክህነታቸውም ካለፈች ሕጋቸው ታልፋለች ። |
| ፲፫ | ወዘተብህለ በእንቲአሁ ከመዝ ተወልደ እምካልእ ሕዝብ ፤ ዘኢዐቀበ ምሥዋዐ ግሙራ አሐዱሂ እምኔሁ ። | ከእርሱ ወገን አንዱ ስንኳን ፈጽሞ መሠዊያውን ካልጠበቀ ከሌላ ሕዝብ እንደ ተወለደ የተነገረለት እርሱ ነው ። |
| ፲፬ | ወይትዐወቅ ዝንቱ ክቱር ከመ እምይሁዳ ወፅአ እግዚእነ ፤ ሕዝብ ዘኢነገረ በእንቲአሁ ሙሴ ሢመተ ክህነት ። | ጌታችን ከይሁዳ እንደ ተወለደ በግልጥ ይታወቃል ፤ ሙሴ ስለ እርሱ የክህነትን ነገር ካልተናገረለት ወገን ። |
| ፲፭ | ወዓዲ ፈድፋደ ያዐውቅ ዝንቱ እስመ ይቤ ይትነሣእ ካህን በአምሳለ ክህነቱ ለመልከ ጼዴቅ ። | ይልቁንም ይህ እጅግ ያስረዳል ፤ ክህነቱ እንደ መልከ ጼዴቅ ያለ ካህን ይነሣል ብሏልና ። |
| ፲፮ | ዘኢኮነ በሕገ ሥርዓት ሥጋ ወደም ፤ አላ በኃይለ ሕይወት ዘኢየኀልቅ ። | ሥጋዊ ደማዊ በሚሆን ሥርዓት ያይደለ ፤ በማይፈጸም በሕይወት ኃይል ነው እንጂ ። |
| ፲፯ | ውእቱ ሰማዕቱ ዘይቤ አንተ ውእቱ ካህን ከመ ሢመቱ ለመልከ ጼዴቅ ። | እንደ መልከ ጼዴቅ ያለ ሹመት ተሹመህ አገልጋይ አንተ ነህ ያለው እርሱ ምስክሩ ነው ። |
| ፲፰ | እስመ ኮነ ተዋልጦ በቀዳሚ ሕግ በእንተ ድክማ ፤ እስመ አልባቲ በቍዕ ። | በመጀመሪያይቱ ሕግ ስለ ድካሟ ለውጥ ተደርጓል ፤ ጥቅም ስላልነበራትና ። |
| ፲፱ | ወኢያበጽሐት ወኢምንተኒ ኦሪት ፤ ወባሕቱ ቦአ ተስፋ ሀየንቴሃ ዘይኄይስ እምኔሃ ፤ ወቦቱ ንቀርቦ ለእግዚአብሔር ። | ኦሪት ምንም ግዳጅ ስላልፈጸመች ፤ ነገር ግን በእርስዋ ፈንታ ከእርስዋ የሚበልጥ ተስፋ መጣ ፤ በእርሱም ወደ እግዚአብሔር እንቀርባለን ። |
| ፳ | እስመ ኢኮነ ዘእንበለ መሐላ ፤ እስመ እልክቱሰ ተሠይሙ ዘእንበለ መሐላ ። | ያለ መሐላ አልሆነምና ፤ ያለ መሐላ የተሾሙ አሉና ። |

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| ፩ | ወለቀዳሚትኒ ደብተራ ባቲ ሥርዓተ ምሥዋዕ ወመቅደስ ። | ለቀደመችቱ ድንኳንም የአገልግሎት ሥርዓትና መቅደስ ነበራት ። |
| ፪ | ወለቀዳሚትኒ ደብተራ እንተ ተሠርዐ ትርሚታ ባቲ ተቅዋመ መብራህት ወማእድ ወኅብስት ዘይሠርዑ ። | ጌጧ ለተከናወነላት ለቀደመችቱ ድንኳንም መብራት የሚያበሩበት መቅረዝ ፤ ማእድና በላይ የተሠራ ኅብስት ነበራት ። |
| ፫ | ወይብልዋ ቅድስት ፤ ወለውሣጢትሰ ደብተራ እንተ እምድኅረ ካልእ መንጦላዕት ይብልዋ ቅድስተ ቅዱሳን ። | ቅድስት ይሏት ነበር ፤ ከሁለተኛው መጋረጃ በስተኋላ የነበረችውን የውስጠኛይቱን ድንኳን ክፍል ግን ቅድስተ ቅዱሳን ይሏት ነበር ። |
| ፬ | ወውስቴታ ማዕጠንት ዘወርቅ ፤ ወታቦትኒ እንተ ውስቴታ ኦሪት እንተ ይከድንዋ በወርቅ ውቱረ ፤ ወውስቴታ መሶበ ወርቅ ዘመና ፤ ወበትረ አሮን እንተ ሠረፀት ወጽላትኒ ዘኦሪት ። | በውስጧም የወርቅ ማዕጠንትና በወርቅ የተለበጠች ሕገ ኦሪት ያለባት ታቦት ነበረች ፤ መናን የያዘች የወርቅ መሶብና የለመለመች የአሮን በትር ሕጉ የተጻፈባቸው ጽላትም በውስጧ ነበሩ ። |
| ፭ | ወመልዕልታ ኪሩቤል ዘስብሐት ይጼልሉ ዲበ ምሥሀል ፤ ወኢኮነ ይእዜ ጊዜሁ ከመ ንንግር በበገጹ ። | በላይዋም የክብር ኪሩቤል በስርየት መክደኛው ላይ ይጋርዱ ነበር ፤ ነገር ግን የሥርዓቱን የጌጡን በየዓይነቱ እንናገር ዘንድ ዛሬ ጊዜው አይደለም ። |
| ፮ | ወዘከመዝ ሥርዓቱ ወትርሚቱ ፤ ወውስተ ጸናፊትሰ ደብተራ ዘልፈ ይበውኡ ካህናት ይግበሩ ምሥዋዖሙ ኵሎ ጊዜ ። | ሥርዓቱ ዝግጅቱ እንዲህ ነበር ፤ ከመጀመሪያይቱ ክፍል በየጊዜው መሥዋዕታቸውን ይሠዉ ዘንድ ካህናት ዘወትር ይገቡ ነበር ። |
| ፯ | ወውስተ ውሣጢትሰ ምዕረ በበዓመት ይበውእ ሊቀ ካህናት ባሕቲቱ ምስለ ደም ፤ ዘያበውእ በእንተ ርእሱ ወበእንተ ሕዝቡ በበይነ ኃጢአቶሙ ። | ከውስጠኛው ክፍል ግን የካህናቱ አለቃ ኃጢአታቸውን ለማስተስረይ ስለ ራሱና ስለ ሕዝቡ የሚያቀርበውን ደም ይዞ በዓመት አንድ ጊዜ ብቻውን ይገባ ነበር ። |
| ፰ | ወከመዝ አዘዘ መንፈስ ቅዱስ ፤ እስመ ዓዲሃ ኢተዐውቀት ፍኖቶሙ ለቅዱሳን በቀዳሚት ደብተራ ። | በቀደመችው ድንኳን የቅዱሳን መንገዳቸው ገና አልታወቀችምና መንፈስ ቅዱስ እንዲህ አዘዘ ። |
| ፱ | ወባሕቱ አምሳለ ኮነ ለዝ መዋዕል ዝክቱ ዘቦቱ ያበውኡ ቍርባነ ወመሥዋዕተ ፤ ዘኢይክል ፈጽሞ ለዘያቄርቦ ። | ነገር ግን ለሚያቀርበው ሰው ግዳጅ መፈጸም የማይቻለውን ቍርባንና መሥዋዕት ያቀርቡበት የነበረው ያ ዘመን ለዚህ ዘመን ምሳሌ ሆነ ። |
| ፲ | ወሰአኑ ዘእንበለ በመባልዕት ወበዘይሰትዩ ወጥምቀታት ዘዘዚአሁ እንተ ይእቲ ሕግ ዘሥጋ ፤ እስከ አመ ይትራታዕ ዘተሠርዓ ። | በመብላት በመጠጣት ልዩ ልዩ በሆነ ጥምቀት ደከሙ ፤ ይህችውም የሥጋ ሕግ ናት ፤ የተሠራው እስኪቃና ድረስ ምሳሌ ሆነ ። |
| **ክፍል** | **ክፍል ፲፩ ፡ በእንተ ሐዳስ ሥርዓት ።** | **ክፍል ፲፩ ፡ ስለ አዲሱ ሥርዓት ።** |
| ፲፩ | ወክርስቶስሰ ዘመጽአ ከዊኖ ሊቀ ካህናት ለእንተ ትመጽእ ሠናይት ፤ በውስተ እንተ ተዐቢ ወትኄይስ ደብተራ እንተ ኢገብራ እደ ሰብእ ወኢኮነት በውስተ ዝ ዓለም ፤ ወአኮ በደመ ላህም ወጠሊ ዘቦአ ። | ለምትመጣይቱ በጎ ሕግ የካህናት አለቃ ሆኖ የመጣው ክርስቶስ ግን ፤ የሰው እጅ ወደ አልሠራት በዚህ ዓለም ወደማትገኘው ከፊተኛይቱ ወደምትበልጠውና ወደምትሻለው ድንኳን ገባ ፤ የላምና የፍየል ደም ይዞ የገባ አይደለም ። |
| ፲፪ | አላ በደመ ዚአሁ ቦአ በምዕር ውስተ ቅድስት ዘለዓለም ወረከበ መድኃኒተ ። | በገዛ ደሙ ወደ ዘለዓለም መቅደስ ገባ እንጂ ፤ የዘለዓለም መድኃኒትነትንም ገንዘብ አደረገ ። |
| ፲፫ | ሶበ ደመ ላሕም ወጠሊ ወከዕበ ዕጐልት ያነጽሕ እምኃጢአት ፤ ወይቄድሶሙ ሥጋሆሙ ለእለ ረኵሱ ። | የላምና የፍየል ደም የጊደር ስብ ከኃጢአት የሚያነጻ የረከሱትንም ሥጋቸውን የሚቀድሳቸው ከሆነ ፤ |
| ፲፬ | እፎ እንከ ፈድፋደ ደሙ ለክርስቶስ ዘሠዋዕ ርእሶ በመንፈስ ዘለዓለም ለእግዚአብሔር ዘአልቦ ነውር ፤ ያነጽሕ ሕሊናነ እምግብር ምውት ከመ ናምልኮ ለእግዚአብሔር ሕያው ። | ነውር የሌለበት ዘለዓለም የሚኖር መሥዋዕት አድርጎ በፈቃዱ ራሱን የሠዋ የክርስቶስ ደሙማ ሕያው እግዚአብሔርን እናመልከው ዘንድ ሕሊናችንን ከሞተ ግብር እንደምን በጣም ያነጻው ይሆን ! |
| ፲፭ | ወበእንተዝ ለሐዳስ ሥርዓት ኢየሱስ ኅሩየ ኮነ ፤ ከመ ጥዒሞ ሞተ ያድኅኖሙ ለእለ ስሕቱ በቀዳሚ ሥርዓት ፤ እለ ሎሙ አስፈወ ወጸውዖሙ ውስተ ርስቱ ዘለዓለም ። | ስለዚህም ሞትን ቀምሶ በመጀመሪያው ሕግ የተሳሳቱትን ተስፋ ሰጥቶ ወደ ዘለዓለማዊ ርስቱ የጠራቸውን ያድናቸው ዘንድ ኢየሱስ ለአዲሲቱ ሥርዓት የተመረጠ ሆነ ። |
| ፲፮ | ኀበ ሀሎ ሥርዓት ግብር ይመጽእ ሞት ላዕለ ዘሠርዓ ። | ሥርዓት ባለበት ዘንድ በሠሪው ላይ ሞት ግድ ይመጣል ። |
| ፲፯ | ሥርዓቱሰ ለዘይመውት ጽንዕት ይእቲ ፤ እስመ ኢትበቍዕ አመ ሕያው ውእቱ ዘሠርዓ ። | የሟች ሰው ሥርዓት የጸናች ናት ፤ ሳይሞት የሠራት ሥራ አትጠቅምምና ። |
| ፲፰ | ከማሁ ቀዳሚትሂ ዘእንበለ ደም ኢተሐደሰት ሥርዓት ። | እንዲሁ ቀድሞም ሕግ ያለ ደም አልጸናችም ። |
| ፲፱ | ወነጊሮ ሙሴ ኵሎ ትእዛዘ ኦሪት ለኵሉ ሕዝብ ፤ ይነሥእ ደመ ላሕም ወጠሊ ምስለ ማይ ወጼርላይ ወቈጽለ ሑሶጵ ፤ ወይነዝኅ መጽሐፈ ኦሪትኒ ወኵሎ ሕዝበ ። | ሙሴ የኦሪትን ትእዛዝ ሁሉ ለሕዝቡ ተናግሮ የላምና የፍየል ደም ከውኃ ጋር ቀላቅሎ ወስዶ ፤ ከቀይ ሐርና ከሂሶጵ ቅጠል ነክሮ መጽሐፈ ኦሪቱንና ሕዝቡን ሁሉ ይረጭ ነበር ። |
