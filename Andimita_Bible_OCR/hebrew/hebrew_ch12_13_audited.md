## ምዕራፍ ፲፪

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፲፫ ፡ በእንተ ትዕግሥቱ ለክርስቶስ ።** | **ክፍል ፲፫ ፡ ስለ ክርስቶስ ትዕግሥት ።** |
| ፩ | ወበእንተ ዝንቱ ንሕነኒ እለ ብነ እሙንቱ ሰማዕት ኩሎሙ ዘየዐውዱነ ከመ ደመና ንግድፍ እምላዕሌነ ኩሎ ክበደ ወሁክተ ኃጢአት ወንሩፅ በትዕግሥት ኀበ ዘጽኑሕ ለነ ተስፋነ ዘሃይማኖት ። | ስለዚህም እንደ ደመና የሚከቡን እነዚህ ሁሉ ምስክሮች ያሉን እኛ የኃጢአትን ትብትብና ሸክም አውርደን እንጣል ፤ ሃይማኖት ወደሚያስገኝልን ወደሚጠብቅልን ተስፋችን በትዕግሥት እንገሥግሥ ። |
| ፪ | ወንትልዎ ለፍጹም መልአክነ ኢየሱስ ክርስቶስ ዘተዐገሠ ኀፍረተ መስቀል አናዕሲዮ በእንተ ፍሥሓሁ ዘጽኑሕ ሎቱ ወመነና ለኀፍረት ወነበረ በየማነ መንበረ እግዚአብሔር ። | ስለሚጠብቀው ደስታውን ንቆ አቃሎ በመስቀል የደረሰበትን ውርደት የታገሠውን ኀፍረትን የናቃትን በአብ ዙፋን ቀኝ የተቀመጠው አለቃችን ኢየሱስ ክርስቶስን እንምሰለው ። |
| ፫ | ሐልይዎ እስኩ ለዘከመዝ ተዐገሠ እምኃጥኣን ወተናገርዎ በበይናቲክሙ ከመ ኢትሥራሕ ነፍስክሙ ወኢትድክም ። | እንግዲህ ከኃጥአን መከራ ታግሦ የተቀበለውን እሱን እስኪ አስቡት እርስ በርሳችሁም ተወያዩት ሰውነታችሁም ፈጽማ እንዳትደክም ። |
| ፬ | እስመ ዓዲክሙ ኢፀናዕክሙ እስከ ለደም ትበጽሑ ተጋደልዋ ለኃጢአት ወእበይዋ ወአብድርዋ ለትምህርተ ተስፋክሙ ። | ደማችሁን እስከ ማፍሰስ ለመድረስ ገና አልፀናችሁምና ኃጢአትን ተዋጓት እምቢ በሏት ተስፋችሁን የምታገኙባትን ትምህርት ውደዷት ። |
| ፭ | እስመ ከመ ውሉድ ይብለክሙ ወልድየ ኢታስተጽሕብ ተግሣፀ እግዚአብሔር ወኢትትገሠሥ እምኔሁ ሶበ ይዘልፈካ አመ ገሠጸከ ። | ልጆቹ እንደ መሆናችሁ ልጄ ! የእግዚአብሔርን ተግሣጽ አታማርር በገሠጸህም ጊዜ ቢዘልፍህ ከእሱ አትራቅ ይላችኋልና ። |
| ፮ | እስመ ዘአፍቀረ እግዚአብሔር ይጌሥፅ ወይቀሥፍዎ ለኩሉ ውሉድ ዘይትፈቀድ ። | እግዚአብሔር የሚወደውን ይገሥጻልና ፣ የሚወደውን ልጅ ሁሉ ይቀጣዋል ። |
| ፯ | ለተግሣጽክሙ ተዐገሡ እስመ ከመ ውሉዱ ያፈቅረክሙ እግዚአብሔር ፤ መኑ ውሉድ ዘኢይጌሥዖ አቡሁ ። | መከራችሁን ታገሡ ፤ እግዚአብሔር ልጆቹ እንደ መሆናችሁ ይወዳችኋልና አባቱ የማይቀጣው ልጅ ማነው ። |
| ፰ | ወእመሰ ኢገሠፀክሙ አንደበራ አንትሙ ወኢኮንክሙ ውሉደ ወዐፀረይክሙ ኩልክሙ ። | ከልቀጣችሁማ ባዕዶች ናችሁ ልጆችም አይደላችሁም ሁላችሁም ተካክላችኋል ። |
| ፱ | ወእመሰ አበዊነ እለ ወለዱነ በሥጋ ይጌሥፁነ ወነኀፍሮሙ እፎ እንከ ፈድፋደ ንግነይ ወንትአዘዝ ለአበ መንፈስነ ይደልወነ ወንሕየው ። | በሥጋ የወለዱን አባቶቻችን የሚቀጡን እኛም የምናፍራቸው ከሆነ እንግዲያ በሕይወት እንደምንኖር ለመንፈሳዊ አባታችን በበለጠ ልንታዘዝ ልንገዛ እንደምን አይገባን ? |
| ፲ | ወእሙንቱሰ ለሥላጤ ለኅዳጥ መዋዕል ይጌሥፁነ በከመ ፈቀዱ ፤ ወውእቱሰ ለእንተ ትጌይስ ለነ ከመ ንርከብ ቅድሳቲሁ ። | እነሱ ለጥቂት ዘመን ግዳጅ ለመፈጸም እንደ ወደዱ ይቀጡናል እሱ ግን ክብሩን እንወርስ ዘንድ እኛን ለምትጠቅም ክብር ይገሥጸናል። |
| ፲፩ | ኩሉ ተግሣፅ ኢይመስል ትፍሥሕተ ለጊዜሁ ዳእሙ ኀዘን ውእቱ ፤ ወድኅረሰ ትፈሪ ሰላመ ለአለ ተገሠፁ ወተዐሥዮሙ ጽድቀ ። | ተግሣጽ ሁሉ ለጊዜው ያሳዝናል እንጂ ደስ አያሰኝም ፤ በኋላ ግን ለተመከሩ ሰላም ታፈራላቸዋለች ጽድቅንም ትሰጣቸዋለች ። |
| ፲፪ | ወበእንተዝ አርትዑ እደ ዕውስተ ወእግረ ዕቡሳተ ። | ስለዚህ የሰለለችውን እጅና ያነከሰችውን እግር አቅኑ ። |
| ፲፫ | ወግበሩ መንኩራኩረ ርቱዐ ለእገሪክሙ ከመ ይሕየው ሕንካሴ ልብክሙ ወኢትትዐንቀፉ ። | የልቡናችሁ አንካሳነት እንዲድንና እንዳትጠራጠሩ ለእግራችሁ የቀና መንኩራኩርን አድርጉ ። |
| ፲፬ | ወሩጹ ኀበ ሰላም ምስለ ኩሉ ወኢትኅድጉ ቅድሳቲክሙ ወዘእንበሌሁሰ አልቦ ዘይሬእዮ ለእግዚአብሔር ። | ከሁሉ ጋር ወደ ሰላም ገሥግሡ ንጽሕናችሁንም አትተዉ ያለ እርሱ ግን እግዚአብሔርን የሚያየው የለም ። |
| ፲፭ | አስተሐይጹ አልቦ ዘያሰትት ጸጋ እግዚአብሔር ወአልቦ ዘይትረከብ ሥርው መሪር እንተ ታሠርፅ ሕማመ እንተ ታስሕቶሙ ወታረኩሶሙ ለብዙኃን ። | አስተውሉ የእግዚአብሔርን ጸጋ የሚያቃልል አይኑር ፤ መከራን የምታመጣ ብዙዎቹን የምታስታቸውና የምታረክሳቸው የመራር ሥር ሆኖ የሚገኝ አይኑር ። |
| ፲፮ | አልቦ ዘይከውን ዘማዊ ወርኩሰ ከመ ዔሳው ዘሠጠ ብኩርናሁ ለአሐዱ መብልዕ ። | ላንድ ጊዜ መብል ብሎ ብኩርናውን እንደ ሸጠ እንደ ዔሳው ሴሰኛና ርካሽ የሚሆን አይኑር ። |
| ፲፯ | ተአምሩ ከመ ድኅሬሃ ፈቀደ ይረስ በረከተ ወአውፅእዎ እስመ ተስአኖ ወኀጥአ ፍኖተ በዘይኔስሕ ወኀሣሣ እንዘ ይበኪ ። | ኋላ ግን በረከትን ሊወርስ እንደ ወደደና እንዳወጡት ታውቃላችሁ ፤ መመለስ ተስኖታልና የሚመለስበትንም መንገድ አጥቶአልና እያለቀሰም ፈለጋት ። |
| ፲፰ | እስመ ኢመጻእክሙ ኀበ እሳት ዘያስተርኢ ዘይነድድ ወጽልመት ግፍትዕት ወቆባር ወዐውሎ ወጣቃ ። | የሚነድ እሳት ወደሚታይበት ወደ ድቅድቅ ጨለማ ወደ ጭጋግ ወደ ጥቅል ነፋስ የሚዳሠሥ ወደሚመስል ጨለማ አልመጣችሁምና ። |
| ፲፱ | ወድምፀ መጥቀዕ ወቃለ ነገር ዘሰምዑ እሙንቱ ወኢፈቀዱ ዳግመ ይትናገሮሙ ። | የነጋሪት ድምፅ ወደ ተሰማበት እነዚያም የነገሩን ድምፅ ሰምተው ዳግመኛ ሊነግራቸው ያልወደዱት ድምፅ ወደ ተሰማበት ። |
