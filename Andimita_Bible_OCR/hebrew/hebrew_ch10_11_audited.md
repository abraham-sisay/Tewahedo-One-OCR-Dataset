## ምዕራፍ ፲

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| ፩ | እስመ ጽላሎታ ይእቲ ኦሪት ለእንተ ትመጽእ ሠናይት ፤ እስመ ኢኮነት ለሊሃ ፤ ወበእንተ ዝንቱ አመ ያበውኡ መሥዋዕተ ዘልፈ በኵሉ ዓመት ፤ ኢይክል ለሊሁ ግሙራ ፈጽሞ ለእለ ያበውእዎ ። | ኦሪት ለምትመጣው በጎይቱ ሕግ ምሳሌ ነበረች እንጂ እርሷ ራሷ አልነበረችምና ፤ ስለዚህ በየዓመቱ ዘወትር መሥዋዕት በሚያቀርቡበት ጊዜ እርሱ ለሚያቀርቡት ሰዎች ግዳጅ ሊፈጽም አይችልም ነበር ። |
| ፪ | ወእመ አኮስ እምአዕረፉ እምዘ ይሠውዑ ፤ እስመ ይሠሪ ሎሙ ኃጢአቶሙ ለእለ ይሠውዑ ፤ ወያነጽሖሙ በምዕር ። | ያ ባይሆን ከሚሠዉት መሥዋዕት ባረፉ ነበር ፤ ለሚሠዉት ኃጢአታቸውን ያስተሰርይላቸዋልና ፤ በአንድ ጊዜም ያነጻቸው ነበርና ። |
| ፫ | አላ ዳእሙ ቦሙ ዘይገብሩ ተዝካረ ኃጢአት በበዓመት በውእቱ መሥዋዕት ። | ነገር ግን በዚያ መሥዋዕት በየዓመቱ የኃጢአት መታሰቢያ አድርገው የሚያቀርቡት ነበራቸው ። |
| ፬ | እስመ ኢይክል ደመ ላሕም ወጠሊ ይኅድግ ኃጢአተ ። | የላምና የፍየል ደም ኃጢአትን ሊያስተሰርይ አይችልምና ። |
| ፭ | ወበእንተዝ አመ ይመጽእ ውስተ ዓለም ይቤ ፤ መሥዋዕተ ወቍርባነ ኢፈቀድከ አላ አልበስከኒ ሥጋ ። | ስለዚህም ወደ ዓለም በሚመጣበት ጊዜ ሥጋን አለበስከኝ እንጂ መሥዋዕትን ቍርባንን አልወደድክም አለ ። |
| ፮ | መሥዋዕተ ዘበእንተ ኃጢአት ኢሠመርከ ። | ስለ ኃጢአት የሚቀርበውን መሥዋዕት አልወደድክም ። |
| ፯ | ውእተ ጊዜ እቤ ነየ መጻእኩ ፤ ውስተ ርእሰ መጽሐፍ ተጽሕፈ በእንቲአየ ፤ ከመ እግበር ፈቃደከ መከርኩ አምላኪየ ። | ያን ጊዜ እነሆ በጄ ብዬ መጣሁ ፤ አምላኪየ ! ፈቃድህን አደርግ ዘንድ ወደድኩ ተብሎ ስለ እኔ በመጽሐፍ ራስ ተጽፏል ። |
| ፰ | መልዕልቶ ይቤ መሥዋዕተ ወቍርባነ ኢፈቀድከ ፤ ዘበእንተ ኃጢአት ኢሠመርኩ ፤ ዘይሠውዑ በሕገ ኦሪት ብሂሎ ። | ከፍ ብሎም ስለ ኃጢአት በኦሪት የሚሠዉትን መሥዋዕቱን ቍርባኑን አልወደድኩም ብሎ ተናገረ ። |
| ፱ | ወእምዝ ይቤ ነየ መጻእኩ ከመ እግበር ፈቃደከ አምላኪየ ፤ ወዝ ቃል ይነሥቶ ለቀዳማይ ከመ ያቅም ደኃራየ ። | ከዚህ በኋላ አምላኬ ሆይ ! ፈቃድህን አደርግ ዘንድ እነሆ መጣሁ አለ ፤ ይህ ቃል የኋለኛውን ያጸና ዘንድ የፊተኛውን ያፈርሳል ። |
| ፲ | ከመ ንትቀደስ በሥምረቱ ፤ በቍርባነ ሥጋሁ ለኢየሱስ ክርስቶስ ዘኮነ በምዕር ። | በፈቃዱ አንድ ጊዜ በቀረበው በኢየሱስ ክርስቶስ በሥጋው ቍርባንነት እንከብር ዘንድ ። |
| ፲፩ | ወኵሉ ሊቀ ካህናት ይቀውም ኵሎ አሚረ ፤ ወይሠውዕ ኪያሃ ከመ መሥዋዕተ እንተ ለግሙራ ኢትክል አንጽሖ ኃጢአት ። | የካህናት አለቃ ሁሉ ዘወትር ቆሞ ያገለግል ነበር ፤ ፈጽሞ ኃጢአት ማስተስረይ የማይቻላትን ያችን ይዞ መሥዋዕት ይሠዋ ነበር ። |
| ፲፪ | ወውእቱሰ ምዕረ ሠዋዕ መሥዋዕተ እንተ ለዝሉፉ በእንተ ኃጢአትነ ፤ ወነበረ በየማነ እግዚአብሔር ። | እርሱ ግን ስለ ኃጢአታችን ዘለዓለም የምትኖር መሥዋዕትን አንድ ጊዜ ሠውቶ በእግዚአብሔር ቀኝ ተቀመጠ ። |
| ፲፫ | ወይጸንሕ እንከ እስከ ይገብኡ ጸላእቱ ታሕተ መከየደ እገሪሁ ። | እንግዲህ ጠላቶቹ ከእግሩ በታች እስኪገቡ ድረስ ይጠብቃል ። |
| ፲፬ | አሐተ መሥዋዕተ ገብረ እንተ ለግሙራ ለእለ ይትቀደሱ ። | ለሚከብሩም ሰዎች ለዘወትር የምትሆን አንዲት መሥዋዕት ሠዋ ። |
| ፲፭ | ወሰማዕትነ መንፈስ ቅዱስ ። | መንፈስ ቅዱስም ምስክራችን ነው ። |
| ፲፮ | እምድኅረ ይቤ ዛቲ ሥርዓት እንተ እሠርዕ ሎሙ እምድኅረ እማንቱ መዋዕል ይቤ እግዚአብሔር ፤ አወዲ ሕግየ ውስተ ልቦሙ ወአጽሕፎ ውስተ ሕሊናሆሙ ። | ከነዚያ ቀኖች በኋላ የምሠራላቸው ሥርዓት ይህች ናት ካለ በኋላ ፤ እግዚአብሔር ሕጌን በልባቸው አሳድራለሁ በሕሊናቸውም እጽፈዋለሁ ብሏልና ። |
| ፲፯ | ወኢይዜከር እንከ ኃጢአቶሙ ወአበሳሆሙ ። | እንግዲህ ኃጢአታቸውን በደላቸውን አላስብባቸውም ። |
| ፲፰ | ወእምከመሰ ይትኀደግ ከመዝ አልቦ እንከ መሥዋዕት በእንተ ኃጢአት ። | አንድ ጊዜ በተሠዋው የሚሠረይ ከሆነስ እንግዲህ ስለ ኃጢአት መሥዋዕት የለም ። |
| ፲፱ | ብነ አኀዊነ ሞገስ ውስተ በዓትነ ቤተ መቅደስ በደሙ ለኢየሱስ ። | ወንድሞቻችን ! የኢየሱስን ደም ይዘን ወደ ቤተ መቅደስ በምንገባበት ጊዜ ባለሟልነት አለን ። |
| ፳ | እስመ ሐደሰ ለነ ፍኖተ ጽድቅ ወሕይወት ግብተ በመንጦላዕተ ሥጋሁ ። | ሥጋውን መጋረጃ አድርጎ የሕይወትንና የጽድቅን መንገድ ፈጽሞ አድሶልናልና ። |
| ፳፩ | ካህን ዐቢይ ለቤተ እግዚአብሔር ። | ለቤተ እግዚአብሔር ታላቁ ካህን እርሱ ነው ። |
| ፳፪ | ንቅረብ እንከ በልበ ጽድቅ ወበሃይማኖት ፍጹም ምእመን ፤ እንዘ ንጹሕ ልብነ ወንጹሓን ንሕነ እምግባረ እኩይ ፤ ወሕፁብ ሥጋነ በማይ ንጹሕ ። | እንግዲህ ልባችንን ንጹሕ አድርገን ሰውነታችንን አንጽተን ፤ እኛም በጥሩ ውኃ ታጥበን በእውነተኛ ልብና ፈጽሞ በታመነ ሃይማኖት ሁነን እንቅረብ ። |
| ፳፫ | ናጽንዕ እንከ አሚነ ወተስፋነ ዘእንበለ ነውር ፤ እስመ ጻድቅ ዘአስፈወነ ። | እንግዲህ ተስፋ የሰጠን እርሱ የታመነ ነውና ፤ ያለ ጥርጥር ተስፋችንንና ሃይማኖታችንን እናጽና ። |
| ፳፬ | ወንትቀናው ምስለ ቢጽነ በተፋቅሮ ወበምግባረ ሠናይ ። | ከባልንጀራችንም ጋር በፍቅርና በበጎ ምግባር እንዋደድ ። |
