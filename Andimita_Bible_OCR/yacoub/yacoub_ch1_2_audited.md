| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፩ ፡ በእንተ ተዐግሦ መከራ ።** | **ክፍል ፩ ፡ መከራ ስለ መታገሥ ።** |
| ፩ | እምያዕቆብ ገብረ እግዚአብሔር ወእግዚእነ ኢየሱስ ክርስቶስ ለዐሠርቱ ወክልኤቱ ሕዝበ ድዮስጶራ ሰላም ለክሙ ። | የእግዚአብሔርና የጌታችን ኢየሱስ ክርስቶስ አገልጋይ ከሚሆን ከያዕቆብ የተላከች መልእክት በስደት ላሉ ለዐሥራ ሁለት ነገደ እስራኤል ትድረስ ። |
| ፪ | ኦ አኀው ኩኑ በኩሉ ፍሥሓ ሶበ መንሱት ይመጽአክሙ ዘዘዚአሁ ። | ወንድሞች ! ልዩ ልዩ መከራ በሚመጣባችሁ ጊዜ በፍጹም ደስታ ሁኑ ። |
| ፫ | እንዘ ተአምሩ ከመ መከራሁ ለሃይማኖትክሙ ትዕግሥተ ይገብር ለክሙ ። | በሃይማኖታችሁ የሚመጣው ፈተና ትዕግሥትን እንደሚያደርግላችሁ ዕወቁ ። |
| ፬ | ወትዕግሥትሰ ግብር ፍጹም ቦቲ ከመ ትኩኑ ፍጹማነ ወጥዑያነ እንዘ አልቦ ዘተኀጥአ ። | ትዕግሥትስ ምንም ሳይጐድላችሁ ፍጹማን ጤነኞች ትሆኑ ዘንድ ፍጹም ግብር አላት ። |
| ፭ | ወእመሰ ቦ ዘኀጥአ ለጥበብ ለይስአል ኀበ ወሀቢ እግዚአብሔር ዘይሁብ ለኩሉ በስፉሕ እንዘ ኢይትዔየር ወኢይዘረኪ ወይትወሀብ ሎቱ ። | ጥበብን ያጣት ሰው ቢኖር ሳይገዳደር ሳይላገጥ ለሁሉ በሰፊው የሚሰጥ ለጋስ እግዚአብሔርን ይለምን ይሰጠዋል ። |
| ፮ | ወይስአል እንዘ ይትአመን ወኢይናፍቅ ፤ እስመ ዘይናፍቅሰ ይከውን ከመ ሞገደ ባሕር እንተ ይዘብጣ ነፋስ ወያነውኃ ። | ሳይጠራጠር አምኖ ይለምን ፤ የሚጠራጠር ግን ነፋስ እንደሚመታት እንደሚያንጓልላት የባሕር አዝዋሪ ይሆናል ። |
| ፯ | ወኢይምሰሎ ለውእቱ ብእሲ ከመ ዘይነሥእ ምንተሂ እምኀበ እግዚአብሔር ። | ለዚያ ሰው ከእግዚአብሔር ምን ምን የሚያገኝ አይምሰለው ። |
| ፰ | እስመ ብእሲ ዘክልኤ ልቡ ህዉክ ውእቱ በኩሉ ፍኖቱ ። | ልቡ ሁለት የሆነ ሰው በመንገዱ ሁሉ ይታወካልና ። |
| ፱ | ለይትመካሕኬ ነዳይ በተልዕሎቱ ። | ድሀ ወንድማችን ከፍ ከፍ በማለቱ ደስ ይበለው ። |
| ፲ | ወባዕልሰ በተትሕቶቱ እስመ ከመ ፍሬ ሣዕር የኀልፍ ። | ባለ ጠጋውም በመዋረዱ ይዘን እንደ ሣር ፍሬ ያልፋልና ። |
| ፲፩ | ወእምከመ ሠረቀ ፀሐይ ምስለ ሳሀቡ ያየብሶ ለሣዕር ወፍሬሁሂ ይወድቅ ወሥነ ራእዩኒ ይትኀጐል ፤ ከማሁኬ ባዕልኒ በፍናዊሁ ይጸመሂ ። | ፀሐይ ከዋዕዩ ጋር በወጣ ጊዜ ሣሩን ያደርቀዋል ፍሬውም ይረግፋል ልምላሜውም ይጠፋል ፤ ባለጠጋም እንዲሁ በሥራው ይጠፋል ። |
| ፲፪ | ወብፁዕ ብእሲ ዘይትዔገሣ ለእኪት ፤ እስመ ተመኪሮ ይነሥእ አክሊለ ሕይወት ዘአሰፈዎሙ እግዚአብሔር ለእለ ያፈቅርዎ ። | መከራን ታግሦ የሚቀበላት ሰው ንኡድ ነው ፤ ተፈትኖም እግዚአብሔር ለሚወዱት ያዘጋጀውን የክብር አክሊል ይወርሳልና ። |
| ፲፫ | ወእመቦ ዘይትሜከር ኢይበል እግዚአብሔር ያሜክረኒ ፤ እስመ እግዚአብሔር ኢያሜክር ለእኪት ፤ ወውእቱሰ ኢያሜክር ወኢመነሂ ። | የሚፈተን ቢኖር እግዚአብሔር ይፈትነኛል አይበል ፤ እግዚአብሔር ለክፉ ነገር አይፈትንምና ፤ እርሱስ ማንንም አይፈትንም ። |
| ፲፬ | አላ አሐዱ አሐዱ ይትሜከር በፍትወተ እንቲአሁ ወይወፅእ ኀቤሃ ወይደነግፅ ። | አንዱም አንዱ በራሱ ምኞት ይፈተናል እንጂ ወደ እርሷ ይወጣል ይደነግጣል ። |
| ፲፭ | ወፍትወትሰ እምከመ ፀንሰት ትወልዳ ለኃጢአት ፤ ወኃጢአትኒ እምከመ ተፈጸመት ትወልዳ ለሞት ። | ምኞትም ከተፀነሰች ኃጢአትን ትወልዳታለች ፤ ኃጢአትም የተፈጸመች እንደሆነ ሞትን ትወልዳታለች ። |
| ፲፮ | ኢያስሕቱክሙ አኃዊነ ፍቁራን ። | የተወደዳችሁ ወንድሞቻችን ! አያስቷችሁ ። |
| ፲፯ | ኩሉ ሀብት ሠናይ ወኩሉ ፍትው ፍጹም እምላዕሉ ይእቲ ትወርድ እምኀበ አቡሃ ለብርሃን ውእቱ ዘአልቦ ተውላጥ ኀቤሁ ወአልቦ ምንትኒ ዘያመስጥ እምእዴሁ ። | መልካም ሀብት ሁሉ ፍጹም በረከትም ሁሉ ከላይ ናት ከብርሃናት አባት ትወርዳለች ፤ መለወጥ የሌለበት እርሱ ከእርሱም የሚያመልጥ ምንም ምን የለም ። |
| ፲፰ | እስመ በፈቃዱ ወለደነ በቃለ ጽድቁ ከመ ንኩን ቀደምተ ለፍጥረቱ ። | ለፍጥረቱ ተቀዳሚዎች እንሆን ዘንድ በፈቃዱ በእውነተኛ ቃሉ ወልዶናልና ። |
| ፲፱ | ወይእዜኒ አኃዊነ ኩኑ ወይኩን ኩሉ ብእሲ ፍጡነ ለሰሚዕ ወጐንዱየ ለነቢብ ወጐንዱየ ለመዓት ። | ወንድሞቻችን ! አሁንም ዕወቁ ሰው ሁሉ ለመስማት የፈጠነ ለመናገርና ለቍጣ የዘገየ ይሁን ። |
| ፳ | እስመ መዓቱ ለብእሲ ጽድቀ እግዚአብሔር ኢያገብር ። | የሰው ቍጣው የእግዚአብሔርን ጽድቅ አያሠራውምና ። |
| ፳፩ | ወይእዜኒ ኅድግዋ ለኩላ ርስሐት ወለኩላ እኪት ፤ ወበየውሃት ተቀበልዎ ለቃል ዘተዘርአ ውስተ ልብክሙ ዘይክል አድኅኖታ ለነፍስክሙ ። | አሁንም ርኩሰትን ሁሉ ክፋትን ሁሉ ተዉአት ፤ ነፍሳችሁን ማዳን የሚቻለውን በልባችሁ የተዘራውን ቃል በገርነት ተቀበሉት ። |
| ፳፪ | ወኩኑ ገባርያኒሃ ለሕግ ወአኮ ሰማዕያኒሃ ባሕቲቱ ፤ ሐልይዎ እስኩ ለሊክሙ ። | ሕግ ፈጻሚዎች ሁኑ ለመስማት ብቻ አይደለም ፤ እስኪ እናንተ ራሳችሁ አስቡት ። |
| ፳፫ | እመቦ ዘይሰምዖ ለቃል ወኢይገብሮ ይመስል ከመ ብእሲ ዘይሬኢ ፍጥረተ ገጹ በመጽሔት ። | ቃልን ሰምቶ የማይሠራው ቢኖር ፊቱን በመስተዋት የሚያየውን ሰው ይመስላል ። |
| ፳፬ | ወጠይቆ ርእዮ ኀለፈ ወረስዐ ዘከመ እፎ ውእቱ ። | ራሱንም ተመልክቶ እርሱ እንዴትም እንደ ሆነ ዘንግቶ ያለፈ ። |
