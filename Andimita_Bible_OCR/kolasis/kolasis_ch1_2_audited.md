| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፩ ፡ ዘከመ ይደሉ ጸልዮ በእንተ ቢጽ ።** | **ክፍል ፩ ፡ ለባልንጀራ መጸለይ እንደገባ ።** |
| ፩ | እምጳውሎስ ሐዋርያሁ ለእግዚእነ ኢየሱስ ክርስቶስ በፈቃደ እግዚአብሔር ፤ ወጢሞቴዎስ እኁነ ፤ ለቅዱሳን እለ ውስተ ቆላስይስ ወአኀዊነ ምእመናን በኢየሱስ ክርስቶስ ። | በእግዚአብሔር ፈቃድ የጌታችን የኢየሱስ ክርስቶስ ሐዋርያ ሆኜ ከተሾምኩት ከእኔ ከጳውሎስና ከወንድማችን ከጢሞቴዎስ የተላከች መልእክት ፤ በቆላስይስ ላሉ ቅዱሳን በኢየሱስ ክርስቶስ ላመኑ ምእመናን ወንድሞቻችን ትድረስ ። |
| ፪ | ሰላም ለክሙ ወጸጋ ለእግዚአብሔር አቡነ ወእግዚእነ ኢየሱስ ክርስቶስ ። | ሰላም ለእናንተ ይሁን ፤ የአባታችን የእግዚአብሔር የጌታችን የኢየሱስ ክርስቶስ ጸጋ ይደርባችሁ ። |
| ፫ | ነአኵቶ ለእግዚአብሔር አቡሁ ለእግዚእነ ኢየሱስ ክርስቶስ ዘልፈ በእንቲአክሙ ። | የጌታችን የኢየሱስ ክርስቶስ አባቱ እግዚአብሔርን ፤ ዘወትር ስለ እናንተ እናመሰግነዋለን ። |
| ፬ | ወንጼሊ እምአመ ሰማዕነ ሃይማኖተክሙ በኢየሱስ ክርስቶስ ፤ ወዘከመ ታፈቅርዎሙ ለኵሎሙ ቅዱሳን ። | በኢየሱስ ክርስቶስ ማመናችሁንና ቅዱሳንን ሁሉ መውደዳችሁን ፤ ከሰማንበት ጀምሮ እንጸልያለን ። |
| ፭ | በእንተ ተስፋክሙ ዘሥዩም ለክሙ በሰማያት ፤ ዘአቅደምክሙ ሰሚዐ በቃለ ጽድቅ ትምህርተ ወንጌል ። | የእውነት ቃል በሆነው በወንጌል ትምህርት አስቀድሞ ስለ ሰማችሁት ፤ በሰማያት ስለ ተዘጋጀላችሁ ስለ ተስፋችሁ ። |
| ፮ | ዘበጽሐ ኀቤክሙ ፤ ከመ በኵሉ ዓለም ይፍረይ ወይሥመር በላዕሌክሙ ፤ እምአመ ሰማዕክሙ ወርኢክሙ ጸጋ እግዚአብሔር በጽድቅ ። | በመላው ዓለም እንደ ደረሰ ወደ እናንተ የደረሰ የወንጌል ትምህርት ፤ የእግዚአብሔርን ጸጋ በእውነት ካያችሁና ከሰማችሁ ፤ በእናንተ ላይ ብዙ ፍሬ ያፈራላችሁ ዘንድ እንጸልያለን ። |
| ፯ | ዘተመሀርክሙ በኀበ ኤጳፍራስ እኁነ ፤ ላእክ ዚአነ ምእመን በክርስቶስ ፤ ዘይትለአክ በእንቲአክሙ ። | ከወንድማችን ከኤጳፍራስ የተማራችሁትን ፤ በክርስቶስ ያመነ ለእኛም ረዳታችን የሆነ ፤ ስለ እናንተ የሚያገለግል ። |
| ፰ | ወውእቱ ነገረነ ተፋቅሮተክሙ በመንፈስ ። | እርሱ በማስተዋል መዋደዳችሁን ነግሮናል ። |
| ፱ | ወበእንተዝ ንሕነሂ እምአመ ሰማዕነ ዜናክሙ ፤ ኢኀደግነ ጸልዮ በእንቲአክሙ ወስኢለ ፤ ከመ ትፈጽሙ አእምሮ ፈቃዱ ለእግዚአብሔር ፤ በኵሉ ጥበብ ወበኵሉ ምክረ መንፈስ ። | ስለዚህ እኛም የናንተን ነገር ከሰማን ጀምሮ ፤ በፍጹም መንፈሳዊ ምክር እግዚአብሔር የሚወደውን ግብር ማወቅን ትፈጽሙ ዘንድ ፤ ስለ እናንተ እንጸልያለን እንማልዳለን ። |
| ፲ | ከመ ትሑሩ በዘይደልወክሙ ለኀበ እግዚአብሔር ፤ ወበኵሉ ታድልዉ ሎቱ በኵሉ ምግባረ ሠናይ ፤ እንዘ ትፈርዩ ወትሠምሩ በጥበበ አእምሮ እግዚአብሔር ። | ወደ እግዚአብሔር ለመድረስ በሚገባችሁ መንገድ ትሄዱ ዘንድ ፤ እግዚአብሔርን በማወቅ ጥበብ ያማራችሁ ያበጃችሁ ሆናችሁ ፤ በፍጹም በጎ ምግባር ደስ ታሰኙት ዘንድ ። |
| ፲፩ | እንዘ ትጸንዑ በኵሉ ኀይል ወበጽንዐ ስብሐቲሁ ፤ በኵሉ ትዕግሥት ወበተስፋ ወበፍሥሐ ። | በከሃሊነቱ ብርታት በተሰጣችሁ ፍጹም ኃይል ፤ በፍጹም ትዕግሥት በተስፋ በደስታ ጸንታችሁ ። |
| ፲፪ | አእኵትዎ ለእግዚአብሔር አብ ዘረሰየነ ድልዋነ ፤ ለመክፈልተ ርስቶሙ ለቅዱሳን በብርሃን ። | በብርሃን የቅዱሳንን ርስት ለመካፈል የበቃን ያደረገን ፤ እግዚአብሔር አብን አመስግኑት ። |
| ፲፫ | ወአድኅነነ እምኵነኔ ጽልመት ፤ ወአግብአነ ውስተ መንግሥተ ወልዱ ፍቁሩ ። | ለድንቁርና ከመገዛት ነጻ ያወጣን ፤ ልጁ ወደሚያወርሳት መንግሥት የመለሰን ። |
| ፲፬ | ዘቦቱ ረከብነ መድኃኒተ ፤ ወተኀድገ ለነ ኃጢአትነ ። | ድኅነት ያገኘንበት ፤ ኃጢአታችን የተሠረየበት ። |
| ፲፭ | ዘውእቱ አምሳሊሁ ለእግዚአብሔር ዘኢያስተርኢ ፤ በኵር ዘላዕለ ኵሉ ፍጥረት ። | ይኸውም የማይመረመር እግዚአብሔርን በባሕርይ የሚተካከለው በመልክ የሚመስለው ነው ፤ ፍጥረቱን ሁሉ ፈጥሮ የሚገዛ አንድ ልጁ ነው ። |
| ፲፮ | እስመ ቦቱ ኵሎ ፈጠረ ዘበሰማይኒ ወዘበምድርኒ ፤ ዘያስተርኢ ወዘኢያስተርኢ ፤ እመኒ መናብርት ወእመኒ አጋእዝት ወእመኒ መኳንንት ወእመኒ ቀደምት ፤ ኵሉ ዘኮነ በእዴሁ ወኵሉ ቦቱ ተፈጥረ ። | በእሱ ቃልነት እግዚአብሔር ሁሉን ፈጥሯልና ፤ በሰማይ ያለውን በምድርም ያለውን የሚታየውንም የማይታየውንም ፤ መናብርትም ቢሆኑ አጋእዝትም ቢሆኑ መኳንንትም ቢሆኑ ቀደምትም ቢሆኑ ፤ ሁሉ በቃሉ የተፈጠረ ነው ፤ ሁሉም በእሱ ተፈጠረ ። |
| ፲፯ | ወውእቱ ሀልወ እምቅድመ ኵሉ ፤ ወኵሉ ቦቱ ቆመ ። | እርሱ ከሁሉ አስቀድሞ የነበረ ነው ፤ ሁሉም በእርሱ ጸንቶ ይኖራል ። |
| ፲፰ | ወውእቱ ርእሳ ለቤተ ክርስቲያን ፤ እስመ ውእቱ በኵር ቀደመ እምኵሎሙ ምውታን ተንሥኦ ፤ ከመ ይኩን ውእቱ ርእሰ ለኵሉ ። | የቤተ ክርስቲያን ገዥዋ እርሱ ነው ፤ በኵር እርሱ ለሁሉ ገዥ ይሆን ዘንድ ፤ ከሙታን ሁሉ አስቀድሞ ተነሥቷልና ። |
| ፲፱ | እስመ ሠምረ ቦቱ ፍጹመ ኵሉ ይኅድር ላዕሌሁ ፤ ወቦቱ ይሣሀሎ ለኵሉ ። | ሁሉ በእርሱ አምኖ ሊኖር ወዷልና ፤ ሁሉን በእርሱ ይቅር ይለው ዘንድ ። |
| ፳ | ወገብረ ሰላመ በደመ መስቀሉ ፤ ለዘበሰማይ ወለዘበምድር ። | በመስቀል ላይ ባፈሰሰው ደሙ ፤ በሰማይና በምድር ላሉት ዕርቅ አደረገ ። |
