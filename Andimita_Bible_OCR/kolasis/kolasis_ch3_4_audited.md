| **ክፍል** | **ክፍል ፬ ፡ በእንተ ትንሣኤ ልቡና ።** | **ክፍል ፬ ፡ ስለ ልቡና ትንሣኤ ።** |
| ፩ | ወእመሰ ተንሣእክሙ ምስለ ክርስቶስ ፤ ዘላዕሉ ኅሡ ኀበ ሀሎ ክርስቶስ በየማነ እግዚአብሔር ይነብር ። | ከክርስቶስ ጋር ከተነሣችሁ ፤ በአብ ቀኝ የሚኖር ክርስቶስ ካለበት ዘንድ የላይኛውን ዓለም ሹ ። |

| ፫ | እስመ ወዳእክሙ ሞትክሙ ፤ ወኅብእት ሕይወትክሙ ምስለ ክርስቶስ በኀበ እግዚአብሔር ። | እናንተ ፈጽማችሁ ሙታችኋልና ፤ ሕይወታችሁም ከክርስቶስ ጋራ በእግዚአብሔር ዘንድ የተሠወረች ናት ። |
| ፬ | ወአመ ይመጽእ ክርስቶስ ይትዐወቅ ሕይወትክሙ ፤ ይእተ አሚረ ታስተርእዩ ምስሌሁ በስብሐት ዐቢይ ። | ክርስቶስ ሲመጣ ያን ጊዜ ሕይወታችሁ ይታወቃል ፤ ያን ጊዜም ከእርሱ ጋር በፍጹም ክብር ትገለጣላችሁ ። |
| ፭ | አሙትዎ ለነፍስትክሙ ዘዲበ ምድር እምዝሙት ወርኵስ ፤ ወሕሱት ወፍትወት እኪት ፤ ወትዕግልት ዘውእቱ አምልኮ ጣዖት ። | ምድራዊ ሰውነታችሁን ከዝሙት ከኃጢአት ከጥፋት ከክፉ ምኞት ከስስት ለዩት ፤ ይኸውም ጣዖት ማምለክ ነው ። |
| ፮ | ዘበእንቲአሁ ይመጽእ መቅሠፍተ እግዚአብሔር ላዕለ ውሉድ ዓላውያን ። | በእርሱ ምክንያት በማይመቹ ልጆች ላይ የእግዚአብሔር መቅሠፍት የሚመጣበት ። |
| ፯ | ዘቦቱ ሖርክሙ አንትሙሂ ትካት ፤ አመ ሐየውክሙ በዝንቱ ግብር ። | በዚህ ሥራ በነበራችሁ ጊዜ ፤ እናንተም ቀድሞ ጸንታችሁ የኖራችሁበት ። |
| ፰ | ወይእዜሰ ዓድግዋ ለመዓት ወለቍጥዓ ወለእክይ ፤ ወለጽርፈት ወለነገረ ኀፍረት ፤ ወነገረ ከንቱ ኢይጻእ እምአፉክሙ ። | አሁንም ቁጣን ተዉአት ፤ ብስጭትንና ክፋትን ስድብንም የሚያሳፍረውን ነገርም ተዉ ፤ ከንቱ ነገር ከአፋችሁ አይውጣ ። |
| ፱ | ወኢተሐስዉ ቢጸክሙ ፤ ዳእሙ ዓድግዎ ለብእሲ ምስለ እኩይ ምግባሩ ። | ወንድሞቻችሁን አትክዱ ፤ አሮጌውን ሰውነታችሁንም ከክፉ ሥራ ጋር ተዉት ። |
| ፲ | ወልበስዎ ለሐዲሲ ብእሲ ፤ ዘይትሔደስ በአእምሮ እምሳለ ፈጣሪሁ ። | በፈጣሪው አምሳል በዕውቀት የሚታደስ ፤ አዲሱን ሰውነት ምሰሉት ። |
| ፲፩ | ዘአልቦ በኀቤሁ አይሁዳዊ ወኢ አረማዊ ፤ ኢ ግዙር ወኢ ቄላፍ ፤ ኢ ሐቃል ወሀገሪት ፤ ኢ ነባሪ ወኢ እግዛእ ፤ ዘእንበለ በኵሉ ወበኀበ ኵሉ ክርስቶስ ። | አይሁዳዊ አረማዊ የተገዘረ ያልተገዘረ ፤ በበረሓ ያለ ቤተ ሰብ አሳዳሪ ማለት የሌለበት ፤ ክርስቶስ በሁሉ ዘንድ ለሁሉ ነው እንጂ ። |
| ፲፪ | ልበስዎ እንከ ከመ ኅሩያነ እግዚአብሔር ቅዱሳን ወፍቁራን ፤ በምሕረት ወበተሣህሎ ፤ ወበኂሩት ወትሑት ልብ ወበየውሃት ወበትዕግሥት ። | እንግዲህ እግዚአብሔር እንደ መረጣቸው እንደ ወዳጆቹ እንደ ቅዱሳን ፤ በምሕረት በይቅርታ በቸርነት በትሑት ልብ በገርነት በትዕግሥት ምሰሉት ። |
| ፲፫ | ጹርዎሙ ለቢጽክሙ ወተጻገዉ በበይናቲክሙ ፤ ዓድጉ ለቢጽክሙ ዘተሐየስክምዎሙ ፤ ከመ ክርስቶስ ጸገወክሙ ከማሁ አንትሙሂ ግበሩ ። | ባልንጀሮቻችሁን ታገሥዋቸው እርስ በርሳችሁ ተረዳዱ ፤ ለወንድሞቻችሁ የተቀየማችሁባቸውን ተዉላቸው ፤ ክርስቶስ ይቅር እንዳላችሁ እናንተም እንዲሁ አድርጉ ። |
| ፲፬ | ወምስለ ዝንቱ ኵሉ ተፋቀሩ ዘልፈ ፤ እስመ ማእሰረ ተፍጻሜቱ ውእቱ ። | ከዚህም ሁሉ ጋር ዘወትር በፍቅር ኑሩ ፤ ያንድነቱ ፍጻሜ ማሠሪያ እርሱ ነውና ። |
| ፲፭ | ወሰላሙ ለክርስቶስ ይጽናዕ በልብክሙ ፤ ዘሎቱ ተጸዋዕክሙ በአሐዱ ሥጋ ፤ ወሀልዉ በአኵቴቱ ለክርስቶስ ። | አንድ አካል በመሆን የተጠራችሁለት የክርስቶስ ፍቅሩ በልባችሁ ጸንቶ ይኑር ፤ ክርስቶስንም እያመሰገናችሁ ኑሩ ። |
| ፲፮ | ወአንብቡ መዝሙረ ወስብሐተ ወማኅሌተ ቅድሳት ፤ ወቃለ እግዚአብሔር ይጽናዕ በኀቤክሙ ከመ ትብዐሉ በኵሉ ጥበብ ፤ ወመሀሩ ነፍሰክሙ ወገሥጹ በመንፈስ ዘምሩ ለእግዚአብሔር በልብክሙ ። | የዳዊትን መዝሙር የሙሴንም ምስጋና የተለየ የሰሎሞን መኃልይን አንብቡ ፤ በፍጹም ጥበብ እንድትበለጽጉ የእግዚአብሔር ቃል በእናንተ ዘንድ ሰውነታችሁን አስተምሩ ፤ በማስተዋል ምከሩ በልቡናችሁ ለእግዚአብሔር ምስጋና አቅርቡ ። |
| ፲፯ | ወኵሎ ዘትገብሩ በስመ እግዚእነ ኢየሱስ ክርስቶስ ግበሩ ፤ ወአእኵትዎ ለእግዚአብሔር አብ በእንቲአሁ ። | የምትሠሩትን ሁሉ በጌታችን በኢየሱስ ክርስቶስ አድርጉ ፤ ስለ እርሱም እግዚአብሔር አብን አመስግኑት ። |

| ፲፱ | አደውኒ አፍቅሩ አንስቲያክሙ ወኢትግአዝዎን ። | ወንዶችም ሚስቶቻችሁን ውደዱ አትንቀፏቸውም ። |
| ፳ | ውሉድኒ ተአዘዙ ለአዝማዲክሙ በኵሉ ፤ እስመ ከማሁ ርቱዕ ወይሠምር እግዚአብሔር ። | ልጆችም ለወላጆቻችሁ በሁሉ ታዘዙ ፤ እንዲህ ማድረግ ይገባልና እግዚአብሔርም ይህን ይሻልና ። |
| ፳፩ | አበውኒ ኢታስተኑጥሁ ውሉደክሙ ከመ ኢይኅዝኑ ። | ወላጆችም ልጆቻችሁን አታበሳጩ እንዳያዝኑ ። |
| ፳፪ | ነባሪኒ ተአዘዙ ለአጋእዝቲክሙ በስፉሕ ልብ ፤ ወአኮ በአድልዎ ለገጸ ሰብእ ፤ አላ በፍርሃተ እግዚአብሔር ። | አገልጋዮችም ለጌቶቻችሁ በሰፊ ልብ ታዘዙ ፤ እግዚአብሔርን በመፍራት እንጂ ለሰው ይምሰል አይሁን ። |
