## ምዕራፍ ፩

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፩ ፡ በእንተ ሢመተ ክህነት ።** | **ክፍል ፩ ፡ ካህናትን ስለ መሾም ።** |
| ፩ | እምጳውሎስ ገብሩ ለእግዚአብሔር ወሐዋርያሁ ለኢየሱስ ክርስቶስ በሃይማኖቶሙ ለኅሩያኒሁ ለእግዚአብሔር ወአእምሮ ጽድቅ ዘበጽድቁ ለእግዚአብሔር ። | እግዚአብሔር በመረጣቸው በምእመናን እምነት በእግዚአብሔር ቸርነት የተገለጠችውን እውነት በማስተማር የእግዚአብሔር አገልጋይ የኢየሱስ ክርስቶስ ሐዋርያ ከሆነው ከጳውሎስ ። |
| ፪ | ወበተስፋ ሕይወት ዘለዓለም ዘአስፈወ እግዚአብሔር ዘኢይሔሱ እምፍጥረተ ዓለም ። | ዓለም ከተፈጠረ ጀምሮ የተናገረውን የማያስቀር እግዚአብሔር በሰጠው በዘለዓለም ሕይወት አለኝታ ፤ |
| ፫ | ወአርአየ ቃሎ በዕድሜሁ በስብከተ ዚአነ ኪያሁ ወተአመነኒ ሊተ ላዕሌሁ በትእዛዘ እግዚአብሔር መድኃኒነ ። | እኛ እርሱን በማስተማራችን በጊዜው ጊዜ ቃሉን የገለጠ በመድኃኒታችን በእግዚአብሔር ትእዛዝም በሕጉ ላይ ከተማመነኝ ከእኔ የተላከ መልእክት ፤ |
| ፬ | ለቲቶ ወልድየ ዘአፈቅር በተፋቅሮ ወበሃይማኖት ፤ ሰላም ለከ ወጸጋ ወሣህል እምኀበ እግዚአብሔር አቡነ ወእግዚእነ ኢየሱስ ክርስቶስ መድኃኒነ ። | በፍቅር በሃይማኖት ለምወድህ ልጄ ለቲቶ ይድረስ ፤ ሰላም ላንተ ይሁን ፤ ጸጋና ይቅርታ ከአባታችን ከእግዚአብሔር ከጌታችን ከኢየሱስ ክርስቶስ ይደረግልህ ። |
| ፭ | እስመ እንበይነ ዝንቱ ኀደግኩከ ውስተ ቀርጤስ ከመ ታስተራትዕ ዘተርፈ ፤ ወትሢም ቀሲሳነ ለለአህጉር በከመ አዘዝኩከ ። | ስለዚህ የቀረውን እንድታስተካክል ቀሳውስትንም እንደ አዘዝኩህ በየአገሩ እንድትሾም በቀርጤስ ትቼሃለሁና ። |
| ፮ | ብእሴ ዘአሐተ ብእሲተ አውሰበ ኅሩየ ዘኢየሐምይዎ በእኩይ ዘቦ ውሉድ መሃይምናን ፤ ዘኢያስተዋድይዎሙ በምርዓት እለ ኢኮኑ ዝሉፋነ እለ ይትኤዘዙ ። | የተመረጠ አንዲት ሚስት ያገባ በክፉ ነገር ሰዎች የማያሙት በመዳራት የማያሳጧቸው ወራዶች ያልሆኑ ታዛዦች ታማኞች የሆኑ ልጆች ያሉትን ሰው ሹም ። |
| ፯ | ወርቱዕ ይሠየም ጳጳስ ዘአልቦ ሐሜት ዘኢያደሉ ከመ መጋቤ እግዚአብሔር ፤ ዘኢኮነ መዓትመ ዘልቡብ ዘኢያበዝኅ ሰትየ ወይን ወኢያፈጥን እዴሁ ለዘቢጥ ፤ ዘኢደፋር ወኢዝጉር ወዘኢያፈቅር ንዋየ ከንቶ ። | የማይታማ የእግዚአብሔር መጋቢ እንደ መሆኑ እንደማያደላ ቁጡ ያይደለ አስተዋይ ፤ ወይን አብዝቶ የማይጠጣ ለመማታት እጁን የማይቃጣ ሰውን የማይደፍር የማይኩራ ከንቱ ገንዘብን የማይወድ ፤ |
| ፰ | መፍቀሬ ነግድ ዘሠናይ ምግባሩ ዘአንጽሐ ርእሶ ፤ ጻድቅ ወኄር ወየዋህ ወመስተዐግሥ ዘያነሐሲ ዘምሁር ቃለ ሃይማኖት ። | እንግዳን የሚወድ ምግባሩ ያማረ ራሱን ንጹሕ ያደረገ እውነተኛ ቸር ቅን ታጋሽ ይቅር ባይ የሃይማኖትን ነገር የተማረ ፤ |
| ፱ | ዘይክል ገሥጾ በትምህርተ ሕይወት ወይዛለፎሙ ለእለ ይትዋሥኡ ። | ሕይወት በሚገኝበት ትምህርት ማስተማር የሚቻለው ለሚከራከሩት መልስ የሚሰጥ ይሾም ። |
| ፲ | እስመ ብዙኃን እለ ኢይትኤዘዙ ወነገሮሙኒ ከንቱ ፤ ወያስሕትዎሙ ለጽሉላነ ልብ ። | የማይታዘዙ ብዙዎች ናቸውና ነገራቸውም ከንቱ ነውና ፤ ልበ ደንዳኖችን ያስቷቸዋልና ፤ |
| ፲፩ | ወፈድፋደሰ ለእለ እምአይሁድ እለ ርቱዕ ይፍጽምዎሙ አፉሆሙ ፤ እስመ እሉ ይገፈትዑ አብያተ ኵሉ ወይሜህሩ በዘኢይደሉ በዘይረብሖሙ ኀሣር ። | ይልቁንም ምላሽ ሊያሳጧቸው ከሚገባ ከአይሁድ ወገን የሆኑትን ተከራክሮ የሚረታ ፤ እነዚህ የሰውን ሁሉ ልቡና ይለዋውጣሉና ፤ ኀሣር በሚበዛባቸው ገንዘብ የማይገባውን ያስተምራሉና ። |
| ፲፪ | ወናሁ ይቤ አሐዱ እምኔሆሙ ነቢዮሙ በእንቲአሆሙ ፤ እስመ ሰብአ ቀርጤስ መደልዋን ሐሳውያን ዘልፈ አራዊት እኩያን ከርሠ መካን ። | እነሆ ከእነሱም አንዱ ነቢያቸው ስለ እነሱ እንዲህ ብሏል ፤ የቀርጤስ ሰዎች እኮ ግብዞች ዘወትር የሚዋሹ ክፉዎች አውሬዎች የመኻን ሆድ ናቸው ብሏል ። |
| ፲፫ | ወዝንቱ ስምዕ እሙን ላዕሌሆሙ ፤ ወበእንተ ዝንቱ ተዛለፎሙ ምቱረ ከመ ይጠይቁ በሃይማኖት ። | ይህ በእነሱ ላይ የታመነ ምስክር ነው ፤ ስለዚህም ሃይማኖትን ይረዱ ዘንድ ቍርጥ አድርገህ ተከራከራቸው ። |
| ፲፬ | ወኢያምጽኡ መኃድምተ ወሥርዓተ ሰብእ ዘይመይጣ ለጽድቅ ። | እውነትን የሚለውጣት ተረትንና ሰው ሠራሽ ሥርዓትን እንዳያመጡ ። |
| ፲፭ | እስመ ኵሉ ዘኮነ ንጹሕ ለንጹሐን ፤ ወለርኩሳንሰ እለ ኢየአምኑ አልቦ ንጹሕ ምንትኒ ። | የተፈጠረው ሁሉ ለንጹሐን ንጹሕ ነው ፤ ለማያምኑ ለርኩሳን ግን ምንም ንጹሕ የላቸውም ። |
| ፲፮ | እስመ ርኩስ ሕሊናሆሙ ወበልቦሙ የአምኑ ከመ ዘየአምርዎ ለእግዚአብሔር ፤ ወይክሕድዎ በምግባሮሙ ፤ ርኩሳን እሙንቱ ወክሑዳን ወምኑናን ውስተ ኵሉ ምግባረ ሠናይ ። | ሐሳባቸው ርኩስ ነውና በልባቸው እግዚአብሔርን እንደሚያውቁት አድርገው ያምናሉ ፤ በሥራቸው ግን ይክዱታል ፤ ርኩሳን ናቸው ከሐዲዎችም ናቸው ፤ በበጎውም ሥራ ሁሉ የተናቁ ናቸው ። |

## ምዕራፍ ፪

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፪ ፡ ዘከመ ይደሉ አክብሮ ዐቢያን እምንኡሳን ።** | **ክፍል ፪ ፡ ታናናሾች ታላላቆችን ማክበር እንዲገባ ።** |
