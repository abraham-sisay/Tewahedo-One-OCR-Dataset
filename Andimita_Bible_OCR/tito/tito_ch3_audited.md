## ምዕራፍ ፫

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፬ ፡ ዘከመ ይደሉ ገሥጾ ።** | **ክፍል ፬ ፡ መምከር ስለሚገባ ።** |
| ፩ | ዘክሮሙ ለሊቃናት ወለመኳንንት ከመ ይትአዘዙ በኵሉ ምግባረ ሠናይ ፤ ወይኩኑ ጥቡዓነ ። | ሽማግሌዎችን መኳንንቱን በበጎ ምግባር ይታዘዙ ዘንድ ፤ በዚያውም ፀንተው ይኖሩ ዘንድ አሳስባቸው ። |
| ፪ | ወኢይትቄጥዑ ወኢይትገአዙ አላ መሐርያነ ወየውሃነ ይኩኑ ምስለ ኵሉ ሰብእ ። | ከሰው ሁሉ ጋር ርኅሩኃን የዋሃን ይሁኑ እንጂ ፤ አይቆጡ አይጣሉ ። |
| ፫ | እስመ ንሕነሂ ትካት ዐበድነ ዘእንበለ አእምሮ ወክሕድነ ወስሕትነ ወተቀነይነ ለፍትወተ ስሒት ወለሐውዝ ዘዘዚአሁ ፤ ወተለውነ እኩየ ወተቃንኦ ወአዕሠምነ ወጸላእነ ቢጸነ ። | እኛም እኮ ቀድሞ ባለማወቅ ሰንፈን ክደን ስተን ነበር ፤ ለፍትወት ተገዝተን ነበር ፤ ልዩ ልዩ ለሚሆን ተድላ ደስታ ተገዝተን ነበር ፤ ክፋትን መቀናናትን ተከትለን ነበር ፤ ወንድሞቻችንን ጠልተን አሳዝነን ነበር ። |
| ፬ | ወአመ አስተተርአየ ምሕረቱ ለእግዚአብሔር መፍቀሬ ሰብእ መድኃኒነ ። | ሰው ወዳጅ የሚሆን የመድኃኒታችን የእግዚአብሔር ቸርነቱ በተገለጠ ጊዜ ፤ |
| ፭ | ወአኮ በምግባረ ጽድቅነ ዳእሙ በምሕረቱ አድኅነነ ፤ በጥምቀተ ዳግም ልደት ወተሐድሶ በመንፈስ ቅዱስ ። | ጽድቅ በመሥራታችን አይደለም ፤ በቸርነቱ ዳግም ልደትን በሚያሰጥ በመንፈስ ቅዱስ በመታደስ አዳነን እንጂ ፤ |
| ፮ | ዘከዐወ ላዕሌነ በብዕሉ በእንተ ኢየሱስ ክርስቶስ መድኃኒነ ። | መድኃኒታችን ኢየሱስ ክርስቶስ ስለ ከፈለልን በቸርነቱ በእኛ ላይ ባሳደረው ፤ |
| ፯ | ከመ ንጽደቅ በጸጋሁ ወንረስ ተስፋ ሕይወት ዘለዓለም ። | በቸርነቱ ከብረን የዘለዓለም የመኖርን ተስፋ እንወርስ ዘንድ ። |
| ፰ | እሙን ነገር ወበእንተዝ እፈቅድ አነሂ ታጽንዖሙ ከመ የሐልዩ ተራድኦ በኵሉ ምግባረ ሠናይ ፤ እለ ተአመኑ በእግዚአብሔር ዝኩ ሠናይ ዘይበቍዕ ለሰብእ ። | ነገሩ እውነት ነው ፤ ስለዚህም በእግዚአብሔር ያመኑት በበጎ ምግባር ሁሉ መረዳዳትን ያስቡ ዘንድ እንድታጸናቸው እወዳለሁ ፤ ለሰው የሚጠቅመው በጎ ነገር ይህ ነው ። |
| ፱ | ነገረ ጋእዝ ወዕበድ ዘይፈጥሩ ወመኃድምተ ወወክሐ ተገኃሥ እስመ ከንቱ ውእቱ ወኢይበቍዕ ። | ፈጥረው የሚናገሩትን የጠብንና የስንፍናን ነገር ፤ የተረትን ነገር የዋዛ ፈዛዛን ነገር የሚናገሩትን ተለያቸው ፤ ከንቱ ነውና አይጠቅምምና ። |
| ፲ | ለመስተካሕድ ብእሲ እምከመ ምዕረ ወካዕበ ገሠጽኮ ወአበየ ኅድጎ ። | ተከራካሪውን ሰው አንድ ጊዜ ሁለት ጊዜ ከመከርከው በኋላ እምቢ ካለ ተወው ። |
| ፲፩ | ወአእምሮ ከመ ዐላዊ ውእቱ ዘከማሁ ያስሕት ወያንጌጊ ወይረክብ ኵነኔ ። | እንደ እርሱ ያለውን የሚያስትና የሚያስክድ ወንጀለኛ እንደ ሆነ አስታውቅበት ፤ ቅጣቱን ይቀበላል ። |
| ፲፪ | ወእምከመ ፈነውክዎ ለአርጢሞስ ኀቤከ አው ጢኪቆስ ፍጡነ ንዓ ኀቤየ ሀገረ ኒቆጵልዮስ እስመ አጥባዕኩ እክርም ህየ ። | አርጢሞንን ወደ እናንተ የላክሁት እንደ ሆነ ወይም ጢኪቆስን ፤ ፈጥነህ ወደ እኔ ወደ ኒቆጵልዮስ አገር ና ፤ በዚያ ልከርም ወስኛለሁና ። |
| ፲፫ | ለዜናስ ጸሐፌ ሀገር ወለአጵሎስ ጽሑቀ አክብሮሙ ኢይጽነሱ ምንተኒ ። | አገር አሳዳሪ ዜናስንና አጵሎስን በምንም በምን እንዳይቸገሩ በጣም አክብራቸው ። |
| ፲፬ | ወእሊአነሂ ይትመሀሩ ምግባረ ሠናየ በዘይቀውሙ ውስተ ዘይትፈቀድ ግብር ከመ ኢይዕጥኡ ፍሬ ። | ወገኖቻችንም ፍሬ እንዳያጡ በሚፈለገው ሥራ ፀንተው እንዲገኙ በጎውን ምግባር ይማሩ ። |
| ፲፭ | ይኤምጉከ ኵሎሙ እለ ምስሌየ ፤ አምኅ ኵሎ ዘያፈቅረነ በሃይማኖት ፤ ጸጋ የሃሉ ምስለ ኵልክሙ ፤ አሜን ። | ከእኔ ጋር ያሉት ሁሉ እንዴት ነህ ብለውሃል ፤ በሃይማኖት የሚወደንን ሁሉ ሰላም በል ፤ ጸጋ ለሁላችሁ ይሁን ፤ አሜን ። |

## መደምደሚያ (Colophon)

| ክፍል | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **መደምደሚያ** | **ተፈጸመት መልእክት ኀበ ቲቶ ወተጽሕፈት በሀገረ ኒቆጵልዮስ ወተፈነወት ምስለ አርጣማ ረድኡ ፤ ወስብሐት ለእግዚአብሔር ፤ አሜን ።** | **በኒቆጵልዮስ ተጽፋ በደቀ መዝሙሩ በአርጣማ እጅ ወደ ቲቶ የተላከችው መልእክት ተፈጸመች ። ለእግዚአብሔር ምስጋና ይሁን ፤ አሜን ።** |
