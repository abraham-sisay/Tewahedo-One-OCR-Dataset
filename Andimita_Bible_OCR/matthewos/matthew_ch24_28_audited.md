### ክፍል ፻፫ ፤ በእንተ ዐሥሩ ደናግል (ስለ ዐሥሩ ደናግል ምሳሌ) — ቍጥር ፩–፲፫

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :---: | :--- | :--- |
| **፩** | አሜሃ ትመስል መንግሥተ ሰማያት ዐሥረ ደናግለ እለ ነሥአ ማኀቶቶን ወወፅአ ይትቀበላ መርዓዌ። | በዚያን ጊዜ መንግሥተ ሰማያት መብራታቸውን ይዘው ሙሽራውን ሊቀበሉ የወጡ አሥር ቆነጃጅትን ትመስላለች። |
| **፪** | ወኀምስ እምኔሆን ሰነፋት፤ ወኀምስሰ ጠቢባት። | ከእነርሱም አምስቱ ሰነፎች አምስቱም ልባሞች ነበሩ። |
| **፫** | እለሰ ሰነፋት ነሥአ ማኀቶቶን ወኢነሥአ ቅብአ ምስሌሆን። | ሰነፎቹ መብራታቸውን ይዘው ከእነርሱ ጋር ዘይት አልያዙምና፤ |
| **፬** | ወጠቢባትሰ ነሥአ ቅብአ ውስተ አቅማሒሆን ምስለ ማኀቶቶን። | ልባሞቹ ግን ከመብራታቸው ጋር በማሰሮአቸው ዘይት ያዙ። |
| **፭** | ወእንዘ ይጐነዲ መርዓዊ ኖማ ኵሎን ወኖማ። | ሙሽራውም በዘገየ ጊዜ ሁላቸው አንቀላፉና ተኙ። |
| **፮** | ወበመንፈቀ ሌሊት ኮነ ገዓር ናሁ መርዓዊ ይመጽእ ፃኡ ተቀበልዎ። | እኩለ ሌሊትም በሆነ ጊዜ፦ እነሆ ሙሽራው ይመጣል ልትቀበሉት ውጡ የሚል ጩኸት ሆነ። |
| **፯** | አሜሃ ተንሥአ ኵሎን እማንቱ ደናግል ወአስተዳለዋ ማኀቶቶን። | በዚያን ጊዜ እነዚያ ቆነጃጅት ሁሉ ተነሡና መብራታቸውን አዘጋጁ። |
| **፰** | ወይቤላሆን ሰነፋት ለጠቢባት፤ ሀባነ እምቅብእክን እስመ ጠፍአ ማኀቶትነ። | ሰነፎቹም ልባሞቹን፦ መብራታችን ሊጠፋብን ነውና ከዘይታችሁ ስጡን አሉአቸው። |
| **፱** | ወአውሥአ ጠቢባት ወይቤላሆን፤ ቦኑ ዘየአክለነ ለነ ወለክን፤ ሑራ ይኄይስክን ኀበ እለ ይሠይጡ ወተሣየጣ ለክን። | ልባሞቹ ግን መልሰው፦ ምናልባት ለእኛና ለእናንተ ባይበቃስ፤ ይልቅስ ወደሚሸጡት ሂዱና ለራሳችሁ ግዙ አሉአቸው። |
| **፲** | ወእንዘ የሐውራ ይሣየጣ መጽአ መርዓዊ፤ ወደለዋት ቦአ ምስሌሁ ውስተ ከብካብ፤ ወተዐፅወ ኆኅት። | ሊገዙም በሄዱ ጊዜ ሙሽራው መጣ፤ ተዘጋጅተው የነበሩትም ከእርሱ ጋር ወደ ሰርግ ገቡ፤ ደጁም ተዘጋ። |
| **፲፩** | ወእምድኅረዝ መጽአ እማንቱኒ ካልአት ደናግል እንዘ ይብላ፤ እግዚኦ እግዚኦ ክሥት ለነ። | በኋላም ደግሞ የቀሩቱ ቆነጃጅት መጥተው፦ ጌታ ሆይ ጌታ ሆይ ክፈትልን አሉፉ። |
| **፲፪** | ወአውሥአ ወይቤላሆን፤ አማን እብለክን ኢየአምረክን። | እርሱ ግን መልሶ፦ እውነት እላችኋለሁ አላውቃችሁም አላቸው። |
| **፲፫** | ትንሥሁ እንከ እስመ ኢተአምሩ ዕለተ ወኢሰዓተ እንተ ባቲ ይመጽእ ወልደ እጓለ እመሕያው። | እንግዲህ የሰው ልጅ የሚመጣባትን ያችን ቀንና ያችን ሰዓት አታውቁምና ንቁ። |

### ክፍል ፻፬ ፤ ምሳሌ በእንተ መካልይ (ስለ መክሊቶች ምሳሌ) — ቍጥር ፲፬–፴

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :---: | :--- | :--- |
| **፲፬** | እስመ ከመ ብእሲ ዘየሐውር ብሔረ ነኪር፤ ጸውዖሙ ለአግብርቲሁ ወአግብአ ሎሙ ንዋዮ። | ወደ ሌላ አገር የሚሄድ ሰው ባሮቹን ጠርቶ ያለውን ገንዘብ እንደ ሰጣቸው እንዲሁ ይሆናልና፤ |
| **፲፭** | ወለአሐዱ ወሀበ ኀምስተ መክሊተ፤ ወለአሐዱ ክልኤተ፤ ወለአሐዱ አሐደ፤ ለለአሐዱ በበኃይሉ ወሖረ ሶቤሃ። | ለእያንዳንዱ እንደ ችሎታው ለአንዱ አምስት መክሊት ለአንዱ ሁለት ለአንዱም አንድ ሰጠና ወዲያው መንገዱን ሄደ። |
| **፲፮** | ወሖረ ውእቱ ዘነሥአ ኀምስተ መክሊተ ወነገደ ቦቱ ወረብሐ ካልአ ኀምስተ መክሊተ። | አምስት መክሊት የተቀበለውም ሄዶ ነገደበት ሌላም አምስት መክሊት አተረፈ፤ |
| **፲፯** | ወከማሁ ዘሂ ክልኤተ ነሥአ ረብሐ ካልአ ክልኤተ። | እንዲሁም ደግሞ ሁለቱን የተቀበለው ሌላ ሁለት አተረፈ። |
| **፲፰** | ወዘሰ አሐደ ነሥአ ሖረ ወኰዐወ ምድረ ወኀብአ ብሩረ እግዚኡ። | አንዱን የተቀበለው ግን ሄዶ ምድርን ቆፈረና የጌታውን ገንዘብ ሸሸገ። |
| **፲፱** | ወእምድኅረ ብዙኅ መዋዕል መጽአ እግዚኦሙ ለእለኩ አግብርት ወተኌለቆሙ። | ከብዙ ዘመንም በኋላ የእነዚያ ባሮች ጌታ መጣና ተቆጣጠራቸው። |
| **፳** | ወቀርበ ውእቱ ዘነሥአ ኀምስተ መክሊተ ወአምጽአ ካልአ ኀምስተ መክሊተ እንዘ ይብል፤ እግዚኦ ኀምስተ መክሊተ ወሀብከኒ፤ ናሁ ካልአ ኀምስተ መክሊተ ረባሕኩ ዲቤሁ። | አምስት መክሊት የተቀበለውም ቀረበና ሌላ አምስት መክሊት አምጥቶ፦ ጌታ ሆይ አምስት መክሊት ሰጥተኸኝ ነበር፤ እነሆ ሌላ አምስት መክሊት አተረፍሁበት አለ። |
| **፳፩** | ወይቤሎ እግዚኡ ሕያውከ ገብር ኄር ወምእመን፤ በኅዳጥ ተአመንከ ዲበ ብዙኅ እሠይመከ፤ ባእ ውስተ ፍሥሓሁ ለእግዚእከ። | ጌታውም፦ መልካም አንተ በጎ ታማኝም ባሪያ በጥቂቱ ታምነሃል በብዙ እሾምሃለሁ፤ ወደ ጌታህ ደስታ ግባ አለው። |
| **፳፪** | ወቀርበ ውእቱኒ ዘነሥአ ክልኤተ መክሊተ ወይቤ፤ እግዚኦ ክልኤተ መክሊተ ወሀብከኒ፤ ናሁ ካልአ ክልኤተ መክሊተ ረባሕኩ ዲቤሁ። | ሁለት መክሊት የተቀበለውም ቀረበና፦ ጌታ ሆይ ሁለት መክሊት ሰጥተኸኝ ነበር፤ እነሆ ሌላ ሁለት መክሊት አተረፍሁበት አለ። |
| **፳፫** | ወይቤሎ እግዚኡ ሕያውከ ገብር ኄር ወምእመን፤ በኅዳጥ ተአመንከ ዲበ ብዙኅ እሠይመከ፤ ባእ ውስተ ፍሥሓሁ ለእግዚእከ። | ጌታውም፦ መልካም አንተ በጎ ታማኝም ባሪያ በጥቂቱ ታምነሃል በብዙ እሾምሃለሁ፤ ወደ ጌታህ ደስታ ግባ አለው። |
| **፳፬** | ወቀርበ ውእቱኒ ዘነሥአ አሐደ መክሊተ ወይቤ፤ እግዚኦ አእመርኩከ ከመ ብእሲ መዓሪር አንተ፤ ታእርር እምኀበ ኢዘራዕከ ወታስተጋብእ እምኀበ ኢዘረውከ። | አንድ መክሊት የተቀበለውም ደግሞ ቀርቦ እንዲህ አለ፦ ጌታ ሆይ ካልዘራህበት የምታጭድ ካልበተንህበትም የምትሰበስብ ጨካኝ ሰው መሆንህን አውቃለሁ፤ |
