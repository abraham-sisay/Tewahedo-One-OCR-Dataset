| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፳ ፡ በእንተ ጽድቀ ሃይማኖት ።** | **ክፍል ፳ ፡ በሃይማኖት ስለሚገኘው ክብር ።** |
| **፩** | ጽደቁ እንከ በአሚን ወንርከብ ሰላመ በኀበ እግዚአብሔር በእግዚእነ ኢየሱስ ክርስቶስ ። | እንግዲህ በሃይማኖት ክበሩ ፤ በእግዚአብሔር ዘንድም በጌታችን በኢየሱስ ክርስቶስ ሰጪነት ዕርቅን እናግኝ ። |
| **፪** | ዘበእንቲአሁ ተመራሕነ በሃይማኖት ውስተ ዛቲ ጸጋሁ እንተ ባቲ ቆምነ ወውእቱ ምክሕነ ወባቲ ንሴፎ ስብሐተ እግዚአብሔር ። | ቤዛ ስለ ሆነ በሃይማኖት ወደ ጸናንባት ወደዚች ወደ ልጅነት የደረስንበት መመኪያችንም እርሱ ነው ፤ በልጅነት እግዚአብሔር የሚሰጠንን ክብር ተስፋ እናደርጋለን ። |
| **፫** | ወአኮ በባሕቲታ ዓዲ ንትሜክሕ በሕማምነሂ እስመ ነአምር ከመ ሕማም ይፌጽም ትዕግሥተ ላዕሌነ ። | የምንመካ በልጅነት ብቻ አይደለም በመከራችንም ደግሞ እንመካለን እንጂ ፤ መከራ በእኛ ላይ ትዕግሥትን ፍጹም እንደሚያደርገው እናውቃለንና ። |
| **፬** | ወትዕግሥትሰ መከራ ወበመከራ ይትረከብ ተስፋ ። | ትዕግሥት ፈተና ነው በፈተናም ተስፋ ይገኛል ። |
| **፭** | ወተስፋኒ ኢያስተኀፍር እስመ ፍቅረ እግዚአብሔር መልአ ውስተ ልብነ በመንፈስ ቅዱስ ዘወሀበነ ። | ተስፋም አያሳፍርም በሰጠን በመንፈስ ቅዱስ የእግዚአብሔር ፍቅር በልቡናችን መልቶአልና ። |
| **አርእስት** | **ክፍል ፳፩ ፡ በእንተ ምጽአተ ክርስቶስ ።** | **ክፍል ፳፩ ፡ ስለ ክርስቶስ መምጣት ።** |
| **፮** | ክርስቶስኒ መጽአ በዕድሜሁ ይሙት በእንተ ኃጢአትነ እንዘ ኃጥአን ንሕነ ። | እኛ ኃጢአተኞች ስንሆን በኃጢአታችን ምክንያት ይሞት ዘንድ ክርስቶስ በቀጠሮው መጣ ። |
| **፯** | በእንተ እኩያንሰ እምዕፁብ ጥቀ ኢይትረከብ ዘይትሀበል ይሙት ፤ ወእንበይነ ኄራንሰ እንዳዒ እንጋ ለእመ ዘይትረከብ ዘያጠብዕ ይሙት ። | ስለ ክፉዎችማ ሊሞት የሚደፍር በጭንቅ እንኳ ቢሆን የሚሞት አይገኝም ፤ ስለ ደጋጎቹ ሰዎች ሊሞት የሚደፍር እንዳለ እንጃ ። |
| **፰** | ናሁ ርእዩ መጠነ አፍቀረነ እግዚአብሔር እንዘ ኃጥአን ንሕነ ክርስቶስ ሞተ በእንቲአነ ። | አሁን እግዚአብሔር እንደ ወደደን እነሆ እዩ ፤ እኛ ኃጢአተኞች ስንሆን ክርስቶስ ስለ እኛ ሞተ ። |
| **፱** | እፎ እንከ ፈድፋደ ለእመ ጸደቅነ ያነጽሐነ በደሙ ወያድኅነነ እመንሱት ዘይመጽእ ። | ጸድቀን ከሆንማ እንዴት በደሙ እጅግ ያነጻን ! ከሚመጣው መከራስ እንደ ምን ያድነን ይሆን ? ። |
| **፲** | ወሶበ እንዘ ፀሩ ንሕነ ለእግዚአብሔር ተሠሃለነ በሞተ ወልዱ እፎ እንከ ይሠሀለነ ፈድፋደ ወእምከመ ተዐረቀነ ወተሠሀለነ ያሕይወነ በሕይወተ ወልዱ ። | እኛ የእግዚአብሔር ጠላቶቹ ስንሆን በልጁ ሞት ይቅር ካለን እንደ ምን እጅግ ይቅር ይለን ይሆን ? ይቅር ብሎ ከታረቀንም በልጁ ሕይወትነት ያድነናል ። |
| **፲፩** | አኮ በእንተ ዝንቱ ባሕቲቱ ዓዲ ንትሜካሕ በኀበ እግዚአብሔር በእንተ እግዚእነ ኢየሱስ ክርስቶስ ዘበእንቲአሁ ረከብነ ሣህሎ ። | በዚህ ብቻ አይደለም ስለ ቤዛነቱ ይቅርታውን ባገኘንበት በጌታችን በኢየሱስ ክርስቶስም በእግዚአብሔር ዘንድ እንመካለን እንጂ ። |
| **አርእስት** | **ክፍል ፳፪ ፡ በእንተ ኃጢአት ዘቦአት ውስተ ዓለም ።** | **ክፍል ፳፪ ፡ ወደ ዓለም ስለ ገባችው ኃጢአት ።** |
| **፲፪** | ወበእንተዝ ከመ በጌጋየ አሐዱ ብእሲ ቦአት ኃጢአት ውስተ ዓለም በእንተ ይእቲ ኃጢአት መጽአ ሞት ላዕለ ኵሉ ሰብእ ወተኌለቈት ኃጢአት ላዕለ ኵሉ ። | ስለዚህም በአንድ ሰው በደል ምክንያት ኃጢአት ወደ ዓለም እንደ ገባች ስለዚችም ኃጢአት በሰው ሁሉ ላይ ሞት መጣ ፤ ኃጢአት በሁሉ ላይ ተቈጠረች ። |
| **፲፫** | እስከ አመ መጽአት ኦሪት ሀለወት ኃጢአት ውስተ ዓለም እንዘ ኢትትዐወቅ ምንት ይእቲ እስመ ኢትትኋለቅ ኃጢአት እስመ ዓዲሁ ኢመጽአ ውእተ አሚረ ሕገጋ ለኦሪት ። | ኦሪት እስከ መጣች ድረስ ኃጢአት ምን እንደ ሆነች ሳትታወቅ በዓለም ውስጥ ነበረች ፤ ኃጢአት ምን እንደ ሆነች አትቈጠርም ነበርና ያን ጊዜ የኦሪት ሕግ ገና አልመጣም ነበርና ። |
| **፲፬** | ወባሕቱ ኵነኖሙ ሞት እምአዳም እስከ ሙሴ ለእለሂ አበሱ ወለእለሂ ኢአበሱ በእንተ ይእቲ ኃጢአቱ ለአዳም እስመ ኵሉ በአምሳለ አዳም ተፈጥረ እስመ አዳም አምሳሉ ውእቱ ለዘሀለዎ ይምጻእ ። | በዚች በአዳም ኃጢአት ምክንያት ከአዳም እስከ ሙሴ የበደሉትንም ያልበደሉትንም ሞት ገዛቸው ፤ ሁሉ በአዳም መልክ ተፈጥሮአልና አዳም ይመጣ ዘንድ ላለው አምሳሉ ነውና ። |
| **፲፭** | ወባሕቱ አኮ በአምጣነ ጌጋይነ ዘኮነነ ሐሳበ ጸጋሁ ለእግዚአብሔር ወሶበ በጌጋየ አሐዱ ብእሲ ሞቱ ብዙኃን እፎ እንከ ፈድፋደ በጸጋሁ ለእግዚአብሔር ወበሀብቱ ዘጸገወነ በእንተ አሐዱ ብእሲ ዘውእቱ ኢየሱስ ክርስቶስ ይፈደፍድ ሕይወት ላዕለ ብዙኃን ። | ነገር ግን የእግዚአብሔር ጸጋው በበደላችን መጠን የሆነብን አይደለም ፤ በአንድ ሰው በደል ብዙዎቹ ከሞቱ በእግዚአብሔር ጸጋ በአንዱ ሰው በኢየሱስ ክርስቶስ ቤዛነት በሰጠን ሀብቱ በብዙዎች ላይ እንዴት ሕይወት ይበዛ ይሆን ! ። |

| **፴፰** | እትአመን ባሕቱ ከመ አልቦ ዘያኀድገነ ፍቅሮ ለእግዚአብሔር በኢየሱስ ክርስቶስ እግዚእነ ፤ ኢሞት ፤ ወኢሕይወት ፤ ኢመላእክት ፤ ወኢቀደምት ፤ ኢዘሀሎ ፤ ወኢዘይመጽእ ። | ሞት ቢሆን ፤ ሕይወትም ቢሆን ፤ መላእክትም ቢሆኑ ፤ ግዛትም ቢሆን ፤ ያለውም ቢሆን ፤ የሚመጣውም ቢሆን ፤ ሥልጣናትም ቢሆኑ ፤ |
