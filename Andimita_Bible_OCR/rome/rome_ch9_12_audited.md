| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፴ወ፯ ፡ በእንተ ልደቱ ለክርስቶስ እምአበው ።** | **ክፍል ፴ወ፯ ፡ ክርስቶስ ከአበው ስለ መወለዱ ።** |
| **፩** | አማነ እብለክሙ በእንተ ክርስቶስ ወኢይሔሱ ወሰማዕትየ መንፈስ ቅዱስ ዘውስተ ልብየ ። | ስለ ክርስቶስ እውነቱን እነግራችኋለሁ ሐሰት አልናገርም ፤ ምስክሬም በልቡናዬ አድሮ ያለ መንፈስ ቅዱስ ነው ። |
| **፪** | ከመ እቴክዝ ወአሐምም በልብየ ፈድፋደ በኵሉ ጊዜ ። | በጊዜው ሁሉ ፈጽሜ በልቤ እንደማዝን እንደምጨነቅ ። |
| **፫** | ወእጼሊ ከመ አነ እትፈለል እምክርስቶስ በእንተ አኀውየ ወአዝማድየ እለ በሥጋ ። | በሥጋ ዘመዶቼ ወንድሞቼ ስለሚሆኑ ሰዎች ከክርስቶስ ልለይ እጸልያለሁ ። |
| **፬** | እሉ እሙንቱ እስራኤል እስራኤላውያን እለ ሎሙ ትርሚተ ወልድ ወሎሙ ክብር ፤ ወሎሙ ሥርዓት ፤ ወሎሙ ሕግ ፤ ወሎሙ አሰፈወ ። | እነዚህም እስራኤል ተብለው የሚጠሩት የእስራኤል ወገኖች ናቸው ፤ የልጅነት ክብር ያላቸው ፤ ክብር ያላቸው ፤ ሥርዓት ያላቸው ፤ ሕግ ያላቸው ፤ ተስፋ የተሰጣቸው ። |
| **፭** | ወእሙንቱ አበዊነ ወእምላዕሌሆሙ ተወልደ ክርስቶስ በሥጋ ሰብእ ዘውእቱ አምላክ ቡሩክ ለዓለመ ዓለም አሜን ። | እነርሱም አባቶቻችን ናቸው ፤ ክርስቶስ በሥጋ ከእነርሱ ተወለደ ፤ ይኸውም ለዘለዓለም ምስጋና የሚገባው አምላክ ነው በእውነት አሜን ። |
| **፮** | አኮኑ ኢተሐሰወ ቃለ እግዚአብሔር ወአኮ ኵሎሙ እስራኤል እስራኤላውያን ። | የእግዚአብሔር ቃል አልታበለምና ፤ እስራኤል ሁሉ እስራኤላውያን አይደሉም ። |
| **አርእስት** | **ክፍል ፴ወ፰ ፡ በእንተ ተሰምዮ ዘርአ አብርሃም ።** | **ክፍል ፴ወ፰ ፡ የአብርሃም ልጅ ስለ መባል ።** |
| **፯** | ወአኮ ኵሎሙ ዘርአ አብርሃም ዘኮንዎ ውሉደ እምይስሐቅ ዳእሙ ይሰመይ ለከ ዘርእ ይቤሎ ። | ግን የአብርሃም ልጆች ሁሉ ልጆቹ የሆኑ አይደለም ፤ «ከይስሐቅ ዘር ይጠራልሃል» አለው እንጂ ። |
| **፰** | እስመ አኮ ውሉደ ሥጋ እሙንቱ አላ ውሉደ እግዚአብሔር እለ ይከውንዎ ዘርአ እለ አሰፈወ ይኩንዎ ውሉደ ። | እነርሱ ሥጋውያን ልጆች አይደሉምና ፤ ልጆች እንዲሆኑት ተስፋ ያናገረለት የእግዚአብሔር ልጆች ናቸው እንጂ ። |
| **፱** | እስመ አሰፈዎ ወይቤሎ ዓመ ከመ ዮም አገብእ ኀቤከ ወትረክብ ሣራ ወልደ ። | «ከርሞ እንደ ዛሬ ወዳንተ እመለሳለሁ ፤ ሣራም ወንድ ልጅ ታገኛለች» ብሎ ተስፋውን እንደ ነገረው ። |
| **፲** | ወአኮ ባሕቲታ ዓዲ ርብቃኒ ፀንሰት መንታ ለይስሐቅ አቡነ ። | ሣራ ብቻ አይደለችም ፤ ርብቃም ለአባታችን ለይስሐቅ መንታ ፀነሰች እንጂ ። |
| **፲፩** | ወዘእንበለ ይትወለዱ ወይግበሩ ሠናየ ወእኩየ ከመ ይትዐወቅ በምንት እንከ ኀርዮቱ ለእግዚአብሔር ። | ሳይወለዱ ክፉና መልካም ሥራም ሳይሠሩ የእግዚአብሔር ምርጫው በምን እንደ ሆነ ይታወቅ ዘንድ ። |
| **፲፪** | ከመ ያእምሩ ከመ ኢኮነ በምግባሩ ለሰብእ ዘእንበለ ዳእሙ ዘውእቱ ጸውዐ ወይቤላ ለርብቃ ዘየዐቢ ይትቀነይ ለዘይንእስ ። | እርሱ የመረጠው ነው እንጂ ሰው በሥራው የሚመረጥ እንዳይደለ ያውቁ ዘንድ ፤ ርብቃን «ታላቁ ለታናሹ ይገዛል» አላት ። |
| **፲፫** | እስመ ከማሁ ጽሑፍ ያዕቆብሃ አፍቀርኩ ወዔሳውሃ ጸላእኩ ። | «ያዕቆብን ወደድኩ ዔሳውን ጠላሁ» ተብሎ እንዲሁ ተጽፎአልና ። |
| **አርእስት** | **ክፍል ፴ወ፱ ፡ በእንተ ኢመፍትው ሐቲተ ፍትሑ ።** | **ክፍል ፴ወ፱ ፡ ፍርዱን መመራመር ስለማይገባ ።** |
| **፲፬** | ምንተ እንከ ንብል ይዔምፅኑ እግዚአብሔር ፤ ሐሰ ። | እንግዲህ ምን እንላለን ? እግዚአብሔር ያደላልን ? አያደላም ። |
| **፲፭** | ወይቤሎ እግዚአብሔር ለሙሴ ለዘሂ መሐርክዎ እምሕሮ ወለዘሂ ተሣሀልክዎ እሣሀሎ ። | እግዚአብሔር ሙሴን «የምምረውን እምረዋለሁ ፤ ይቅር የምለውንም ይቅር እለዋለሁ» አለው ። |
| **፲፮** | ናሁኬ ኢኮነ ለዘበደረ ወለዘሮጸ ዘእንበለ ዳእሙ ለዘእግዚአብሔር ምሕሮ ። | እነሆ ለሮጠ ለቀደመ አልሆነም ፤ እግዚአብሔር ይቅር ላለው ነው እንጂ ። |
| **፲፯** | ወይቤሎ እግዚአብሔር በመጽሐፍ ለፈርዖን በእንተዝ አንሣእኩከ ከመ አርኢ ኃይልየ በላዕሌከ ወይሰማዕ ስምየ በኵሉ ምድር ። | እግዚአብሔር ፈርዖንን በመጽሐፍ እንዲህ አለው ፤ «ኃይሌን በአንተ ላይ እገልጥ ዘንድ ስሜም በምድር ሁሉ ይሰማ ዘንድ አስነሣሁህ» ። |
| **፲፰** | ናሁኬ ለዘፈቀደ ይምሕር ወለዘፈቀደ ያዐፅብ ። | እነሆ የወደደውን ይምራል ፤ የወደደውን ያጸናዋል (ያደነድነዋል) ። |
| **፲፱** | ምንተ ትብል ተሐይሶኑ ለእግዚአብሔር ቦኑ ዘይትቃወማ ለምክሩ ። | ምን ትላለህ ? አንተ እግዚአብሔርን ትነቅፈው ይሆን ? የእግዚአብሔርስ ምክሩን የሚቃወማት አለን ? ። |
| **፳** | እጓለ እመሕያው ምንትኑ አንተ ዘትትዋሥኦ ለእግዚአብሔር ፤ ይክልኑ ብሂሎቶ ግብር ለገባሪሁ ኢትግበረኒ ከመዝ ። | የሰው ልጅ ሆይ ፤ እግዚአብሔርን ለምን ትከራከረዋለህ ? የተሠራው ሥራ ሠሪውን «እንዲህ አድርገህ ለምን ሠራኸኝ ?» ሊለው ይችላልን ? ። |
| **፳፩** | ኢኮነኑ ብዑሐ ለብሐዊ ይግበር እምአሐዱ ጽቡር ንዋየ ፤ መንፈቆ ለክብር ወመንፈቆ ለኀሣር ። | ሸክላ ሠሪ ከአንድ ጭቃ ዕቃውን ግማሹን ለክብር ግማሹን ለውርደት ሊሠራ ሥልጣን የለውምን ? ። |
| **፳፪** | ወእመኒ ፈቀደ እግዚአብሔር ያርኢ መቅሠፍተ ኃይሉ አርእዮ ትዕግሥቶ ያመጽእ መላእክተ መዐቱ እለ ድልዋን ለአማስኖ ። | እግዚአብሔር ኃይሉን የሚገልጽበትን ቅጣቱን ሊያሳይ ቢወድ ትዕግሥቱን ካሳየ በኋላ ለማጥፋት የተዘጋጁትን ቁጣውን የሚገልጽበት መላእክትን ያመጣል ። |
