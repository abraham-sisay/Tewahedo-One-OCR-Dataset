## መቅድመ ወንጌል (ብሥራተ አብ)

| ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- |
| ብሥራተ አብ ትሩፍ ረድእ ተናጋሪ በመለኮት ዮሐንስ ወልደ ዘብዴዎስ ፍቁረ እግዚእነ ኢየሱስ ክርስቶስ አሐዱ እምዐሠርቱ ወክልኤቱ ሐዋርያት ጸሎቱ ወበረከቱ የሃሉ ምስለ ኵልነ ሕዝበ ክርስቲያን ለዓለመ ዓለም አሜን። | ፍጹም አባት የመለኮትን ነገር የሚያስተምር ሐዋርያ ከዐሥራ ሁለት ሐዋርያት አንዱ ጌታችን ኢየሱስ ክርስቶስ የሚወደው የዘብዴዎስ ልጅ ዮሐንስ የጻፈው ይህ ነው። ልመናው በረከቱ ከሁላችን ከሕዝበ ክርስቲያን ጋር ይሁን፤ አሜን። |

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፩፡ በእንተ ቃል ቀዳማዊ (ስለ ቀዳማዊ ቃል)** | **ክፍል ፩፡ በእንተ ቃል ቀዳማዊ (ስለ ቀዳማዊ ቃል)** |
| **፩** | ቀዳሚሁ ቃል ውእቱ ወውእቱ ቃል ኀበ እግዚአብሔር ውእቱ ወእግዚአብሔር ውእቱ ቃል ውእቱ። | ያ ቃል ቀዳማዊ ነው፤ ያ ቃል በእግዚአብሔር ዘንድ ነበረ፤ ያም ቃል እግዚአብሔር ነው። |
| **፪** | ወከማሁ ቀዳሚሁ እምቀዲሙ ኀበ እግዚአብሔር ውእቱ። | እንዲሁም ቀዳማዊ ቃል አስቀድሞ በእግዚአብሔር ዘንድ ነበረ። |
| **፫** | ወቦቱ ኵሉ ኮነ ወዘእንበሌሁሰ አልቦ ዘኮነ ወኢምንትኒ እምዘኮነ። | በእርሱም ሁሉ ተፈጠረ፤ ከተፈጠረውም ሁሉ ያለ እርሱ ምንም ምን የተፈጠረ የለም። |
| **፬** | ወሕይወት ውእቱ ዘኮነ ቦቱ ወሕይወትሰ ብርሃኖሙ ለሰብእ ውእቱ። | በእርሱ ሕይወት ነበረ፤ ሕይወትም የሰው ብርሃን ነበረ። |
| **፭** | ወውእቱ ብርሃን የበርህ ውስተ ጽልመት ወጽልመትሰ ኢይረክቦ። | ብርሃንም በጨለማ ይበራል፤ ጨለማውም አላሸነፈውም (አላገኘውም)። |
| **አርእስት** | **ክፍል ፪፡ በእንተ ተፈንዎቱ ለዮሐንስ መጥምቅ (ስለ ዮሐንስ መጥምቅ መላክ)** | **ክፍል ፪፡ በእንተ ተፈንዎቱ ለዮሐንስ መጥምቅ (ስለ ዮሐንስ መጥምቅ መላክ)** |
| **፮** | ወሀሎ አሐዱ ብእሲ ዘተፈነወ እምኀበ እግዚአብሔር ዘስሙ ዮሐንስ። | ከእግዚአብሔር የተላከ ስሙ ዮሐንስ የሚባል አንድ ሰው ነበረ፤ |
| **፯** | ወመጽአ ውእቱ ከመ ይኩን ስምዐ ወይስምዕ በእንተ ብርሃን ከመ ኵሉ ያእምን ቦቱ። | እርሱም ስለ ብርሃን ይመሰክር ዘንድ፣ በእርሱ በኩል ሁሉም እንዲያምኑ ለምስክር መጣ። |
| **፰** | አኮ ውእቱ ብርሃን ዘእንበለ ከመ ይስምዕ በእንተ ብርሃን። | ስለ ብርሃን ሊመሰክር መጣ እንጂ እርሱ ራሱ ብርሃን አልነበረም። |
| **፱** | እስመ ውእቱ ብርሃን ዘበአማን ዘያበርህ ለኵሉ ሰብእ ዘይመጽእ ውስተ ዓለም። | ወደ ዓለም ለሚመጣ ሰው ሁሉ የሚያበራው እውነተኛው ብርሃን እርሱ ነበረ። |
| **፲** | ወውስተ ዓለም ሀሎ ወዓለምኒ ቦቱ ኮነ ወዓለምሰ ኢያእመሮ። | በዓለም ውስጥ ነበረ፤ ዓለሙም በእርሱ ተፈጠረ፤ ዓለሙ ግን አላወቀውም። |
| **፲፩** | ውስተ ዚአሁ መጽአ ወእለ ዚአሁሰ ኢተወክፍዎ። | ወደ ራሱ ገንዘብ መጣ፤ የገዛ ወገኖቹም አልተቀበሉትም። |
| **፲፪** | ወለእለሰ ተወክፍዎ ወአምኑ በስሙ ወሀቦሙ ሥልጣነ ከመ ውሉደ እግዚአብሔር ይኩኑ። | ለተቀበሉትና በስሙ ላመኑበት ሁሉ ግን የእግዚአብሔር ልጆች ይሆኑ ዘንድ ሥልጣንን ሰጣቸው። |
| **፲፫** | እለ አኮ እምደም ወኢእምፈቃደ ሥጋ ወኢእምፈቃደ ብእሲ አላ እምእግዚአብሔር ተወልዱ። | እነርሱም ከእግዚአብሔር ተወለዱ እንጂ ከደም ወይም ከሥጋ ፈቃድ ወይም ከወንድ ፈቃድ አልተወለዱም። |
| **፲፬** | ወቃል ሥጋ ኮነ ወኀደረ ላዕሌነ ወርኢነ ስብሐቲሁ ከመ ስብሐተ አሐዱ ዋሕድ ለአቡሁ ዘምሉዕ ጸጋ ወጽድቀ። | ቃልም ሥጋ ሆነ፤ በመካከላችንም አደረ፤ ጸጋንና እውነትንም ተሞልቶ ከአባቱ ዘንድ እንደ ተወለደ እንደ አንድ ልጅ የሚገባውን ክብሩን አየን። |

| **፲፮** | ወእምነ ምልአቱ ንሕነ ኵልነ ነሣእነ ጸጋ በዲበ ጸጋ። | እኛ ሁላችን ከእርሱ ምሉእነት በጸጋ ላይ ጸጋን ተቀበልን። |
| **፲፯** | እስመ ሕግሰ በሙሴ ተውህበ፤ ጸጋሰ ወጽድቅ በኢየሱስ ክርስቶስ ኮነ። | ሕግ በሙሴ ተሰጥቶ ነበርና፤ ጸጋና እውነት ግን በኢየሱስ ክርስቶስ ሆነ። |

| **፵፰** | ወሶበ ርእዮ እግዚእ ኢየሱስ ለናትናኤል እንዘ ይመጽእ ኀቤሁ ይቤ በእንቲአሁ ነዋ ዘበአማን እስራኤላዊ ዘአልቦ ጽልሑት ውስተ ልቡ። | ጌታ ኢየሱስም ናትናኤልን ወደ እርሱ ሲመጣ አይቶ ስለ እርሱ፦ «ተንኮል የሌለበት በእውነት የእስራኤል ሰው እነሆ!» አለ። |
| **፵፱** | ወይቤሎ ናትናኤል በአይቴ ተአምረኒ፤ ወአውሥአ እግዚእ ኢየሱስ ወይቤሎ እምቅድመ ይጸውዕከ ፊልጶስ ርኢኩከ በታሕተ ዕፀ በለስ። | ናትናኤልም፦ «ከወዴት ታውቀኛለህ?» አለው፤ ጌታ ኢየሱስም መልሶ፦ «ፊልጶስ ሳይጠራህ ከበለስ በታች ሳለህ አየሁህ» አለው። |
| **፶** | ወአውሥአ ናትናኤል ወይቤሎ ረቢ አማን አንተ ውእቱ ወልደ እግዚአብሔር ወንጉሠ እስራኤል አንተ። | ናትናኤልም መልሶ፦ «መምህር ሆይ! አንተ የእግዚአብሔር ልጅ ነህ፤ አንተ የእስራኤል ንጉሥ ነህ» አለው። |
| **፶፩** | ወአውሥአ እግዚእ ኢየሱስ ወይቤሎ እስመ አቤለከ ርኢኩከ በታሕተ ዕፀ በለስ ተአምንሁ፤ እምይእዜሰ ዘየዐቢ እምዝ ትሬኢ፤ ወይቤሎሙ አማን አማን እብለክሙ እምይእዜሰ ትሬእዩ እንዘ ይትረኃዋ ሰማያት ወመላእክተ እግዚአብሔር እንዘ የዐርጉ ወይወርዱ ኀበ ወልደ እጓለ እመሕያው። | ጌታ ኢየሱስም መልሶ፦ «ከበለስ በታች አየሁህ ስላልሁህ አመንህን? ከዚህ የሚበልጥ ነገር ታያለህ፤ እውነት እውነት እላችኋለሁ፤ ከእንግዲህ ወዲህ ሰማይ ሲከፈት የእግዚአብሔርም መላእክት በሰው ልጅ ላይ ሲወጡና ሲወርዱ ታያላችሁ» አላቸው። |
