## ምዕራፍ ፲፫

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፴ወ፪ ፡ በእንተ ድራር ወሕፅበተ እግር።** | **ክፍል ፴፪ ፡ ስለ ራትና ስለ እግር ማጠብ።** |
| **፩** | ወእምቅድመ በዓለ ፋሲካ ኮነ የአምር እግዚእ ኢየሱስ ከመ በጽሐ ጊዜሁ ከመ ይፈልስ እምዝንቱ ዓለም ወየሐውር ኀበ አብ ዘፈነዎ፤ አፍቀሮሙ ለእሊአሁ እለ ውስተ ዓለም ወለዝሉፉ አፍቀሮሙ። | ከፋሲካ በዓል አስቀድሞ ጌታ ኢየሱስ ከዚህ ዓለም ተለይቶ ወደ አብ የሚሄድበት ጊዜው እንደ ደረሰ ያውቅ ነበርና፤ በዓለም ያሉት ወገኖቹን ወደዳቸው እስከ መጨረሻም ወደዳቸው። |
| **፪** | ወእንዘ ይዴረሩ ቦአ ሰይጣን ውስተ ልበ ይሁዳ ስምዖን አስቆሮታዊ ከመ ያግብኦ ፡ | ራትም ሲበሉ እንዲያስይዘው ስምዖን በሚባለው በአስቆሮቱ ሰው በይሁዳ ልብ ሰይጣን አደረ። |
| **፫** | ወሶበ ኮነ የአምር እግዚእ ኢየሱስ ከመ አወፈዮ አብ ኲሎ ውስተ እዴሁ ወከመ እምኀበ እግዚአብሔር ወፅአ ወኀበ እግዚአብሔር የሐውር። | ጌታ ኢየሱስም አብ ሁሉን በእጁ እንደ ሰጠውና ከእግዚአብሔር እንደ ወጣ ወደ እግዚአብሔርም እንዲሄድ ባወቀ ጊዜ፡ |
| **፬** | ተንሥአ እምኀበ ይዴረሩ ወአንበረ አልባሲሁ ወነሥአ መክፌ ዘለንጽ ወቀነተ ሐቌሁ ። | ራት ከሚበሉበት ተነሥቶ ልብሱን አኖረና ማበሻ (ሽርጥ) ወስዶ ታጠቀ። |
| **፭** | ወወደየ ማየ ውስተ ንብቲራ ወአኀዘ ይኅፅብ እገሪሆሙ ለአርዳኢሁ፤ ወመዝመዘ በውእቱ መክፌ ። | በመታጠቢያውም ውኃ ጨመረና የደቀ መዛሙርቱን እግር ያጥብ ጀመር፤ በታጠቀበትም ማበሻ ያብስላቸው (ይወለውላቸው) ነበር። |
| **፮** | ወበጽሐ ኀበ ስምዖን ጴጥሮስ ወይቤሎ አንተኑ እግዚኦ ዘተሐፅበኒ እገርየ። | ወደ ስምዖን ጴጥሮስም በደረሰ ጊዜ፡ አቤቱ! እግሬን የምታጥበኝ አንተ ነህን? አለው። |
| **፯** | ወአውሥአ እግዚእ ኢየሱስ ወይቤሎ ዘእገብር አነ አንተ ኢተአምር ይእዜ ወባሕቱ ድኅረሰ ተአምሮ። | ጌታ ኢየሱስም፡ እኔ የምሠራውን አንተ ዛሬ አታውቀውም ኋላ ግን ታውቀዋለህ ብሎ መለሰለት ። |
| **፰** | ወይቤሎ ጴጥሮስ ኢተሐጽበኒ እገርየ ለዓለም፤ ወአውሥአ እግዚእ ኢየሱስ ወይቤሎ አማን አማን እብለከ እመ አነ ኢሐፀብኩከ እገሪከ አልብከ ክፍል ምስሌየ ። | ጴጥሮስም፡ ለዘለዓለም አንተ እግሬን አታጥበኝም አለው፤ ጌታ ኢየሱስም፡ እውነት እውነት እልሃለሁ እኔ እግርህን ካላጠብኩህ ከእኔ ጋር ዕድል ፈንታ የለህም ብሎ መለሰለት። |
| **፱** | ወይቤሎ ስምዖን ጴጥሮስ እግዚኦ አኮ እገርየ ባሕቲቶ ዘተሐፅበኒ ወዓዲ እደውየሂኒ ወርእስየሂኒ ። | ስምዖን ጴጥሮስም፡ አቤቱ! እንኪያስ የምታጥበኝ እግሬን ብቻ አይደለም፤ እጆቼንም ራሴንም እጠበኝ አለው። |
| **፲** | ወይቤሎ እግዚእ ኢየሱስ ዘሰ ወድአ ተሐፅበ ኢይፈቅድ ይትሐፀብ ዘእንበለ እገሪሁ ዳእሙ እስመ ንጹሕ ኲለንታሁ፤ ወአንትሙሰ ንጹሐን አንትሙ ወባሕቱ አኮ ኲልክሙ ንጹሐን ። | ጌታ ኢየሱስም፡ የታጠበ ሁለንተናው ንጹሕ ስለሆነ ከእግሩ በቀር ሌላ ሊታጠብ አያስፈልገውም፤ እናንተም ንጹሐን ናችሁ ነገር ግን ሁላችሁ ንጹሐን አይደላችሁም አለው። |
| **፲፩** | እስመ የአምር እግዚእ ኢየሱስ ዘያገብኦ፤ ወበእንተ ዝንቱ ይቤ አኮ ኲልክሙ ንጹሐን ። | ጌታ ኢየሱስ የሚያሲዘውን ያውቅ ነበርና ስለዚህ ሁላችሁ ንጹሐን አይደላችሁም አለ። |
| **፲፪** | ወሶበ ሐፀቦሙ እገሪሆሙ ነሥአ አልባሲሁ ወረፈቀ ካዕበ ምስሌሆሙ ወይቤሎሙ አአመርክሙኑ ዘገበርኩ ለክሙ። | እግራቸውንም ካጠበ በኋላ ልብሱን ለብሶ ዳግመኛ ከእነርሱ ጋር ተቀመጠ፤ ያደረግሁላችሁን አወቃችሁን? አላቸው ። |
| **፲፫** | አንትሙሰ ትብሉኒ ሊቅነ ወእግዚእነ፤ ወሠናየ ትብሉ እስመ ከማሁ አነ። | እናንተ መምህራችንና ጌታችን ትሉኛላችሁ፤ መልካም ትላላችሁ እንዲሁ ነኝና። |
| **፲፬** | ሶበ አነ እንከ እንዘ ሊቀክሙ ወእግዚእክሙ ሐፀብኩክሙ እገሪክሙ፤ ከማሁኬ አንትሙኒ ይደልወክሙ ትሕፅቡ እግረ ቢጽክሙ ፡ | እንግዲህ እኔ ጌታችሁና መምህራችሁ ስሆን እግራችሁን ካጠብኳችሁ፤ እናንተም እንዲሁ እርስ በርሳችሁ እግራችሁን ትተጣጠቡ ዘንድ ይገባችኋል ። |
| **፲፭** | እስመ አርአያየ ወሀብኩክሙ ከመ ትግበሩ አንትሙኒ በከመ ገበርኩ ለክሙ አነ። | እኔ እንደ አደረግሁላችሁ እናንተም ታደርጉ ዘንድ ምሳሌ ሰጥቻችኋለሁና ። |
| **፲፮** | አማን አማን እብለክሙ አልቦ ገብር ዘየዐቢ እምእግዚኡ፤ ወአልቦ ሐዋርያ ዘየዐቢ እምዘፈነዎ ። | እውነት እውነት እላችኋለሁ ከጌታው የሚበልጥ ባሪያ የለም፤ ከላከውም የሚበልጥ መልእክተኛ የለም ። |
| **፲፯** | ወእመሰ ዘንተ ተአምሩ ብፁዓን አንትሙ አመ ገበርክምዎ። | ይህን አውቃችሁ ብታደርጉት ግን ብፁዓን ናችሁ። |
| **፲፰** | ወአኮ በእንተ ኲልክሙ ዘእብል ዘንተ፤ እስመ አነ አአምር መኑ እሙንቱ እለ ኃረይኩ፤ ወባሕቱ ከመ ይብጻሕ ቃለ መጽሐፍ ዘይቤ ዘይሴሰይ እክልየ አንሥአ ሰኩናሁ ላዕሌየ ። | ይህን የምናገረው ስለ ሁላችሁ አይደለም፤ የመረጥኳቸው እነማን እንደ ሆኑ እኔ አውቃለሁና፤ ነገር ግን መጽሐፍ የተናገረው፡ እንጀራዬን የሚበላ ተረከዙን በእኔ ላይ አነሣ ያለው ይፈጸም ዘንድ ነው። |
| **፲፱** | ወይእዜሰ እነግረክሙ ዘእንበለ ይኩን፤ ከመ አመ ኮነ ትእመኑ ከመ አነ ውእቱ። | አሁን ግን ሳይሆን አስቀድሜ እነግራችኋለሁ በሆነ ጊዜ እኔ እንደ ሆንኩ ታምኑ ዘንድ ። |
