| **አርእስት** | **ክፍል ፲ወ፩፡ በእንተ መፃጕዕ ዘሠላሳ ወሰመንተ ክረምተ ደወየ (ሠላሳ ስምንት ዓመት ስለ ታመመው ድውይ)** | **ክፍል ፲ወ፩፡ በእንተ መፃጕዕ ዘሠላሳ ወሰመንተ ክረምተ ደወየ (ሠላሳ ስምንት ዓመት ስለ ታመመው ድውይ)** |
| **፩** | ወእምድኅረዝ ኮነ በበዓሎሙ ለአይሁድ ዐርገ እግዚእ ኢየሱስ ኢየሩሳሌም። | ከዚህም በኋላ የአይሁድ በዓል ነበረ፤ ጌታ ኢየሱስም ወደ ኢየሩሳሌም ወጣ። |
| **፪** | ወቦ ውስተ ኢየሩሳሌም ምጥማቃት ዘጵሮባጢቄ ቅልንብጥራ ዘውእቱ ኃይለ አባግዕ ብሂል ወይብልዋ ስማ በዕብራይስጥ ቤተ ሳይዳ (ቤተ ሣህል) ዘውእቱ ቤተ ሣህል ወባቲ ኃምስቱ ሕዋራት። | በኢየሩሳሌምም በበጎች በር አጠገብ በዕብራይስጥ ቤተ ሳይዳ (ቤተ ሣህል — የበጎች መዋኛ) የምትባል አንዲት መጠመቂያ ነበረች፤ አምስትም መመላለሻ (መተላለፊያ) ነበራት። |
| **፫** | ወህየ ይሰክቡ ብዙኃን ድውያን ዕውራን ሐንካሳን ወይቡሳን ፅቡሳን ወጽውሳን ወይጸንሑ ሁከተ ማይ። | በእነዚህም ውስጥ ብዙ ድውያን፥ ዕውሮች፣ አንካሶች፣ ሰባራዎችና የሰለሉ የውኃውን መናወጥ እየጠበቁ ይተኙ ነበር። |
| **፬** | እስመ መልአከ እግዚአብሔር በጊዜ ይወርድ ውስተ ምጥማቃት ይትሀወክ ማይ ወዘይወርድ ቀዲሙ እምድኅረ ሁከተ ማይ ወይትሐጸብ የሐዩ እምኵሉ ደዌ ዘቦ። | አንዳንድ ጊዜ የእግዚአብሔር መልአክ ወደ መጠመቂያይቱ ወርዶ ውኃውን ያናውጥ ነበርና፤ ከውኃውም መናወጥ በኋላ በመጀመሪያ የገባ ከማናቸውም ካለበት ደዌ ይድን ነበር። |
| **፭** | ወሀሎ ህየ አሐዱ ብእሲ ዘሠላሳ ወሰመንቱ ክረምት እምዘደወየ። | በዚያም ከታመመ ሠላሳ ስምንት ዓመት የሆነው አንድ ሰው ነበረ። |
| **፮** | ወኪያሁ ርእዮ እግዚእ ኢየሱስ ይሰክብ ውስተ ዓራቱ አእመረ ከመ ጐንደየ ውስተ ደዌሁ ወይቤሎ ትፈቅድኑ ትሕየው። | ጌታ ኢየሱስ ይህን ሰው ተኝቶ ባየ ጊዜ፥ በደዌው ብዙ ዘመን እንደ ኖረ አውቆ፦ «ልትድን ትወዳለህን?» አለው። |
| **፯** | ወአውሥአ ውእቱ ድውይ ወይቤሎ አወ እግዚኦ አላ ሰብእ አልብየ ከመ ሶበ ይትሀወክ ማይ ያውርደኒ ወይደየኒ ውስተ ምጥማቃት ወሶበ እመጽእ አነ ባዕድ ይቀድመኒ ወሪደ። | ድውዩም መልሶ፦ «አዎን ጌታ ሆይ! ነገር ግን ውኃው በተናወጠ ጊዜ ወደ መጠመቂያይቱ የሚያወርደኝ ሰው የለኝም፤ እኔ ስመጣ ሌላው ይቀድመኛል» አለው። |
| **፰** | ወይቤሎ እግዚእ ኢየሱስ ተንሥእ ወንሣእ ዓራተከ ወሑር። | ጌታ ኢየሱስም፦ «ተነሣና አልጋህን ተሸክመህ ሂድ» አለው። |
| **፱** | ወሐይወ ሶቤሃ ውእቱ ብእሲ ወነሥአ ዐራቶ ወሖረ፤ ወሰንበት አሜሃ ይእቲ ዕለት። | ያን ጊዜም ያ ሰው ዳነ፤ አልጋውንም ተሸክሞ ሄደ፤ ያቺም ቀን ሰንበት ነበረች። |
| **፲** | ወይቤልዎ አይሁድ ለውእቱ ዘሐይወ ሰንበት ዮም ወኢይደልወከ ትጹር ዓራተከ። | ስለዚህ አይሁድ የዳነውን ሰው፦ «ዛሬ ሰንበት ነው፥ አልጋህን ልትሸከም አይገባህም» አሉት። |
| **፲፩** | ወአውሥአ ወይቤሎሙ ዘአሕየወኒ ውእቱ ይቤለኒ ንሣእ ዓራተከ ወሑር። | እርሱ ግን መልሶ፦ «ያዳነኝ እርሱ፦ ‹አልጋህን ተሸክመህ ሂድ› አለኝ» አላቸው። |
| **፲፪** | ወተስእልዎ ወይቤልዎ መኑ ውእቱ ዝ ብእሲ ዘይቤለከ ንሣእ ዓራተከ ወሑር። | እነርሱም፦ «‹አልጋህን ተሸክመህ ሂድ› ያለህ ያ ሰው ማን ነው?» ብለው ጠየቁት። |
| **፲፫** | ወኢያእመረ ውእቱ ዘሐይወ መኑ ውእቱ፤ እስመ እግዚእ ኢየሱስ ተግሕሠ እምኔሆሙ እስመ ሕዝብ ብዙኅ ውስተ ውእቱ መካን። | ዳሩ ግን በዚያ ስፍራ ብዙ ሕዝብ ስለ ነበሩ ጌታ ኢየሱስ ፈቀቅ ብሎ ነበርና የዳነው ሰው ማን እንደ ሆነ አላወቀም። |
| **፲፬** | ወእምድኅረዝ ረከቦ እግዚእ ኢየሱስ በምኵራብ ወይቤሎ ነዋ ሐየውከ ኢትአብስ እንከ ካዕበ ከመ ኢይርከብከ ዘየአኪ እምዝንቱ። | ከዚህ በኋላ ጌታ ኢየሱስ በመቅደስ አገኘውና፦ «እነሆ ድነሃል፤ ከዚህ የሚብስ እንዳያገኝህ ወደ ፊት ኃጢአት አትሥራ» አለው። |
| **፲፭** | ወሖረ ውእቱ ብእሲ ወነገሮሙ ለአይሁድ ከመ እግዚእ ኢየሱስ ውእቱ ዘአሕየዎ። | ያም ሰው ሄዶ ያዳነው ጌታ ኢየሱስ እንደ ሆነ ለአይሁድ ነገራቸው። |
| **፲፮** | ወበእንተ ዝንቱ ሰደድዎ አይሁድ ለእግዚእ ኢየሱስ እስመ ከመዝ ገብረ በሰንበት። | ስለዚህም አይሁድ ይህን በሰንበት ስላደረገ ጌታ ኢየሱስን ያሳድዱት ሊገድሉትም ይሹ ነበር። |
| **፲፯** | ወይቤሎሙ እግዚእ ኢየሱስ አቡየሰ እስከ ይእዜ ይገብር ወአነኒ እገብር። | ጌታ ኢየሱስ ግን፦ «አባቴ እስከ ዛሬ ይሠራል፥ እኔም ደግሞ እሠራለሁ» ብሎ መለሰላቸው። |
| **፲፰** | ወፈድፋደሰ የኀሥሡ አይሁድ ይቅትልዎ አኮ እስመ ሰዐረ ሰንበተ ባሕቲታ አላ እስመ ሰመዮ ለእግዚአብሔር አቡሁ ወአስተዓረየ ርእሶ ምስለ እግዚአብሔር። | እንግዲህ ሰንበትን ስለ ሻረ ብቻ አይደለም፥ ነገር ግን ራሱን ከእግዚአብሔር ጋር አስተካክሎ፦ «እግዚአብሔር አባቴ ነው» ስላለ አይሁድ ሊገድሉት አብዝተው ይሹ ነበር። |
| **አርእስት** | **ክፍል ፲ወ፪፡ ዘከመ አስተዋደይዎ አይሁድ ለእግዚእነ (አይሁድ ጌታችንን እንደ ከሰሱት — ስለ ወልድ መለኮታዊ ሥልጣን)** | **ክፍል ፲ወ፪፡ ዘከመ አስተዋደይዎ አይሁድ ለእግዚእነ (አይሁድ ጌታችንን እንደ ከሰሱት — ስለ ወልድ መለኮታዊ ሥልጣን)** |
