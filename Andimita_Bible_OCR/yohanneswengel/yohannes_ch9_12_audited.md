| **፩** | ወእንዘ የኀልፍ እምህየ ርእየ ብእሴ ዘዕውሩ ተወልደ። | ከዚያ ሲያልፍ ዕዉር ሆኖ የተወለደውን ሰው አየ። |
| **፪** | ወተስእልዎ አርዳኢሁ ወይቤልዎ ረቢ በኃጢአተ መኑ ተወልደ ዝንቱ ዕውር በዘ ርእሱኑ ወሚመ በዘ አዝማዲሁ። | ደቀ መዛሙርቱም፡ መምህር ሆይ! ይህ ዕዉር በማን ኃጢአት ተወለደ? በራሱ ኃጢአት ነውን? ወይስ በዘመዶቹ ኃጢአት ነው? ብለው ጠየቁት። |
| **፫** | ወይቤሎሙ እግዚእ ኢየሱስ ኢ ውእቱ አበሰ ወኢ አዝማዲሁ ዳእሙ ከመ ያስተርኢ ግብረ እግዚአብሔር በላዕሌሁ ። | ጌታ ኢየሱስም፡ እርሱ አልበደለ ዘመዶቹም አልበደሉም የእግዚአብሔር ሥራ በእርሱ ይገለጥ ዘንድ ነው እንጂ አላቸው። |
| **፬** | ወባሕቱ ርቱዕ ሊተ እግበር ግብሮ ለዘፈነወኒ እንዘ መዐልት ውእቱ፤ እስመ ትመጽእ ሌሊት ዘኢይክል ቦቱ አሐዱሂ ገቢረ። | ነገር ግን ቀን ሳለ የላከኝን ሥራ ልሠራ ይገባኛል፤ አንድ ስንኳ ሥራ ሊሠራ የማይችልባት ሌሊት ትመጣለችና። |
| **፭** | እንዘ ሀሎኩ ውስተ ዓለም አነ ውእቱ ብርሃኑ ለዓለም። | በዓለም ሳለሁ የዓለም ብርሃን እኔ ነኝ። |
| **፮** | ወዘንተ ብሂሎ ወረቀ ውስተ ምድር ወገብረ ጽቡረ በምራቁ ወቀብኦ አዕይንቲሁ ለውእቱ ዕውር። | ይህን ብሎ በምድር ላይ እንትፍ ብሎ በምራቁ ጭቃ አደረገና የዚያን ዕውር ዓይኑን ቀባው ። |
| **፯** | ወይቤሎ ሑር ተሐፀብ በምጥማቃተ ሰሊሆም ዘበትርጓሜሁ ሐዋርያ፤ ወሖረ ወተሐፅበ ወገብአ እንዘ ይሬኢ ። | ሂድና ትርጓሜው ፈሳሽ (የተላከ) በሆነው በሰሊሆም መጠመቂያ ታጠብ አለው፤ ሄዶም ታጠበና እያየ ተመለሰ። |
| **፰** | ወአጐራቢሁኒ ወእለሂ የአምርዎ ትካት ወይሬእይዎ እንዘ ይስእል ይቤሉ አኮኑ ዝንቱ ውእቱ ዘይነብር ውስተ ፍኖት ወይስእል ። | ጐረቤቶቹ፣ ቀድሞ የሚያውቁትና ሲለምንም ያዩት የነበሩት፡ ይህ በመንገድ ተቀምጦ ይለምን የነበረው አይደለምን? አሉት። |
| **፱** | ወቦ እለ ይቤሉ ውእቱ ዝንቱ፤ ወካልአን ይቤሉ አልቦ አላ ይመስሎ፤ ወለሊሁሰ ይቤ አነ ውእቱ። | ይህ እርሱ ነው ያሉ አሉ፤ ሌሎችም ይመስለዋል እንጂ አይደለም አሉ፤ እርሱ ራሱ ግን፡ እኔ ነኝ አለ። |
| **፲** | ወይቤልዎ እፎ ተከሥታ አዕይንቲከ ። | ዓይኖችህ እንዴት ተገለጡ? አሉት ። |
| **፲፩** | ወአውሥአ ወይቤሎሙ ብእሲ ዘስሙ ኢየሱስ ጽቡረ ገብረ በምራቁ ወቀብአኒ አዕይንትየ ወይቤለኒ ሑር ተሐፀብ በምጥማቃተ ሰሊሆም ወሖርኩ ወተሐፀብኩ ወርኢኩ። | እርሱም መልሶ፡ ኢየሱስ የሚባለው ሰው በምራቁ ጭቃ አድርጎ ዓይኔን ቀባኝና፡ ሄደህ በፈሳሽ ውሃ ታጠብ አለኝ፤ ሄጄም ታጠብኩና አየሁ አላቸው ። |
| **፲፪** | ወይቤልዎ አይሁድ አይቴ ውእቱ ብእሲሁ፤ ወይቤሎሙ ኢየአምር። | አይሁድም፡ ሰውየው ወዴት አለ? አሉት፤ አላውቅም አላቸው ። |
| **፲፫** | ወወሰድዎ ኀበ ፈሪሳውያን ለውእቱ ዘዕውሩ ተወልደ ። | ያን ዕውር ሆኖ የተወለደውን ወደ ፈሪሳውያን ወሰዱት። |
| **፲፬** | እስመ ሰንበት አሜሁ አመ ገብረ እግዚእ ኢየሱስ ጽቡረ በምራቁ ወከሠተ አዕይንቲሁ ። | ጌታ ኢየሱስ በምራቁ ጭቃ አድርጎ ዓይኑን ያዳነበት ቀኑ ሰንበት (ቅዳሜ) ነበረና ። |
| **፲፭** | ወተስእልዎ ካዕበ ፈሪሳውያን ዘከመ እፎ ርእየ፤ ወይቤሎሙ ጽቡረ ገብረ በምራቁ ወወደየ ውስተ አዕይንትየ ወሖርኩ ወተሐፀብኩ ወርኢኩ። | ፈሪሳውያን ዳግመኛ እንዴት እንዳየ ጠየቁት፤ በምራቁ ጭቃ አድርጎ በዓይኖቼ ውስጥ ጨመረው፣ ሄጄ ታጥቤ አየሁ አላቸው። |
| **፲፮** | ወቦ እለ ይቤሉ እምፈሪሳውያን ዝንቱ ብእሲ ኢኮነ እምእግዚአብሔር ዘኢየዐቅብ ሰንበተ፤ ወቦ እለ ይቤሉ በአይቴ ይክል ብእሲ ኃጥእ ገቢረ ዘከመዝ ተአምረ፤ ወተናፈቁ በበይናቲሆሙ በእንተ ዝንቱ ነገር። | ከፈሪሳውያንም፡ ሰንበትን የማይጠብቅ ይህ ሰው ከእግዚአብሔር አይደለም ያሉ አሉ፤ ኃጢአተኛ ሰው እንዲህ ያለ ተአምራት ማድረግ እንዴት ይችላል? ያሉም አሉ፤ ስለዚህም ነገር እርስ በርሳቸው ተለያዩ። |
| **፲፯** | ወይቤልዎ ካዕበ ለውእቱ ዕውር ምንተ ትብል አንተ በእንቲአሁ እስመ ከሠተከ አዕይንቲከ፤ ወይቤሎሙ ነቢይ ውእቱ ። | ዳግመኛም ያንን ዕውር፡ አንተስ ስለ እርሱ ምን ትላለህ ዓይኖችህን አብርቶልሃልና? አሉት፤ ነቢይ ነው አላቸው። |
| **፲፰** | ወኢአምንዎ አይሁድ ከመ ዕውሩ ተወልደ ወይእዜ ርእየ፤ እስከ ጸውዑ አዝማዲሁ ለዘርእየ። | አይሁድም የዳነውን የዕውሩን ወላጆች እስኪጠሩ ድረስ ዕውር ሆኖ እንደ ተወለደ ዛሬ እንዳየ አላመኑትም ። |
| **፲፱** | ወተስእልዎሙ ወይቤልዎሙ ዝኑ ውእቱ ወልድክሙ ዘትብሉ ዕውሩ ተወልደ፤ ወእፎ እንከ ይእዜ ይሬኢ። | ዕውር ሆኖ ተወለደ የምትሉት ልጃችሁ ይህ ነውን? ታዲያ ዛሬ እንዴት ያያል? ብለው ጠየቋቸው ። |
| **፳** | ወአውሥኡ አዝማዲሁ ወይቤሉ ነአምር ከመ ዝንቱ ውእቱ ወልድነ ወከመሂ ዕውሩ ተወልደ። | ወላጆቹም መልሰው እንዲህ አሉ፡ ይህ ልጃችን እንደ ሆነ ዕውር ሆኖም እንደ ተወለደ እናውቃለን። |
| **፳፩** | ወይእዜሰ ዘከመ እፎ ይሬኢ አው መኑ ከሠተ አዕይንቲሁ ኢነአምር፤ ኪያሁ ተስእልዎ እስመ ልሂቅ ውእቱ ወይክል ተናግሮ ለርእሱ። | ዛሬ ግን እንዴት እንደሚያይ ወይም ዓይኖቹን ማን እንዳበራለት አናውቅም፤ እርሱን ጠይቁት አዋቂ ስለ ራሱ መናገርም የሚችል ሙሉ ሰው ነውና ። |
