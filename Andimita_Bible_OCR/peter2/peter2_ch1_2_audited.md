| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፩ ፡ ዘከመ ይደሉ አትልዎ ሠናይት በሃይማኖት ።** | **ክፍል ፩ ፡ በሃይማኖት በጎነትን መያዝ እንዲገባ ።** |
| ፩ | እምኀበ ስምዖን ኬፋ ገብሩ ወልኡኩ ለኢየሱስ ክርስቶስ ለእለ ነኀብር ክብረ በሃይማኖት እንተ ከፈለነ በጽድቁ ለአምላክነ ወፈራቂነ ኢየሱስ ክርስቶስ ። | የኢየሱስ ክርስቶስ አገልጋዩ ተላኪው ከሚሆን ከስምዖን ጴጥሮስ የተላከች መልእክት ፤ በፈጣሪያችን በአምላካችን በኢየሱስ ክርስቶስ ቸርነት በደለን በሃይማኖት በሚገኘው ክብር ለምንተባበር ትድረስ ። |
| ፪ | ሞገስ ወሰላም ይብዛሕ ለክሙ በአእምሮቱ ለአምላክነ ወኢየሱስ ክርስቶስ እግዚእነ ። | አምላካችንና ጌታችን ኢየሱስ ክርስቶስን በማወቅ ሞገስና ሰላም ይብዛላችሁ ። |
| ፫ | ዘበኀይለ መለኮቱ ወሀበነ ለነ ኵሎ ምግባረ ዘይወስድ ኀበ ሕይወት ወጽድቅ ውእቱ ዘጸውዐነ ውስተ ስብሐቲሁ ወውስተ ሠናይቱ ። | በመለኮቱ ኃይል ወደ ሕይወትና ወደ ጽድቅ የሚወስደውን ምግባር ሁሉ የሠራልን ወደ ጌትነቱ ወደ ቸርነቱ የጠራን እርሱ ነው ። |
| ፬ | በዘቦቱ ነሐዩ ወነዐቢ ወንክብር በተስፋሁ እንተ ጸገወነ ከመ በእንተ ዝንቱ ትኩኑ ሱቱፋነ ለመለኮተ ዚአሁ እንዘ ትጐይይዋ ለፍትወተ ሙስናሁ ለዝንቱ ዓለም ። | በሰጠን በተስፋው እንድንድን ከፍ ከፍ እንድንልና እንድንክብር ፤ ለዚህ የዚህን ዓለም አጥፊ ፈቃዱን እየሸሻችሁ ጌትነቱን ለማገልገል ተካፋዮች ትሆኑ ዘንድ ። |
| ፭ | ወአንትሙኒ በኵሉ ጐሥዓ ገቢረክሙ አትልውዋ ለሠናይት በሃይማኖትክሙ ፤ ወበሠናይት ለአእምሮ ፤ ወበአእምሮ ለኢዘምዎ ። | እናንተ ግን በሥራው ሁሉ ችኩላን አድርጋችሁ በሃይማኖት ላይ በጎነትን ያዙ ፤ በበጎነትም ዕውቀትን ፤ በዕውቀትም ንጽሕናን ያዙ ። |
| ፮ | ወበኢዝምዎ ለትዕግሥት ፤ ወበትዕግሥት ለአምልኮ ። | በንጽሕናም ትዕግሥትን ፤ በትዕግሥትም አምልኮቱን ያዙ ። |
| ፯ | ወበአምልኮ ለተአኅዎ ፤ ወበተአኅዎ ለተፋቅሮ ። | በማምለክም ላይ ወንድማማችነትን ፤ በወንድማማችነትም ላይ ፍቅርን ያዙ ። |
| ፰ | ወዝንቱ ኵሉ እምከመ ሀለወ ኀቤክሙ ኢኮንክሙ ዕሩቃነ ወኢኮንክሙ እለ እንበለ ፍሬ አላ ያበጽሐክሙ ውስተ አእምሮቱ ለእግዚእነ ኢየሱስ ክርስቶስ ። | ይህ ሁሉ ከእናንተ ዘንድ ካለ ሥራ ፈቶች አይደላችሁም ፍሬ የሌላችሁም አይደላችሁም ፤ ጌታችን ኢየሱስ ክርስቶስን ወደ ማወቅ ያደርሳችኋል እንጂ ። |
| ፱ | ወዘሰ ኢሀሎ ውስተ ዝንቱ ምግባር ዕዉር ውእቱ ዘየሐውር በመርሰስ ወረስዐ አንጽሖ ርእሶ እምእለ በልያ በላዕሌሁ ኃጣውኢሁ ። | በዚህ ምግባር ፀንቶ የማይኖር ግን በዳሰሳ የሚሄድ ዕዉር ነው ፤ ካለፉበት ኃጣውእም ራሱን ማንጻትን የዘነጋ ነው ። |
| ፲ | ወይእዜኒ አኀዊነ ጐሥዑ ከመ በጽንዐ ምግባሪክሙ ጽንዕተ ትኩን ጽዋዔክሙ ወታወፍዩ ሐሳበ ሃይማኖትክሙ ፤ ወዘንተ እንዘ ትገብሩ ኢትስሐቱ ። | ወንድሞቻችን ! አሁንም በምግባራችሁ ጽናት ሃይማኖታችሁ የፀናች እንድትሆን የሃይማኖታችሁንም ግምገማ ታበረክቱ ዘንድ ቸኩሉ ፤ ይህንንም ስታደርጉ አትሳሳቱ ። |
| ፲፩ | ወይትወሀበክሙ ርሑብ ፍኖት ዘይወስድ ውስተ ሕይወት ዘለዓለም ወመንግሥቱ ለመድኀኒነ ኢየሱስ ክርስቶስ ። | ወደ ዘለዓለም ሕይወትና ወደ ጌታችን ኢየሱስ ክርስቶስ መንግሥት የሚወስድ ሰፊ መንገድ ይሰጣችኋል ። |
| **ክፍል** | **ክፍል ፪ ፡ በእንተ ኑዛዜ ሞቱ ለጴጥሮስ ።** | **ክፍል ፪ ፡ ጴጥሮስ ስለ ሞቱ የተናዘዘው ።** |
| ፲፪ | ወበእንተዝ እጽሕቅ ለክሙ ዘልፈ ወአዜክረክሙ ዘንተ ትእዛዘ እንዘ ፅኑዓን አንትሙ በዘሀለወ ጽድቅ ። | አሁንም ፀንቶ በሚኖረው እውነት ፀንታችሁ ሳለ ይህን ትእዛዝ ሁል ጊዜ ላሳስባችሁ እወዳለሁ ። |
| ፲፫ | ወይመስለኒሰ ከመ ርቱዕ ሊተ አምጣነ ሀሎኩ በዝንቱ ሥጋየ አንቅሕክሙ በዘክሮ ። | ነገር ግን በዚህ ሥጋዬ ሳለሁ በማሳሰብ ላነቃቃችሁ የሚገባ ይመስለኛል ። |
| ፲፬ | እስመ አእምር ከመ ፍጥንት ይእቲ ሥሳሌ ዚአየ እምኔክሙ በከመ አይድዐኒ እግዚእየ ኢየሱስ ክርስቶስ ። | ጌታዬ ኢየሱስ ክርስቶስ እንደ ነገረኝ ከእናንተ መለየቴ ፈጥና እንደ ደረሰች ዐውቃለሁና ። |
| ፲፭ | ወዓዲ ጐሥዑ ከመ ተሀሉ ኀቤክሙ ዛቲ ትእዛዝ ዘልፈ ወከመ ትዘከርዋ እምድኅረ ኅልፈትየ ወከማሁ ትግበሩ ። | ዳግመኛም ይህች ትእዛዝ ሁል ጊዜ በእናንተ ዘንድ እንድትኖር ፤ ከሞትኩም በኋላ ታስቧት ዘንድ እንዳዘዝኳችሁም ታደርጉ ዘንድ ቸኩሉ ። |
| ፲፮ | እስመ ኢኮነ መኃድምተ ጥበብ ዘተሎነ ወአእመርናክሙ ዕበየ ኀይሎ ለእግዚእነ ኢየሱስ ክርስቶስ ወምጽአቶ ወሀልዎቶ አላ ለሊነ ርኢነ ዕበዮ ዘነሥአ እምኀበ እግዚአብሔር አብ ክብረ ወስብሐተ ። | የጌታችን የኢየሱስ ክርስቶስን ኃይሉን ቅድመ ዓለም መኖሩን ወደ ዓለም መምጣቱን ስናስተምራችሁ የተከተልነው የጥበብ ተረት አይደለምና ፤ ከእግዚአብሔር አብ ዘንድ ክብርን ምስጋናን ስለ ተቀበለ እኛ ራሳችን ጌትነቱን አይተን ነው እንጂ ። |
