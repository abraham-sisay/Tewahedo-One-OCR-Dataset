| **ክፍል** | **ክፍል ፬ ፡ በእንተ እለ የሐውሩ በፍትወተ ልቦሙ ።** | **ክፍል ፬ ፡ ልባቸው በፈቀደው ስለሚሄዱ ሰነፎች ።** |
| ፩ | ወዛቲ ይእቲ አኀውየ ዳግሚትየ ጸሐፍኩ ለክሙ መጽሐፈ ከመ አንሥእክሙ በዘክሮ ወትዕቀብዋ በልብክሙ ለጽድቅ ። | ወንድሞቼ ! ጽድቅን በልባችሁ ትጠብቋት ዘንድ በማሳሰብ አቀሰቅሳችሁ ዘንድ መጽሐፍ አድርጌ የጻፍኩላችሁ ሁለተኛይቱ መልእክት ይህች ናት ። |
| ፪ | ወከመ ትዘከሩ ቃለ ነቢያት ቀደምት ቅዱሳን ዘይቤሉ ወትእዛዘ እግዚእነ ወመድኀኒነ ኢየሱስ ክርስቶስ ዘአዘዘ ለነ ለሐዋርያት ። | የቀደሙ ቅዱሳን ነቢያት ያሉትንና ጌታችን መድኃኒታችን ኢየሱስ ክርስቶስ ለእኛ ለሐዋርያቱ ያዘዘንን ትእዛዝ ታስቡ ዘንድ ። |
| ፫ | ወዘንተኒ ቅድሙ አእምሮ ከመ ሀለዎሙ ይምጽኡ በደኃሪ መዋዕል መስተስህቃን ለአስተዐብዶ ፤ እለ የሐውሩ በፍትወተ ልቦሙ ። | ይህንም አስቀድማችሁ ዕወቁ ፤ በኋላ ዘመን ልባቸው በወደደው የሚሄዱ ሰንፈው የሚያሰንፉ ሰዎች ይመጡ ዘንድ እንዳላቸው ። |
| ፬ | ወይብሉ አይቴ ውእቱ ቃሉ ዘይቤ ከመ ሀለዎ ይምጻእ ፤ ናሁ እመሰ አበዊነ ቀደምት ሞቱ እስመ ኵሉ ግብር ሀለወ በከመ ሀሎ እምፍጥረት ዓለም ። | ይመጣ ዘንድ እንዳለው የተናገረው ቃሉ የት አለ? የሚሉ ፤ እነሆ የቀደሙ አባቶቻችን ሞቱ ፤ ዓለም ከተፈጠረ ጀምሮ የተፈጠረው ፍጥረት ሁሉ እንደ ፀና አለ ። |
| ፭ | ወኢየአምርዎ ለዝንቱ ከመ ሰማያትኒ ተፈጥራ እምትካት ወምድርሂኒ እምነ ማይ ወበማይ ፀንዐት በቃለ እግዚአብሔር ። | ሰማያት አስቀድመው እንደተፈጠሩ ምድርም በውኃ ላይ እንደተፈጠረች በውኃውም ላይ በእግዚአብሔር ቃል እንደፀናች ይህን አያውቁትም ። |
| ፮ | ወዓለመ ትካትኒ ቦቱ አጥፍአ በማየ አይኅ ። | የቀደመውን ዓለም በጥፋት ውኃ አጠፋ ። |
| ፯ | ወይእዜሂ ሰማይ ወምድር በውእቱ ቃል ዝጉባን ወዕቁባን እሙንቱ እስከ ዕለተ ደይን ወድምሳሴ ኃጥኣን ሰብእ ። | አሁንም ሰማይና ምድር ኃጢአተኞች ሰዎች እስከሚጠፉባት እስከ ፍርድ ቀን ድረስ በዚያ ቃል ተመዝግበው የሚጠበቁ ናቸው ። |
| ፰ | ወዘንተ ባሕቱ ኢትርስዑ አኀዊነ እስመ አሐቲ ዕለት በኀበ እግዚአብሔር ከመ ዐሠርቱ ምእት ዓመት ፤ ወዐሠርቱ ምእት ዓመት ከመ አሐቲ ዕለት ። | ነገር ግን ወንድሞቻችን ! በእግዚአብሔር ዘንድ አንዲቱ ቀን እንደ ሺሕ ዓመት ፤ ሺሑም ዓመት እንደ አንዲት ቀን እንደሆነች ይህን አትርሱ ። |
| ፱ | ኢያጐነዲ እግዚአብሔር ቃለ ዘነበበ እስመቦ እለ ይብሉ ከመ ይጐነዲ ፤ ወባሕቱ ይትዔገሥ በእንቲአሆሙ እስመ ኢይፈቅድ መኑሂ ያማስን አላ ይነስሑ ለኵሉ ሰብእ ያርዓብ ። | እግዚአብሔር የተናገረውን ቃል አያስቀርም እንዳስቀረ የሚናገሩ አሉና ፤ ነገር ግን ስለ እነርሱ ይታገሣል ፤ ማንንም ማንን ያጠፋ ዘንድ አይሻምና ንስሐ ይገቡ ዘንድ ለሰው ሁሉ ዕድሜን ይሰጣል እንጂ ። |
| ፲ | ወዕለቱሰ ለእግዚአብሔር ግብተ ትመጽእ ከመ ሰራቂ ፤ እንተ ባቲ ሰማያትኒ ይትረኀዋ ወይሴስላ ወኵሉ ፍጥረት ዘቀዲሙ በውዕየተ እሳት ይትመሰው ወምድርኒ ወኵሉ ዘላዕሌሃ ግብር ይውዒ ። | እግዚአብሔር የሚመጣባት ቀን ግን እንደ ሌባ ድንገት ትመጣለች ፤ ሰማያት ፈጽመው የሚያልፉባት ፤ ቀድሞ የነበረው ፍጥረት ሁሉ በእሳት መቃጠል ይጠፋል ፤ ምድርም በእሷ ላይ ያለውም ፍጥረት ሁሉ ያልፋል ። |
| ፲፩ | ወዝንቱ ኵሉ ተመሲዎ ጐሥዑ ከመ ተሀልዉ በምግባር ቅዱስ ዘጽድቅ ። | ይህ ሁሉ ካለፈ በኋላ የተቀደሰ የጽድቅን ሥራ በመሥራት እንድትኖሩ ቸኩሉ ። |
| ፲፪ | እንዘ ትሴፈዉ ዕለተ ምጽአቱ ለእግዚአብሔር እንተ ባቲ ሰማያትኒ ይረክሳ ወይትመሰዋ ወኵሉ ፍጥረት ይውዒ ወይትመሰው ። | ሰማያት ቀልጠው የሚጠፉበት ፍጥረት ሁሉ ተቃጥሎ የሚጠፋበትን የእግዚአብሔርን ቀን ተስፋ እያደረጋችሁ ። |
| ፲፫ | ሐዳሳተ ሰማያተ ወሐዳሳተ ምድረ ንሴፎ ዘውስቴቶን የኀድር ጽድቅ ። | ጽድቅ አድሮባቸው የሚኖረውን አዲሶቹን ሰማያትንና አዲሲቱን ምድር ተስፋ እናደርጋለን ። |
| ፲፬ | ወይእዜኒ አኀውየ ዘንተ እንዘ ትሴፈዉ ጐሥዑ ይርከብክሙ ዘእንበለ ርስሐት ወዘእንበለ ጌጋይ እንዘ ትዕነዉ ። | አሁንም ወንድሞቼ ! ይህን ተስፋ አድርጋችሁ በአንድነት ርኵሰት በደል የሌለባችሁ ሆናችሁ ያገኛችሁ ዘንድ ቸኩሉ ። |
| ፲፭ | ወትዕግሥቱሰ ለእግዚእነ የሀብክሙ መድኀኒተ በከመ እኁነ ጳውሎስ ዘናፈቅር ጸሐፈ ለክሙ በእንተ ዘወሀቦ እግዚአብሔር ጥበበ ። | የጌታችን ትዕግሥቱም ድኅነትን ይስጣችሁ ፤ እግዚአብሔር ዕውቀቱን እንደ ሰጠው የምንወደው ወንድማችን ጳውሎስ እንደ ጻፈላችሁ ። |
| ፲፮ | ዘከመ ሀሎ ውስተ ኵሉ መጻሕፍቲሁ ዘነበበ ውስቴቶን በእንቲአሁ ለዝንቱ ፤ ወዘሰ ነበቡ ዕሙራን ሰብእ እለ ይሌብውዎ ወእለሰ አልቦሙ ትምህርት አላ ኢለበዉ ይመይጥዎ ለቃለ መጽሐፍ ከመ ሜጥዎን ለብዙኃት መጻሕፍት ለግዕዞሙ ወያጣስኑ ። | የዚህን ነገር በተናገረባቸው መጻሕፍቱ ሁሉ እንዳለ ፤ የታወቁ ሰዎች የሚናገሩትን የተረዱት ነው ፤ ትምህርት የሌላቸው ያላስተዋሉ ግን የመጽሐፉን ቃል ይለውጡታል ፤ ብዙዎችን መጻሕፍት ለግብራቸው እንዲስማማ አድርገው እንደለወጧቸውና እንዳጠፏቸው ። |
| ፲፯ | ወአንትሙኒ አኀዊነ አስቅድሙ አእምሮ ወተዐቀቡ ከመ ኢትስሐቱ በዘኢይበቁዕ ትምህርት ከመ ኢትደቁ እምነ ምጽናዕክሙ ። | ወንድሞቻችን ! እናንተ ግን በማይጠቅም ትምህርት እንዳትሳሳቱና ፀንታችሁ ከኖራችሁበት ከሃይማኖታችሁ እንዳትወድቁ አስቀድማችሁ ተጠንቀቁ ። |
| ፲፰ | ተባዝኁ በእግዚእነ ወበአኵቴቱ ለኢየሱስ ክርስቶስ መድኃኒነ ወእግዚአብሔር አብ ፤ ዘሎቱ ስብሐት ይእዜኒ ወዘልፈኒ ወለዓለመ ዓለም አሜን ። | በጌታችን አጋዥነት በዝታችሁ ኑሩ ፤ መድኃኒታችን ኢየሱስ ክርስቶስንና እግዚአብሔር አብን በማመስገን ክብር ምስጋና ለእርሱ ይሁን ፤ ዛሬም ዘወትርም ለዘለዓለሙ አሜን ። |
