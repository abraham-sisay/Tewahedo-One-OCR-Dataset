| **አርእስት** | **ክፍል ፳ወ፪ ፤ በእንተ ተጸውዖተ ስምዖን ።** | **ክፍል ፳ወ፪ ፤ ስለ ስምዖን መጠራት ።** |
| **፩** | ወሀለዉ ኀቤሁ ሰብእ ብዙኃን ወያጸምዑ ቃለ እግዚአብሔር ፤ ውእቱሰ ይቀውም መንገለ ሐይቀ ባሕረ ጌንሴሬጥ ። | ሕዝቡም የእግዚአብሔርን ቃል እየሰሙ ሲጋፉት ሳሉ ፤ እርሱ በጌንሴሬጥ ባሕር ዳር ቆሞ ነበር ። ማቴ ፬ ፡ ፲፰-፳፪ ። ማር ፩ ፡ ፲፮-፳ ። |
| **፪** | ወርእየ ክልኤተ አሕማረ ኀበ ውእቱ ሐይቅ ፤ ወወረዱ እምኔሆን መሠግራን ይሕጽቡ መሣግሪሆሙ ። | በባሕሩ ዳርም ቆመው የነበሩ ሁለት ጀልባዎችን አየ ፤ ዓሣ አጥማጆቹ ግን ከእነርሱ ወጥተው መረቦቻቸውን ያጥቡ ነበር ። |
| **፫** | ወዐርገ ውስተ አሐቲ ሐመር እምኔሆን ወይእቲ ሐመር እንተ ስምዖን ፤ ወይቤሎ ከመ ያርኅቃ ሕቀ እምነ ምድር ከመ ይንበር ዲቤሃ ወይምሀር ፤ ወነበረ ውስተ ሐመር ወመሀሮሙ ለሕዝብ ። | ከእነዚያም ጀልባዎች የስምዖን ወደ ነበረችው ወደ አንዲቱ ገባ ፤ ከምድርም ጥቂት ፈቀቅ እንዲያደርጋት ለመነው ፤ በጀልባይቱም ተቀምጦ ሕዝቡን ያስተምር ነበር ። ማቴ ፲፫ ፡ ፩-፪ ። |
| **፬** | ወሶበ ፈጸመ ነገሮ አርመመ ፤ ወይቤሎ ለስምዖን አእትቱ መንገለ ዕመቀ ባሕር ወአውርዱ መሣግሪክሙ ኀበ ይምነ ሐመር ። | ነገሩንም በፈጸመ ጊዜ ዝም አለ ፤ ስምዖንንም ወደ ጥልቁ ፈቀቅ በሉና ዓሣ ለማጥመድ መረቦቻችሁን ጣሉ አለው ። |
| **፭** | ወአውሥአ ስምዖን ወይቤሎ ሊቅ ጻሐርነ ኵላ ሌሊተ እንዘ ናወርድ መሣግሪነ ወአልቦ ዘአኀዝነ ፤ ወባሕቱ እስመ አዘዝከነ ናወርድ መሣግሪነ ። | ስምዖንም መልሶ አቤቱ ሌሊቱን ሁሉ ደክመን ምንም አልያዝንም ፤ ነገር ግን ስላዘዝኸን መረቡን እጥላለሁ አለው ። ዮሐ ፳፩ ፡ ፫-፮ ። |
| **፮** | ወገቢሮሙ ከማሁ ተእኅዙ ብዙኃን ዓሣት ፈድፋደ ፤ እስከ ይትበተክ መሣግሪሆሙ ። | ይህንም ባደረጉ ጊዜ እጅግ ብዙ ዓሣ ያዙ ፤ መረቦቻቸውም ተቀዳደዱ ። |
| **፯** | ወጸውዕዎሙ ለቢጾሙ እለ ውስተ ካልእ ሐመር ከመ ይምጽኡ ወይርድአዎሙ ፤ ወመጽኡ ወመልኡ ክልኤሆን አሕማረ እስከ ይሰጠማ ። | በሌላይቱም ጀልባ የነበሩትን ባልንጀሮቻቸውን መጥተው እንዲያግዟቸው ጠቀሷቸው ፤ መጥተውም ሁለቱ ጀልባዎች እስኪሰጥሙ ድረስ ሞሏቸው ። |
| **፰** | ወርእዮ ስምዖን ጴጥሮስ አስተብረከ ወሰገደ ኀበ እገሪሁ ለእግዚእ ኢየሱስ ወይቤሎ ፤ ኅድገኒ እግዚኦ ወሑር እምኔየ እስመ ብእሲ ኃጥእ አነ ። | ስምዖን ጴጥሮስም ባየ ጊዜ በኢየሱስ እግር ላይ ወድቆ ፤ ጌታ ሆይ እኔ ኃጢአተኛ ሰው ነኝና ከእኔ ተለይተህ ሂድ አለው ። |
| **፱** | እስመ አኀዞ ድንጋፄ ወፍርሃት ፤ ወኵሎሙ እለ ምስሌሁ ደንገፁ በእንተ ዓሣት ዘተሠግሩ ። | ስላጠመዱት ዓሣ እርሱ ከእርሱም ጋር የነበሩት ሁሉ በመደነቅና በፍርሃት ተይዘው ነበርና ። |
| **፲** | ወከማሁ ያዕቆብኒ ወዮሐንስ ደቂቀ ዘብዴዎስ አርክቲሁ ለስምዖን ፤ ወይቤሎ እግዚእ ኢየሱስ ለስምዖን ኢትፍራህ እምይእዜሰ ሰብአ ታመግር ። | እንዲሁም የስምዖን ጓደኞች የነበሩት የዘብዴዎስ ልጆች ያዕቆብና ዮሐንስም ተደነቁ ፤ ኢየሱስም ስምዖንን አትፍራ ከእንግዲህ ወዲህ ሰውን የምታጠምድ ትሆናለህ አለው ። |
| **፲፩** | ወአውፅኡ አሕማሪሆሙ ውስተ ምድር ፤ ወኀደጉ ኵሎ ወተለውዎ ። | ጀልባዎቻቸውንም ወደ ምድር አድርሰው ሁሉን ትተው ተከተሉት ። |
| **አርእስት** | **ክፍል ፳ወ፫ ፤ ዘከመ አሕየዎሙ እግዚእ ኢየሱስ ለዘለምጽ ወለመጻጕዕ ።** | **ክፍል ፳ወ፫ ፤ ጌታ ኢየሱስ ለምጻሙንና መጻጕዑን ስለ ማዳኑ ።** |
| **፲፪** | ወእንዘ ሀሎ ውስተ አሐቲ ሀገር መጽአ ብእሲ ዘለምጽ ኵለንታሁ ፤ ወሶበ ርእዮ ለእግዚእ ኢየሱስ ሰገደ ሎቱ በገጹ ወአስተብቍዖ ወይቤሎ እግዚኦ አመሰ ፈቀድከ ትክል አንጽሖትየ ። | በአንዲት ከተማም ሳለ እነሆ ሰውነቱ ሁሉ በለምጽ የተሞላ ሰው መጣ ፤ ኢየሱስንም ባየ ጊዜ በግምባሩ ወድቆ ጌታ ሆይ ብትወድስ ልታነጻኝ ትችላለህ ብሎ ለመነው ። ማቴ ፰ ፡ ፩-፬ ። ማር ፩ ፡ ፵-፵፭ ። |
| **፲፫** | ወሰፍሐ እዴሁ ወገሠሦ ወይቤሎ አፈቅድ ንጻሕ ፤ ወኃደጎ ለምጹ ሶቤሃ ። | እጁንም ዘርግቶ ዳሰሰውና እወዳለሁ ንጻ አለው ፤ ወዲያውም ለምጹ ለቀቀው ። |
| **፲፬** | ወከልኦ ኢይንግር ወኢለመኑሂ ፤ ወአዘዘ ወይቤሎ ሑር ወአፍትን ርእሰከ ለካህን ወአብእ መባአከ በእንተ ዘነጻሕከ በከመ አዘዘ ሙሴ ከመ ይኩን ስምዐ ላዕሌሆሙ ። | ለማንም እንዳይናገር ከለከለው ፤ ነገር ግን ሄደህ ራስህን ለካህን አሳይ ፤ ለእነርሱም ምስክር እንዲሆን ስለ መንጻትህ ሙሴ እንዳዘዘ መባህን አቅርብ ብሎ አዘዘው ። ዘሌ ፲፬ ፡ ፪-፴፪ ። |
| **፲፭** | ወተሰምዐ ነገሩ ፈድፋደ ፤ ወይመጽኡ ብዙኃን ሰብእ ኀቤሁ ይሰምዕዎ ወይትፈወሱ እምደዌሆሙ ። | ነገር ግን ዝናው ይበልጥ ወጣ ፤ ብዙ ሕዝብም ሊሰሙትና ከደዌአቸው ሊፈወሱ ይሰበሰቡ ነበር ። |
| **፲፮** | ወውእቱሰ ይወፅእ ገዳመ ወይጼሊ በህየ ። | እርሱ ግን ወደ ምድረ በዳ ወጥቶ በዚያ ይጸልይ ነበር ። |
