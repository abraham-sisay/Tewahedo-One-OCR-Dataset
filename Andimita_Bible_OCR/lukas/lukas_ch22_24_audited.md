| **አርእስት** | **ክፍል ፻ወ፱፡ በእንተ ይሁዳ (ስለ ይሁዳ አሳልፎ ለመስጠት መነጋገር)** | **ክፍል ፻ወ፱፡ በእንተ ይሁዳ (ስለ ይሁዳ አሳልፎ ለመስጠት መነጋገር)** |
| **፫** | ወቦአ ሰይጣን ውስተ ልበ ይሁዳ አስቆሮታዊ ዘእምዐሠርቱ ወክልኤቱ ኀልቁ። | በቁጥሩ ከዐሥራ ሁለት ወገን በነበረው በአስቆሮቱ ይሁዳ ልብ ሰይጣን ገባ። |
| **፬** | ወሖረ ወተናገሮሙ ለሊቃነ ካህናት ወለጸሐፍት ከመ ያገብኦ ሎሙ። | ሄደም እንዲያስይዛቸው የካህናት አለቆችንና ጻፎችን ተነጋገራቸው። |
| **፭** | ወተፈሥሑ ወተሰነዐዉ ምስሌሁ ወተናገርዎ የሀብዎ ሠላሳ ብሩረ ወአስተኀለቁ ነገረ። | ደስ ብሏቸው ከእርሱ ጋር ተስማምተው ሠላሳ ብር ሊሰጡት ተነጋገሩትና ነገር ቆረጡ። |
| **፮** | ወየኀሥሥ ሳሕተ ያግብኦ ሎሙ እንዘ አልቦ ሰብእ። | ሰው ሳይኖር ለብቻው አሳልፎ ሊሰጠው ምቹ ጊዜ ይሻ ነበር። |
| **አርእስት** | **ክፍል ፻ወ፲፡ በእንተ አስተዳልዎተ ፍሥሕ (የፋሲካን በግ ስለ ማዘጋጀት)** | **ክፍል ፻ወ፲፡ በእንተ አስተዳልዎተ ፍሥሕ (የፋሲካን በግ ስለ ማዘጋጀት)** |
| **፯** | ወበጽሐት ዕለተ መጸለት አመ ይጠብሑ ፍሥሐ። | ፋሲካን (በጉን) የሚያርዱበት የቂጣ በዓል ደረሰች። |
| **፰** | ወይቤሎሙ እግዚእ ኢየሱስ ለጴጥሮስ ወለዮሐንስ ሑሩ ወአስተዳልዉ ለነ ፍሥሐ ዘንበልዕ። | ጌታ ኢየሱስም ጴጥሮስንና ዮሐንስን፦ «ሂዱና የምንበላውን ፋሲካን አዘጋጁልን» አላቸው። |
| **፱** | ወይቤልዎ በአይቴ ትፈቅድ ናስተዳሉ ለከ ፍሥሐ። | እነርሱም፦ «ወዴት ልናዘጋጅልህ ትወዳለህ?» አሉት። |
| **፲** | ወይቤሎሙ ቦኢአክሙ ሀገረ ትረክቡ ብእሴ ዘይጸውር ጻሕበ ማይ ወትልውዎ ኪያሁ ኀበ ቦአ ቤት። | እርሱም እንዲህ አላቸው፦ «ወደ ከተማ በገባችሁ ጊዜ የውኃ ማድጋ የተሸከመ ሰው ታገኛላችሁ፤ እርሱ ወደሚገባበት ቤት ተከተሉት፤ |
| **፲፩** | ወበልዎ ለበዐለ ውእቱ ቤት ይቤለከ ሊቅ አይቴኑ ቤት ኀበ እበልዕ ፍሥሐ ምስለ አርዳእየ። | የዚያንም ቤት ጌታ፦ ‹መምህር፦ ከደቀ መዛሙርቴ ጋር ፋሲካን የምበላበት የእንግዳ ማረፊያ ቤት ወዴት ነው? ብሎሃል› በሉት። |
| **፲፪** | ወውእቱ ያርእየክሙ ጽርሐ ዐቢየ ወንጹፈ ወሥርግወ ወበህየ አስተዳልዉ ለነ። | እርሱም የተነጠፈና የተዘጋጀ ታላቅ አዳራሽ ያሳያችኋል፤ በዚያም አዘጋጁልን።» |
| **፲፫** | ወሐዊሮሙ ረክቡ በከመ ይቤሎሙ ወአስተዳለዉ ፍሥሐ። | ሄደውም እንዳላቸው አገኙና ፋሲካን አዘጋጁ። |
| **አርእስት** | **ክፍል ፻፲ወ፩፡ በእንተ ምሥጢረ ቍርባን ሐዲስ (ስለ ሐዲስ የቍርባን ምሥጢር)** | **ክፍል ፻፲ወ፩፡ በእንተ ምሥጢረ ቍርባን ሐዲስ (ስለ ሐዲስ የቍርባን ምሥጢር)** |
| **፲፬** | ወሶበ ኮነ ጊዜሁ ለድራር ረፈቀ እግዚእ ኢየሱስ ወዐሠርቱ ወክልኤቱ ሐዋርያቲሁ ምስሌሁ። | የራት ሰዓት በሆነ ጊዜም ጌታ ኢየሱስ ማዕድ ተቀመጠ፤ ዐሥራ ሁለቱም ሐዋርያት ከእርሱ ጋር ተቀመጡ። |
| **፲፭** | ወይቤሎሙ ፈቲወ ፈተውክዋ ለዛቲ ፋሲካ እብላዕ ምስሌክሙ ዘእንበለ ይብጽሐኒ ሕማምየ። | እንዲህም አላቸው፦ «መከራ ከመቀበሌ በፊት ይህችን ፋሲካ ከእናንተ ጋር ልበላ እጅግ ወደድኩ፤ |
| **፲፮** | እብለክሙ ባሕቱ ከመ ኢይበልዕ እንከ እምኔሃ እስከ ይትፌጸም በመንግሥተ እግዚአብሔር። | ነገር ግን በእግዚአብሔር መንግሥት እስኪፈጸም ድረስ እንግዲህ ከእርሷ አልበላም እላችኋለሁ።» |
| **፲፯** | ወተመጠወ ጽዋዐ ወአእኰተ ወይቤሎሙ ንሥኡ ዘንተ ወተካፈልዎ ኩልክሙ። | ጽዋውንም ተቀብሎ አመሰገነና፦ «ይህን ተቀበሉ፤ በመካከላችሁም ተካፈሉት፤ |
| **፲፰** | እብለክሙ ኢይሰቲ እንከ እምዝንቱ ፍሬ ወይን እስከ አመ እሰትዮ ሐዲሰ በመንግሥተ እግዚአብሔር። | በእግዚአብሔር መንግሥት አዲሱን እስክጠጣው ድረስ እንግዲህ ከዚህ የወይን ፍሬ አልጠጣም እላችኋለሁ።» |
| **፲፱** | ወነሥአ ኅብስተ ወአእኰተ ፈተተ ወወሀቦሙ ወይቤሎሙ ዝንቱ ውእቱ ሥጋየ ዘይትወሀብ በእንቲአክሙ ለቤዛ ብዙኃን ወከመዝ ግበሩ ተዝካርየ በእንቲአየ። | ኅብስቱንም አንሥቶ አመስግኖ ቆርሶ ሰጣቸውና፦ «ስለ እናንተና ስለ ብዙዎች ቤዛ የሚሰጥ ሥጋዬ ይህ ነው፤ እኔ ስለ ሠራሁላችሁ መታሰቢያዬን እንዲህ አድርጉ» አላቸው። |
| **፳** | ወከማሁ ጽዋዐኒ እምድኅረ ተደሩ ይቤሎሙ ዝንቱ ጽዋዕ ዘሐዲስ ሥርዓት ደምየ ውእቱ ዘይትከዐው በእንቲአክሙ ወበእንተ ብዙኃን። | እንዲሁም ሥጋውን ከተቀበሉ በኋላ (ከተመገቡ በኋላ)፦ «ሐዲስ ሥርዓት የሚሆን ይህ ጽዋዕ ስለ እናንተና ስለ ብዙዎች የሚፈስ ደሜ ነው» አላቸው። |
| **አርእስት** | **ክፍል ፻፲ወ፪፡ በእንተ ትእምርት ዘያገብኦ (ስለሚያስይዘው የተሰጠ ምልክት)** | **ክፍል ፻፲ወ፪፡ በእንተ ትእምርት ዘያገብኦ (ስለሚያስይዘው የተሰጠ ምልክት)** |
| **፳፩** | ወባሕቱ ናሁ እዴሁ ለዘያገብአኒ ምስሌየ ውስተ ማእድ። | ነገር ግን የባላጋራዬ (አሳልፎ የሚሰጠኝ) እጅ እነሆ በማዕድ ላይ ከእኔ ጋር ነው። |

## ማጠቃለያ (ኮሎፎን)

| ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- |
| መልአ ጽሕፈተ ብሥራቱ ለሉቃስ ረድእ አሐዱ እምሰብዓ ወክልኤቱ አርድእት። ዘጸሐፎ በልሳነ ዮናኒ ለሰብአ ሀገረ መቄዶንያ እምድኅረ ዕርገቱ ለእግዚእነ ኢየሱስ ክርስቶስ ውስተ ሰማይ በሥጋ በ፳ወ፩ ዓመት፤ ወበ፲ወ፬ ዓመተ መንግሥቱ ለቀላውዴዎስ ቄሣር። ወስብሐት ለእግዚአብሔር። አሜን። | ከሰባ ሁለቱ አርድእት አንዱ ወንጌላዊ ሉቃስ ጌታችን ኢየሱስ ክርስቶስ ወደ ሰማይ ባረገ በሃያ አንደኛው ዓመት፤ ቀላውዴዎስ ቄሣር በነገሠ በዐሥራ አራተኛው ዓመት፤ ለመቄዶንያ ሰዎች በጽርዕ ቋንቋ የጻፈው ወንጌል ደረሰ ተፈጸመ። ለእግዚአብሔር ምስጋና ይሁን። አሜን። |
