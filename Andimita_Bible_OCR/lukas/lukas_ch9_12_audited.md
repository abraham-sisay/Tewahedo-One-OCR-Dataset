| **አርእስት** | **ክፍል ፴ወ፩፡ በእንተ ተፈንዎተ ሐዋርያት (ስለ ሐዋርያት መላክ)** | **ክፍል ፴ወ፩፡ በእንተ ተፈንዎተ ሐዋርያት (ስለ ሐዋርያት መላክ)** |
| **፩** | ወጸውዖሙ ለዐሠርቱ ወክልኤቱ አርዳኢሁ ወወሀቦሙ ኃይለ ወአብሖሙ ላዕለ ኵሉ አጋንንት ያሕይዉ ድዉያነ። | ዐሥራ ሁለቱንም ሐዋርያት ጠርቶ ኃይልን ሰጣቸው፤ ድዉያንን ይፈውሱ ዘንድ በአጋንንት ሁሉ ላይ አሠለጠናቸው። |
| **፪** | ወፈነዎሙ ይስብኩ መንግሥተ እግዚአብሔር ወይፈውሱ ድዉያነ ወኵሎሙ ሕሙማነ። | የእግዚአብሔርንም መንግሥት ሊሰብኩ፣ ድዉያንንና ሕሙማንን ሁሉ ሊፈውሱ ላካቸው። |
| **፫** | ወይቤሎሙ ኢትንሥኡ ለፍኖት ወኢምንተኒ ኢበትረ ወኢጽፍነተ ወኢእክለ ወኢወርቀ ወኢክልኤተ ክዳናተ። | እንዲህም አላቸው፦ ለመንገድ ምንም ምን አትያዙ፤ በትርም ቢሆን፣ ከረጢትም ቢሆን፣ እህልም ቢሆን፣ ሁለት ልብስም ቢሆን አትያዙ። |
| **፬** | ወቤተ ኀበ ቦእክሙ ሀየ ዓድሩ ወኢትፃኡ እምሀየ እስከ አመ ተሐውሩ። | በገባችሁበት ቤት በዚያ ተቀመጡ፤ ከዚያ አገር እስክትሄዱም ድረስ ከዚያ አትውጡ። |
| **፭** | ወዘሰ ኢተወክፉክሙ ወፃእክሙ እምይእቲ ሀገር ንግፉ ጸበለ እገሪክሙ ከመ ይኩን ስምዐ ላዕሌሆሙ። | የማይቀበሏችሁን ግን ከዚያች አገር ወጥታችሁ ምስክር እንዲሆንባቸው የእግራችሁን ትቢያ አራግፉ። |
| **፮** | ወወፂኦሙ ዖዱ አህጉረ አድያም ወሰበኩ ወፈወሱ በኵለሄ። | ወጥተውም አገሩን ሁሉ ዞሩ፤ በየመንደሩም ወንጌልን አስተማሩ፣ በየስፍራውም ድዉያንን ፈወሱ። |
| **አርእስት** | **ክፍል ፴ወ፪፡ በእንተ ሕሊና ሄሮድስ (ስለ ሄሮድስ ሐሳብ)** | **ክፍል ፴ወ፪፡ በእንተ ሕሊና ሄሮድስ (ስለ ሄሮድስ ሐሳብ)** |
| **፯** | ወሰምዐ ሄሮድስ ንጉሥ ኵሎ ዘኮነ ወዘተገብረ ወየኃጥእ ዘይብል እስመ ቦ እለ ይብሉ ዮሐንስ ተንሥአ እምነ ምውታን። | ንጉሥ ሄሮድስም የሆነውንና የተደረገውን ሁሉ ሰምቶ የሚናገረውን ያጣ ነበር፤ ዮሐንስ መጥምቅ ከሙታን ተለይቶ ተነሣ የሚሉ ነበሩና። |
| **፰** | ወቦ እለ ይብሉ ኤልያስ አስተርአየ፣ ወቦ እለ ይብሉ አሐዱ እምነቢያት ቀደምት ተንሥአ። | ኤልያስ ተገለጠ የሚሉም ነበሩ፤ ከቀደሙት ነቢያት አንዱ ተነሣ የሚሉም ነበሩ። |
| **፱** | ወይቤ ሄሮድስ ለዮሐንስሰ አነ መተርኩ ርእሶ መኑ እንከ ውእቱ ዝንቱ ዘእሰምዕ በእንቲአሁ ወፈቀደ ይርአዮ። | ሄሮድስም፦ እኔ የዮሐንስን ራስ ቆርጬዋለሁ፤ እንግዲህ ስለ እርሱ እንዲህ ሲወራ የምሰማው ይህ ማነው? አለ፤ ሊያየውም ወደደ። |
| **፲** | ወሶበ ተሰውጡ ሐዋርያት ነገርዎ ኵሎ ዘገብሩ ወነሥኦሙ በባሕቲቶሙ ወተግኅሠ ወወፅኡ ሐቅለ ሀገር እንተ ስማ ቤተ ሳይዳ። | ሐዋርያትም በተመለሱ ጊዜ ያደረጉትን ሁሉ ነገሩት፤ እርሱም ለብቻቸው ይዟቸው ቤተ ሳይዳ ወደምትባል አገር ምድረ በዳ ፈቀቅ አለ። |
| **፲፩** | ወአእሚሮሙ ሕዝብ ተለውዎ ወተቀበሎሙ ወነገሮሙ በእንተ መንግሥተ እግዚአብሔር፤ ወለእለሂ ይፈቅዱ ይትፈወሱ አሕየዎሙ። | ሕዝቡም አውቀው ተከተሉት፤ እርሱም ተቀብሎ ስለ እግዚአብሔር መንግሥት አስተማራቸው፣ ሊፈወሱ የሚወዱትንም አዳናቸው። |
| **አርእስት** | **ክፍል ፴ወ፫፡ በእንተ ኃምስ ኅብስት ወክልኤቲ ዓሣት (ስለ አምስቱ ኅብስትና ስለ ሁለት ዓሣዎች)** | **ክፍል ፴ወ፫፡ በእንተ ኃምስ ኅብስት ወክልኤቲ ዓሣት (ስለ አምስቱ ኅብስትና ስለ ሁለት ዓሣዎች)** |
| **፲፪** | ወተቄልቄለ ፀሐይ ወመጽኡ ዐሠርቱ ወክልኤቱ አርዳኢሁ ወይቤልዎ ፈኑ ሰብአ ይእተዉ አህጉረ አድያም ወይቢቱ ውስተ አዕፃዳት ወይርከቡ ዘይበልዑ እስመ ሐቅል ውእቱ ኀበ ሀለውነ። | ፀሐይም ዘነበለ፤ ዐሥራ ሁለቱም ደቀ መዛሙርት መጥተው፦ ሰዎቹን አሰናብት፤ በዙሪያው ወደ አሉት አውራጃዎችና መንደሮች ይሂዱ፣ የሚበሉትንም ያገኙ ዘንድ በየመንደሩ ይግቡ፣ ያለንበት በረኻ ነውና አሉት። |
| **፲፫** | ወይቤሎሙ ሀብዎሙ አንትሙ ዘይበልዑ፤ ወይቤልዎ አልብነ ዝየ ዘእንበለ ኃምስ ኅብስት ወክልኤቲ ዓሣት፤ እመ ኢሖርነ ንሣየጥ መብልዐ ለዝንቱ ኵሉ ሕዝብ። | እርሱም፦ እናንተ የሚበሉትን ስጧቸው አላቸው፤ እነርሱም፦ ለዚህ ሁሉ ሕዝብ የሚሆን ምግብ ልንገዛ ካልሄድን እዚህ ከአምስት እንጀራና ከሁለት ዓሣ በቀር ሌላ የለንም አሉት። |
| **፲፬** | ወየአክሉ እደው ኀምሳ ምእት፤ ወይቤሎሙ ለአርዳኢሁ አርፍቅዎሙ በበኃምሳ ለለምርፋቆሙ። | ሰዎቹም አምስት ሺህ ያህል ነበሩ፤ ደቀ መዛሙርቱንም፦ አምሳ አምሳውን በየመደባቸው አስቀምጧቸው አላቸው። |
| **፲፭** | ወገብሩ ከማሁ ወረፈቁ ኵሎሙ። | እንደታዘዙም አደረጉ፤ ሁሉም ተቀመጡ። |
| **፲፮** | ወነሥኦን ለኃምስ ኅብስት ወለክልኤቲ ዓሣት ወነጸረ ሰማየ ወባረከ ወፈተተ ወወሀቦሙ ለአርዳኢሁ ያቅርቡ ለሰብእ። | አምስቱንም እንጀራና ሁለቱን ዓሣ አንሥቶ ወደ ሰማይ ተመለከተ፤ ባርኮ ቆርሶም ለሕዝቡ እንዲያቀርቡ ለደቀ መዛሙርቱ ሰጣቸው። |
| **፲፯** | ወአቅረቡ ወበልዑ ወጸግቡ ኵሎሙ፤ ወዘአግኀሡ ዘተርፈ ፍተታተ መልአ ዐሠርተ ወክልኤተ መሣይምተ ምሉአነ። | አቀረቡ፤ በሉና ሁሉም ጠገቡ፤ ያነሡት የቀረው ፍርፋሪ ዐሥራ ሁለት መሶብ ሙሉ ሆነ። |
| **አርእስት** | **ክፍል ፴ወ፬፡ በእንተ ተስእሎተ አርዳኢሁ (ደቀ መዛሙርቱን ስለ መጠየቁ)** | **ክፍል ፴ወ፬፡ በእንተ ተስእሎተ አርዳኢሁ (ደቀ መዛሙርቱን ስለ መጠየቁ)** |
