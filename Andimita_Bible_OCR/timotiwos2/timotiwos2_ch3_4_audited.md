| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፬ ፡ በእንተ መፍቀርያነ ርእሶሙ ።** | **ክፍል ፬ ፡ ራሳቸውን ስለሚወዱ ሰዎች ።** |
| ፩ | ወዘንተ ባሕቱ አእምር ከመ በደኃሪ መዋዕል ይመጽእ ዓመታት እኩያት ። | ይህን ብቻ ዕወቅ ፤ በኋላ ዘመን ክፉ ዘመናት እንደሚመጡ ። |
| ፪ | ወይከውኑ ሰብእ መፍቀርያነ ርእሶሙ ባሕቲቶሙ ወመፍቀርያነ ፈጊዕ ወንዋይ ነባብያን ዓላውያን ዝጉራን ዕፉራን ዓላውያነ አዝማዲሆሙ እለ አልቦሙ አኰቴት ውፁዓን እምጽድቅ ። | ሰዎች ራሳቸውን ብቻ የሚወዱ ተድላ ደስታንና ገንዘብን የሚወዱ ለፍላፊዎች ወንጀለኞች ትዕቢተኞች ተሳዳቢዎች ወላጆቻቸውን የማይረዱ ምስጋና የሌላቸው ከጽድቅ የወጡ ይሆናሉ ። |
| ፫ | እስመ አልቦሙ ምሕረት ሥሑፃን ጸላእያነ ሠናይ ። | ርኅራኄ የሌላቸው ደፋሮች በጎውን ነገር የሚጠሉ ይሆናሉ ። |
| ፬ | ዝሉፋን ጽሉአን እለ ያበድሩ ሐውዘ እምፍቅረ እግዚአብሔር ። | ኃጢአት አዘውታሪዎች የተጠሉ ከእግዚአብሔር ፍቅር ይልቅ ተድላ ደስታን የሚመርጡ ይሆናሉ ። |
| ፭ | ይትሜሰሉ ጻድቃነ ወይክሕድዎ ለኃይለ ጽድቅ ፤ ወለእለ ከመዝ ተገኃሦሙ ። | ጻድቃን ይመስላሉ ነገር ግን የጽድቅን ኃይል ይክዱታልና እንደነዚህ ያሉትን ተለያቸው ። |
| ፮ | እስመ እሙንቱ እለ ይትባውኡ አብያተ ሰብእ ወይፄውዎን ለአንስት እለ ጽፉራት በኃጢአት ወያወርዳ ውስተ ብዙኅ ፍትወት ። | እነዚህ በየሰው ቤት ጥልቅ ብለው ገብተው በኃጢአት የተተበተቡትንና ወደ ብዙ ፍትወት የሚያወርዱ ሴቶችን ይማርኳቸዋልና ። |
| ፯ | ወዘልፈ ይትጌሠፁ ወኢየአምርዋ ግሙራ ለጽድቅ ። | ዘወትር ይመከራሉ ነገር ግን እውነትን አያውቋትም ። |
| ፰ | ከመ ኢያኔስ ወኢያንበሬስ እለ ተቃወምዎ ለሙሴ ፤ ከማሁ እለሂ ይትቃወምዋ ለጽድቅ ሰብእ ሙስናነ ልብ ወኑፉቃነ ሃይማኖት ። | ኢያኔስና ኢያንበሬስ ሙሴን እንደ ተቃወሙት እነዚህም እንዲሁ እውነትን ተቃወሟት ፤ ልባቸው የጠፋ ሃይማኖት የሌላቸው ሰዎች ናቸው ። |
| ፱ | ወኢይትሌዐሉ እስመ ፈድፈደት ዕበዶሙ ወተዐውቀት ለኵሉ ከመ ዕበዶሙ ለአልክቱ ዓዲ ። | ልዕልና ነፍስ አያገኙም ፤ የነዚያ ስንፍና በሁሉም ዘንድ እንደ ታወቀች የነዚህ ስንፍናቸው ደግሞ ለሁሉ ትታወቃለችና ። |
| ፲ | ወአንተሰ ተለውከ ትምህርትየ ወተመሰልከ በግዕዝየ በዘመሀርኩከ በሃይማኖት ወበተፋቅሮ ወበትዕግሥት ወበህድአት ወበተሰዶ ወበሕማም ። | አንተ ግን ትምህርቴን ተከትለሃል ፤ ግብሬንም ይዘሃል በአስተማርኩህ ትምህርት ፀንተህ በፍቅር በትዕግሥት በዝግታ ሆነህ በመሰደድ መከራን በመቀበል መስለኸኛል ። |
| ፲፩ | ተአምር መጠነ ረከበኒ በአንጾኪያ ወበኢቆንያ ወበልስጥራን መጠነ ተዐገሥኩ ተሰዶ ፤ ወእምኵሉ አድኃነኒ እግዚአብሔር ። | በአንጾኪያ በኢቆንያ በልስጥራን ያገኘኝን መከራ መሰደድንም እንደ ታገሥኩ ታውቃለህ ፤ ከሁሉም እግዚአብሔር አዳነኝ ። |
| ፲፪ | ወኵሎሙ እለ ይፈቅዱ ይሕየዉ በጽድቀ ኢየሱስ ክርስቶስ የሐምሙ ። | በኢየሱስ ክርስቶስ ጽድቅ ሊድኑ የሚወዱ ሁሉ መከራ ይቀበላሉ ። |
| ፲፫ | ወሰብእሰ እኩያን ይትሌዐሉ ውስተ እንተ ተዐቢ ፤ ወይስሕቱ ወያስሕቱ ። | ክፉ ሰዎች ግን በክፋት ላይ ክፋት እየጨመሩ ይሄዳሉ ፤ ራሳቸው ስተው ሌላውንም ያስታሉ ። |
| ፲፬ | ወአንተሰ ሀሉ በዘተምህርከ ወተአመንከ ። | አንተ ግን በተማርከውና ባመንከው እምነት ፀንተህ ኑር ። |
| ፲፭ | ተአምር በኀበ መኑ ተምህርከ እምንእስከ መጽሐፈ ቅዱሰ ዘይክል አሕይዎተከ በሃይማኖተ ኢየሱስ ክርስቶስ ። | ኢየሱስ ክርስቶስን በማመን ሊያድንህ የሚችለውን ቅዱስ መጽሐፍን ከሕፃንነትህ ጀምሮ ከማን እንደ ተማርክ ታውቃለህ ። |
| ፲፮ | ወኵሉ መጽሐፍ ዘበመንፈሰ እግዚአብሔር ተጽሕፈ ይበቍዕ በኵሉ ትምህርት ወተግሣፅ ወአርትዖ ወጥበብ ወጽድቅ ። | በእግዚአብሔር መንፈስ የተጻፈ መጽሐፍ ሁሉ ለፍጹም ትምህርት ለተግሣፅ ለማስተማር ለጥበብ ለጽድቅ ይጠቅማል ። |
| ፲፯ | ከመ ይትገሠፅ ብእሴ እግዚአብሔር ውስተ ኵሉ ምግባረ ሠናይ ። | በእግዚአብሔር ያመነ ሰው በጎውን ምግባር ሁሉ ይማር ዘንድ ። |

| **ክፍል** | **ክፍል ፭ ፡ በእንተ አዝልፎተ ትምህርት ።** | **ክፍል ፭ ፡ ተግቶ ማስተማር ስለሚገባ ።** |
| ፩ | ወእኤዝዘከ በቅድመ እግዚአብሔር ወእግዚእነ ኢየሱስ ክርስቶስ ዘሀለዎ ይኰንን ሕያዋነ ወሙታነ አመ ይመጽእ በመንግሥቱ ። | በጌትነቱ በመጣ ጊዜ በሕያዋንና በሙታን ላይ ሊፈርድ ይመጣ ባለው በጌታችን በኢየሱስ ክርስቶስና በእግዚአብሔር ፊት አዝዝሃለሁ ። |
| ፪ | ከመ ትስብክ ቃሎ ቀዊመከ በድሉው በጊዜሁ ወዘእንበለ ጊዜሁ ገሥፅ ወተአካፍ ናዝዝ ወርውህ እንዘ ትትዔገሥ በኵሉ ወትሜህር ። | በጸጥታ ቁመህ ቃሉን ታስተምር ዘንድ ፤ በጊዜውም አለጊዜውም ምከር አስተምር ፤ በሁሉ ታግሠህ ስታስተምር አጽናና አለዝብ ። |
| ፫ | እስመ ይበጽሕ ጊዜሁ አመ ኢየአብይዋ ለትምህርተ ሕይወት ፤ ወየሐውሩ በፍትወቶሙ ወያመጽኡ መምህራነ ለርእሶሙ በሁከተ እዝኒሆሙ ። | የሕይወትን ትምህርት አንቀበልም የሚሉበት ፤ ልባቸው እንደ ወደደ የሚኖሩበት ፤ በጆሮአቸው ቀበዝባዥነት ለራሳቸው መምህራንን የሚያመጡበት ጊዜ ይመጣልና ። |
| ፬ | ወይመይጡ እዝኒሆሙ እምጽድቅ ወያመጽኡ ካልአ ትምህርተ ወይትመየጡ ኀበ መኃድምት ። | እውነትን ከመስማት ጆሮአቸውን መልሰው ሌላ ትምህርት ያመጣሉ ፤ ወደ ተረትም ይመለሳሉ ። |
