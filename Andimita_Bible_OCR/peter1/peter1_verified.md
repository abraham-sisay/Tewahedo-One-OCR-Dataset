| **ክፍል** | **ክፍል ፩ ፡ በእንተ ተዐግሦ መከራ ።** | **ክፍል ፩ ፡ መከራን ስለ መታገሥ ።** |
| ፩ | እምጴጥሮስ ልኡከ እግዚእነ ኢየሱስ ክርስቶስ ፤ ለኅሩያን ለእለ ሀለዉ ውስተ በሐውርተ ጳንጦስ ወገላትያ ወቀጰዶቅያ ወአስያ ወቢታንያ ። | ጌታችን ኢየሱስ ክርስቶስን ከማገለግል ከእኔ ከጴጥሮስ የተላከች መልእክት ፤ በጳንጦስ በገላትያ በቀጶዶቅያ በእስያና በቢታንያ አገሮች ላሉ ለተመረጡ ምእመናን ። |
| ፪ | ለእለ ቀደሙ አእምሮቶ ለእግዚአብሔር አብ በመንፈስ ቅዱስ ከመ ይስምዑ በንዝኀተ ደሙ ለኢየሱስ ክርስቶስ ፤ ሞገስ ወሰላም ይብዛሕ ለክሙ ። | እግዚአብሔር አብን አስቀድመው በመንፈስ ቅዱስ ላወቁት ፤ የኢየሱስ ክርስቶስን የደሙን መፍሰስ ይመሰክሩ ዘንድ ፤ ሞገስና ሰላም ይብዛላችሁ ። |
| ፫ | ይትባረክ እግዚአብሔር አቡሁ ለእግዚእነ ኢየሱስ ክርስቶስ ዘወለደነ በብዝኀ ምሕረቱ ወለተስፋ እንተ ባቲ ነሐዩ በተንሥኦቱ ለእግዚእነ ኢየሱስ ክርስቶስ እምነ ምዉታን ። | ጌታችን ኢየሱስ ክርስቶስ ከሙታን ተለይቶ በመነሣቱ ሕይወት ለምናገኝባት ተስፋ በቸርነቱ ብዛት የወለደን የጌታችን የኢየሱስ ክርስቶስ አባቱ እግዚአብሔር ይክበር ይመስገን ። |
| ፬ | ለተዋርሶ ዘኢይበሊ ወዘኢይረኩስ ወዘኢይጸመሂ ዘዕቁብ ለነ ወለክሙ በሰማያት ። | ለእኛና ለእናንተ በልዕልና የተጠበቀልን የማያልፈውን የማይለወጠውን የማይጠፋውን ዓለም ለመውረስ ። |
| ፭ | ለእለ በኀይለ እግዚአብሔር ዕቁባን በሃይማኖት ለመድኃኒት እንተ ድሉት ከመ ታስተርኢ በደኃሪ መዋዕል ። | በኋለኛው ዘመን ትገለጥ ዘንድ ተዘጋጅታ ላለችው ድኅነት በሃይማኖት በእግዚአብሔር ኃይል ለምንጠበቀው ። |
| ፮ | ወትትፌሥሑ እስከ ለዓለም ፤ ወባሕቱ ኅዳጠ ሀለወክሙ ይእዜ ትተክዙ በዘይመጽአክሙ መከራ ዘዘዚአሁ ። | እስከ ዘላለም ደስ ይላችኋል ፤ ነገር ግን በሚመጣባችሁ ልዩ ልዩ መከራ አሁን ታዝኑ ዘንድ አላችሁ ። |
| ፯ | ከመ መከራሃ ለሃይማኖትክሙ ዘይትበደር ፈድፋደ እምወርቅ ንጹሕ ዘበእሳት አመክርዎ ወትትረከቡ ሀለወክሙ በክብር ወበስብሐት ወበውዳሴ አመ ያስተርኢ ኢየሱስ ክርስቶስ ። | በሃይማኖታችሁ ምክንያት የሚመጣው መከራ በእሳት ከፈተኑት ከጥሩ ወርቅ ይልቅ እንዲወደድ ፤ ኢየሱስ ክርስቶስ በሚገለጥበት ጊዜ በክብር በጌትነት በምስጋና ትገኙ ዘንድ አላችሁ ። |
| ፰ | ውእቱኬ ዘታፈቅርዎ እንዘ ኢትሬእይዎ ፤ ወእስከ ይእዜ ኢርኢክምዎ ፤ ወባሕቱ ተአምኑ ቦቱ ፤ ወይእዜሂ ትትፌሥሑ በፍሥሓ እንተ አልባቲ ማኅለቅት ። | እርሱም ሳታዩት የምትወዱት ነው ፤ እስከ ዛሬም ድረስ ታምኑበታላችሁ እንጂ አላያችሁትም ፤ አሁንም ፍጻሜ በሌላት ደስታ ደስ ይላችኋል ። |
| ፱ | ወትነሥኡ በፍጻሜሃ ለሃይማኖትክሙ መድኀኒተ ነፍስክሙ ። | በሃይማኖታችሁም ፍጻሜ የነፍሳችሁን ድኅነት ታገኛላችሁ ። |
| ፲ | ይእቲኬ መድኃኒት እንተ ኀሠሥዋ ወዖድዋ ነቢያት እለ ተነበዩ በእንተ ክብርክሙ ። | ስለ ክብራችሁ ትንቢት የተናገሩ ነቢያት ፈልገው የመረመሯት ድኅነት ይህች ናት ። |
| ፲፩ | እንዘ የኀሥሡ ለአይ ወለማእዜ መዋዕል ዘነገረ በእንቲአሁ በላዕሌሆሙ መንፈሱ ለኢየሱስ ክርስቶስ ወአቅደመ ስምዐ ከዊነ በእንተ ዘሀለዎ ይሕምም ክርስቶስ ወበእንተ ስብሐቲሁ ዘእምድኅሬሁ ። | በእነሱ ላይ ያደረው የክርስቶስ መንፈስ ስለ ክርስቶስ መከራና ከመከራው በኋላ ስለሚሆነው ክብሩ አስቀድሞ ሲመሰክር ፤ ለመቼና እንዴት ላለ ዘመን እንዳመለከተ ይመረምሩ ነበር ። |
| ፲፪ | እስመ አስተርአዮሙ ወአኮ በርእሶሙ ዘነገሩክሙ ዘንተ ዘይእዜ ንዜንወክሙ አላ አይድዑክሙ በመንፈስ ቅዱስ ዘተፈነወ እምሰማይ እምኀበ ያፈትዎሙ ለመላእክት ከመ የሐውጽዎ ። | ተገልጦላቸዋልና እኛ ዛሬ የምንነግራችሁን የነገሯችሁ ከራሳቸው አንቅተው አይደለም ፤ መላእክት ሊያዩት ከሚመኙት ከሰማይ በተላከ በመንፈስ ቅዱስ ተገልጦላቸው ነገሯችሁ እንጂ ። |
| **ክፍል** | **ክፍል ፪ ፡ በእንተ ተሰፍዎ ሐዲስ ዓለም ።** | **ክፍል ፪ ፡ አዲሱን ዓለም ተስፋ ስለ ማድረግ ።** |
| ፲፫ | ወይእዜኒ ቅንቱ ሐቌ ልብክሙ ጥዩቀ ወንቁሓ ተሰፈውዋ ለእንተ ትመጽእ ለክሙ ትፍሥሕት በአስተርእዮቱ ለኢየሱስ ክርስቶስ ። | አሁንም የልቡናችሁን ወገብ ታጥቃችሁ ነቅታችሁ በመጠን ኑሩ ፤ በኢየሱስ ክርስቶስ መገለጥ የምትመጣላችሁን ደስታ ተጠባበቁ ። |
| ፲፬ | ከመ ውሉድ እለ ይትኤዘዙ እንዘ ኢትትመየጡ ለእንተ ቀዳሚ ጌጋይክሙ በኢያእምሮ ዘፈተውክሙ ። | እንደሚታዘዙ ልጆች ሳታውቁ ትከተሉት ወደ ነበረ ወደ ቀድሞው ምኞታችሁ ሳትመለሱ ። |
| ፲፭ | ወባሕቱ በከመ ዘጸውዐክሙ ቅዱስ ውእቱ አንትሙሂ ኩኑ ቅዱሳነ በኩሉ ግዕዝክሙ ። | ነገር ግን የጠራችሁ እርሱ ቅዱስ እንደ ሆነ እናንተም በኑሯችሁ ሁሉ ቅዱሳን ሁኑ ። |
| ፲፮ | እስመ ጽሑፍ ዘይብል ኩኑ ቅዱሳነ እስመ ቅዱስ አነ ። | «እኔ ቅዱስ ነኝና እናንተም ቅዱሳን ሁኑ» የሚል ተጽፏልና ። |
| ፲፯ | ወእመሰ ለአብ ትጼውዕዎ ለዘይኬንን እንዘ ገጸ ኢይነሥእ በበምግባሪሁ ለለአሐዱ እንዘ ትፈርሁ በኩሉ መዋዕለ ሕይወትክሙ ወበዘአመንክሙ ሑሩ ባቲ ። | ለእያንዳንዱ እንደ ሥራው ሳያዳላ የሚፈርደውን አብን የምትጠሩት ከሆናችሁ ፤ በሕይወታችሁ ዘመን ሁሉ ፈርታችሁ ባመናችሁበት ፀንታችሁ ኑሩ ። |
