## ምዕራፍ ፫

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| ፩ | ወከማሁ አንትንሂ አንስት ተኩነና ለአምታቲክን ፤ ከመ እመቦ ዘኢየአምን በዝንቱ ነገር እምሥነ ምግባሪሆን ለአንስት ይርአዩ ወዘእንበለ ካሕድ ይርብሕዋ ለነፍሶሙ ። | እንዲሁ እናንተም ሴቶች ለባሎቻችሁ ተገዙ ፤ በዚህ ነገር የማያምን ቢኖር ሴቶች ከሚሠሩት መልካም ሥራ ወገን አንዱን አይተው ያለ ጥርጥር ሰውነታቸውን ይጠቅሟት ዘንድ ። |
| ፪ | ወእንዘ ትፈርሃ አሠንያ ግዕዝክን በንጽሕ ። | እየፈራችሁም በንጽሕና ኑሯችሁን አሳምሩ ። |
| ፫ | አኮ ከመ ታድልዋ ለዐይን ሰብእ በተጸፍሮ ሥዕርትክን ወአኮ በተሠርግዎ ወርቅ ወብሩር ወአኮ በተላብሶ አልባስ ዘብዙኅ ሜጦ ። | ራስ ፀጕራችሁን በመሠራት ለሰው ይምሰል እንድትሠሩ አይደለም ፤ በወርቅና በብር በማጌጥ ወይም ዋጋው ብዙ የሆነ ልብስ በመልበስ አይደለም ። |
| ፬ | አላ በኅቡእ ልቡ ለሰብእ ለዘኢይጠፍእ ወለዘኢይደምፅ መንፈስ ቅዱስ ዘህልው ቅድመ እግዚአብሔር ዘብዙኅ ሐሳቡ ። | ሀብቱ ብዙ በሆነ በእግዚአብሔር ሀልውና ላለ ለማይጠፋና ለማይሰማ መንፈስ ቅዱስ ማደሪያ ለመሆን በሰው ውስጣዊ ልብ ነው እንጂ ። |
| ፭ | ወከማሁ ትካትኒ ቅዱሳት አንስት እለ ይትዌከላ ላዕለ እግዚአብሔር ይሠረገዋ ርእሶን በተኩንኖ ለአምታቲሆን ። | ቀድሞም በእግዚአብሔር የታመኑ ቅዱሳት ሴቶች ለባሎቻቸው በመገዛት ራሳቸውን ያስጌጡ ነበርና ። |
| ፮ | ከመ ሣራ እስመ ይእቲ ትትኤዘዞ ለአብርሃም ወእግዚእየ ትብሎ ፤ ወአንትንሂ አዋልዲሃ ኩና በምግባረ ሠናይ እንዘ ኢትፈርሃ እምነ ድንጋፄ ወኢምንተኒ ። | እንደ ሣራ ፤ እርሷ አብርሃምን ትታዘዘው ነበርና «ጌታዬ» ትለውም ነበርና ፤ እናንተም መልካም እያደረጋችሁ ከድንጋፄ የተነሣ ምንም ሳትፈሩ ልጆቿ ሁኑ ። |
| ፯ | ወከማሁ አንትሙሂ እደው እንዘ ትነብሩ ምስለ አንስቲያክሙ ኢታስተሐቅሩ አንስቲያክሙ እስመ ይደክም ፍጥረተ ዚአሆን ለአንስት ፤ አክብሩ አንስቲያክሙ እስመ ይወርሳ እማንቱኒ ክብረ ወሕይወተ ምስሌክሙ ከመ ኢትትዐቀፍ ጸሎትክሙ ። | እናንተም ባሎች ከሚስቶቻችሁ ጋር ስትኖሩ ሚስቶቻችሁን አታቃልሉ ፤ የሴቶች ተፈጥሯቸው ደካማ ነውና አክብሯቸው ፤ እነርሱም ከእናንተ ጋር የሕይወትን ክብር ይወርሳሉና ጸሎታችሁ እንዳይሰናከል ። |
| ፰ | ወማዕለቀቱሰ ለኩሉ ከመ ተዐርዩ ልበ በአሐዱ ሕሊና እንዘ ተሐምሙ ሕማመ ቢጽክሙ ። | የሁሉ ማጠቃለያ ግን የወንድሞቻችሁን መከራ እየተቀበላችሁ በአንድ አሳብ ትኖሩ ዘንድ ነው ። |
| ፱ | ወእንዘ ኢታሀብዩ ልበክሙ ወእንዘ ኢትፈድይዎ እኪተ ለዘገብረ ለክሙ እኪተ ወእንዘ ኢትኤልዎ ለዘጸአለክሙ ፤ ወለጸላኢክሙኒሂ ባርክዎ እስመ ለዝንቱ ተጸዋዕክሙ ከመ በረከተ ትረሱ ። | ልባችሁን ሳታስታብዩ ፤ ክፉ ላደረገባችሁም ክፉ ሳትመልሱ ፤ የሰደባችሁንም ሳትሰድቡ ፤ ጠላታችሁንም መርቁት ፤ በረከትን ትወርሱ ዘንድ ለዚህ ተጠርታችኋልና ። |
| ፲ | ወዘሰ ያፈቅራ ለሕይወት ወይፈቱ ይርአይ መዋዕለ ሠናያተ ያርምም ልሳኖ እምእኪት ወከናፍሪሁኒ ከመ ኢይንብባ ሐሰተ ። | ሕይወትን የሚወድ መልካም ቀኖችንም ሊያይ የሚሻ ፤ አንደበቱን ከክፉ ነገር ይከልክል ፤ ከንፈሮቹም ተንኰልን እንዳይናገሩ ይከልክላቸው ። |
| ፲፩ | ይትገኀሥ እምእኪት ወይግበራ ለሠናይት ፤ ለይኅሥሣ ለሰላም ወይትልዋ ። | ከክፉ ነገር ይራቅ በጎ ሥራንም ይሥራ ፤ ሰላምን ይሻ ይከተላትም ። |
| ፲፪ | እስመ አዕይንቲሁ ለእግዚአብሔር ኀበ ጻድቃኑ ወእዝኑሂ ኀበ ስእለቶሙ ፤ ገጹ ለእግዚአብሔር ኀበ እለ ይገብሩ እኪተ ። | የእግዚአብሔር ዓይኖቹ ወደ ጻድቃን ናቸውና ፤ ጆሮዎቹም ወደ ጸሎታቸው ናቸውና ፤ የእግዚአብሔር ፊቱ ግን ክፉ በሚሠሩት ላይ ነው ። |
| ፲፫ | ወመኑ ውእቱ ዘእኪተ ይፈቅድ ለክሙ እመ ትቀንኡ ለገቢረ ሠናይ ። | ለበጎ ሥራ የምትቀኑ ከሆናችሁ ክፉ ሊያደርግባችሁ የሚወድ ማነው ?  |
| ፲፬ | ወእመሰ በገቢረ ጽድቅ ተሐምሙ ብፁዓን አንትሙ ፤ ወዘሰ ይጌርመክሙ ኢትፍርሁ ወኢትደንግፁ ፤ አላ ለእግዚአብሔር ቀድስዎ በኩሉ ልብክሙ ። | ስለ ጽድቅ እንኳን መከራን ብትቀበሉ ብፁዓን ናችሁ ፤ የሚያስፈራችሁንም አትፍሩ አትደንግጡም ፤ ነገር ግን እግዚአብሔርን በልባችሁ ቀድሱት ። |
| ፲፭ | ወድልዋኒክሙ ሀልዉ በኩሉ ጊዜ ከመ ታውሥእዎሙ ቃለ ለእለ ይስእሉክሙ በእንተ ዛቲ ተስፋክሙ ። | ስለ ተስፋችሁ ለሚጠይቋችሁ ሁሉ ምላሽ ለመስጠት ዘወትር የተዘጋጃችሁ ሁኑ ። |
| ፲፮ | ወበየውሃትክሙ ወበፍርሃተ እግዚአብሔር አሠንዩ ግዕዝክሙ ከመ እመቦ እለ ይሔምዩክሙ ከመ ዘእኩይ ምግባሪክሙ ይትኀፈሩ እለ ይሔምዩክሙ እምሥነ ምግባሪክሙ ዘበእንተ ክርስቶስ ። | በገርነትና በእግዚአብሔር ፍርሃት ኑሯችሁን አሳምሩ ፤ እንደ ክፉ አድራጊዎች አድርገው የሚያሟችሁ ስለ ክርስቶስ ካለው ከመልካም ኑሯችሁ የተነሣ ያፍሩ ዘንድ ። |
| ፲፯ | እስመ ይጌይስ እንዘ ሠናየ ትገብሩ ወትፈቅዱ ፈቃዶ ለእግዚአብሔር ትሕምሙ እምነ እንዘ እኪተ ትገብሩ ። | የእግዚአብሔር ፈቃድ ቢሆን ክፉ እየሠራችሁ መከራን ከመቀበል በጎ እየሠራችሁ መከራን ብትቀበሉ ይሻላልና ። |
