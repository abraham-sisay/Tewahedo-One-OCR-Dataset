| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፫ ፡ ዘከመ ይደሉ ጸልዮ እምድኅነተ ሰብእ እኩያን ።** | **ክፍል ፫ ፡ ከክፉ ሰዎች ለመዳን መጸለይ እንዲገባ ።** |
| ፩ | ወይእዜኒ አኀዊነ ጸልዩ ለነ ከመ ይሩጽ ቃለ እግዚአብሔር ወይሰባሕ በከመ በኀቤክሙ ። | አሁንም ወንድሞቻችን! የእግዚአብሔር ቃል ከእናንተ እንደ ደረሰ እንዲሁ ከሁሉ ዘንድ እንዲደርስ ጸልዩልን ። |
| ፪ | ወከመ ንድኃን እምሰብእ እኩያን ወዐላውያን እስመ አኮ ኵሉ ዘየአምን ። | ከክፉ ሰዎችና ከከሐዲዎች አንድን ዘንድ ፤ ሁሉ በእግዚአብሔር የሚያምን አይደለምና ። |
| ፫ | ወእግዚአብሔርሰ ምእመን ወጻድቅ ዘያጸንዐክሙ ወየዐቅበክሙ እምኵሉ እኩይ ። | ከክፉ ሁሉ የሚጠብቃችሁና የሚያፀናችሁ እግዚአብሔር ግን የታመነ እውነተኛ አምላክ ነው ። |
| ፬ | ንትአመነክሙ ምስለ እግዚአብሔር ከመ ትግበሩ ዘአዘዝናክሙ ወገበርክሙሂ ። | ከእግዚአብሔር ጋር ያዘዝናችሁን እንደምታደርጉ እንታመንባችኋለን ከዚህ በፊትም አድርጋችኋል ። |
| ፭ | ወእግዚእነ ያርትዕ ልበክሙ ውስተ ፍቅረ እግዚአብሔር ወውስተ ተስፋሁ ለክርስቶስ ። | ጌታችንም ልቡናችሁን እግዚአብሔርን ወደ መውደድና ወደ ክርስቶስ ተስፋ ያቅናው ። |
| **ክፍል** | **ክፍል ፬ ፡ ዘከመ ይደሉ በሊዕ በተቀንዮ ።** | **ክፍል ፬ ፡ ሠርቶ መብላት ስለሚገባ ።** |
| ፮ | አኀዊነ ንኤዝዘክሙ በስመ እግዚእነ ኢየሱስ ክርስቶስ ተገኃሥዎሙ ለኵሎሙ ቢጽ እለ የሐውሩ በትምይንት ወአኮ በሥርዐት ዘሠራዕናሆሙ ። | ወንድሞቻችን! በሠራንላቸው ሥርዓት ያይደለ በተንኰል የሚሄዱትን ሰዎች ሁሉ ተለዩዋቸው ብለን በጌታችን በኢየሱስ ክርስቶስ እናዝዛችኋለን ። |
| ፯ | ለሊክሙ ተአምሩ ከመ ርቱዕ ትትመሰሉነ ከመ ኢሰሳዕነ ላዕሌክሙ ። | እኛ በእናንተ ላይ እንዳልሳሳን ሁሉ እናንተም እኛን ትመስሉን እንዲገባ እናንተ ራሳችሁ ታውቃላችሁ ። |
| ፰ | ወኢበላዕነ እክለ ባዕድ በከንቱ ዘእንበለ ዳእሙ ወንሠርሕ መዓልተ ወሌሊተ ወንትጌበር ከመ ኢናክብድ ላዕሌክሙ ። | እናንተን እንዳናስቸግር በመዓልትም በሌሊትም ሠርተን የደከምንበትን እንጂ የሌላውን እህል በከንቱ አልበላንም ። |
| ፱ | ወአኮሰ ዘኢኮነ ብዉሐነ ዳእሙ አርአያ ከመ ንኩንክሙ ከመ አንትሙ ትትመሰሉነ ። | ግን የማይገባን ሆኖ አይደለም እናንተ ትመስሉን ዘንድ አብነት እንድንሆናችሁ ነው እንጂ ። |
| ፲ | ወአመሂ ሀለውኩ ኀቤክሙ ዘንተ አዘዝኩክሙ ዘኢይፈቅድ ይትቀነይ ኢይሴሰይ ። | ከእናንተም ዘንድ በነበርኩ ጊዜ ይህን አዝዣችኋለሁ ሊሠራ የማይወድ አይብላ ብዬ ። |
| ፲፩ | ሰማዕነ ከመ ቦ እምውስቴትክሙ እለ የሐውሩ በሁከት ወአልቦ ዘይትቀነዩ ዓዲ መስተሐውራን ። | በመካከላችሁ በማወክ የሚኖሩ የሚሠሩት የሌላቸው በዚያውም ላይ ነገር አዋሳጆች እንዳሉ ሰምተናል ። |
| ፲፪ | ወለእለ ከመዝ ንኤዝዞሙ ወንገሥፆሙ በስሙ ለእግዚእነ ኢየሱስ ክርስቶስ ከመ በየውሃት ወበጽምው ይትገበሩ ተግባሮሙ ወይሴሰዩ ሲሳዮሙ ። | እንደነዚህ ያሉትን በቅንነት በፀጥታ እየሠሩ ምግባቸውን እንዲመገቡ በጌታችን በኢየሱስ ክርስቶስ ስም እንመክራቸዋለን እናዝዛቸዋለን ። |
| ፲፫ | ወአንትሙሂ አኀዊነ ኢትትሀክዩ ገቢረ ሠናይ ኵሎ ጊዜ ። | ወንድሞቻችን! እናንተም ሁል ጊዜ በጎ ሥራ መሥራትን ቸል አትበሉ ። |
| ፲፬ | ወእመቦ ዘኢይትኤዘዝ ለቃልክሙ ወለመጽሐፍክሙ ይትፈለጥ ወኢትትሀወልዎ ከመ ይትኃፈር ። | ለቃላችሁና ለመጽሐፋችሁ የማይታዘዝ ቢኖር ይለይ እንዲያፍር አትቀላቀሉት ። |
| ፲፭ | ወከመሰ ጸላኢ ኢትረስይዎ አላ ገሥፅዎ ከመ እኁክሙ ። | እንደ ጠላት ግን አታድርጉት ወንድማችሁ እንደመሆኑ ምከሩት ገሥፁት እንጂ ። |
| ፲፮ | ወውእቱ አምላከ ሰላም የሀብክሙ ሰላመ በኵሉ ጊዜ ወበኵሉ ግብር ፤ ወእግዚእነ የሃሉ ምስለ ኵልክሙ ። | የሰላም አምላክ እርሱ ሁል ጊዜ በሥራው ሁሉ አንድነቱን ይስጣችሁ ፤ ጌታችን ከሁላችሁ ጋር ይኑር ። |
| ፲፯ | ዘንተ አምኃ ዘጸሐፍኩ ለክሙ በእዴየ አነ ጳውሎስ ፤ ወዝንቱ ትእምርትየ ውስተ ኵሉ መጻሕፍትየ ከመዝ እጽሕፍ ። | ይህን ሰላምታ በእጄ የጻፍኩላችሁ እኔ ጳውሎስ ነኝ ፤ በመጻሕፍቶቼ ሁሉ ምልክቴ ይህ ነው እንዲህ እጽፋለሁ ። |
| ፲፰ | ጸጋሁ ለእግዚእነ ኢየሱስ ክርስቶስ የሃሉ ምስለ ኵልክሙ ፤ አሜን ። | የጌታችን የኢየሱስ ክርስቶስ ጸጋ ከሁላችሁ ጋር ይሁን ፤ አሜን ። |

## መደምደሚያ (Colophon)

| ክፍል | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **መደምደሚያ** | **ተፈጸመት ካልእት መልእክት ኀበ ሰብአ ተሰሎንቄ ወተጽሕፈት በሎዶቅያ ወተፈነወት በእደ ጢኪቆስ ፤ ወስብሐት ለእግዚአብሔር ፤ አሜን ።** | **በሎዶቅያ ተጽፋ በጢኪቆስ እጅ ወደ ተሰሎንቄ ሰዎች የተላከችው ሁለተኛይቱ መልእክት ተፈጸመች ። ለእግዚአብሔር ምስጋና ይሁን ፤ አሜን ።** |
