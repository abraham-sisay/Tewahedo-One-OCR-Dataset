| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፩ ፡ በእንተ ተመክሖ በእንተ ፍቅረ አኀው ።** | **ክፍል ፩ ፡ በወንድሞች መፋቀር ስለ መመካት ።** |
| **፩** | እምጳውሎስ ወስልዋኖስ ወጢሞቴዎስ ለቤተ ክርስቲያን ዘተሰሎንቄ ምእመናን በእግዚአብሔር አቡነ ወእግዚእነ ኢየሱስ ክርስቶስ ። | ከጳውሎስ ከስልዋኖስና ከጢሞቴዎስ በአባታችን በእግዚአብሔር በጌታችን በኢየሱስ ክርስቶስ አምነው በተሰሎንቄ ላሉ ምእመናን ትድረስ ። |
| **፪** | ሰላም ለክሙ ወጸጋ እግዚአብሔር አቡነ ወእግዚእነ ኢየሱስ ክርስቶስ ። | ሰላም ለእናንተ ይሁን ፤ የአባታችን የእግዚአብሔር የጌታችን የኢየሱስ ክርስቶስ ጸጋ ይደረግላችሁ ። |
| **፫** | ርቱዕ ነአኵቶ ለእግዚአብሔር በኵሉ ጊዜ በእንቲአክሙ አኀዊነ በከመ ይደልዎ ፤ እስመ ዐብየት ሃይማኖትክሙ ፤ ወፈድፈደት ተፋቅሮትክሙ ምስለ ኵሉ ቢጽክሙ ። | ወንድሞቻችን የሚገባው እንደ መሆኑ ስለ እናንተ ዘወትር እግዚአብሔርን ልናመሰግነው ይገባል ፤ ሃይማኖታችሁ ጸንታለችና ከወንድሞቻችሁ ሁሉ ጋራም ፍቅራችሁ በዝታለችና ። |
| **፬** | ከመ ንሕነሂ ንትመካሕ ብክሙ በቤተ ክርስቲያኑ ለእግዚአብሔር ፤ በእንተ ሃይማኖትክሙ ወትዕግሥትክሙ በሕማምክሙ ወምንዳቤክሙ ዘትትዐገሡ ወትትዌከፉ ። | እኛም ታግሣችሁ ስለምትቀበሉት መከራችሁና ሥቃያችሁ ፤ በእግዚአብሔር ቤተ ክርስቲያን ፊት እንመካባችሁ ዘንድ ። |
| **፭** | ከመ ታርእዩ ኵነኔ ጽድቁ ለእግዚአብሔር ፤ ከመ ይክፍልክሙ መንግሥቶ ዘበእንቲአሁ ተሐምሙ ። | የእግዚአብሔርን እውነተኛ ፍርዱን ትገልጹ ዘንድ ፤ ስለ እርሱ መከራ የምትቀበሉለት መንግሥቱን ያድላችሁ ዘንድ ። |
| **፮** | ወርቱዕሰ ይትፈደዩ በኀበ እግዚአብሔር ሕማመ እለ ያሐምሙክሙ ። | መከራ የሚያጸኑባችሁ ግን በእግዚአብሔር ዘንድ ፍዳቸውን ሊቀበሉ ይገባል ። |
| **፯** | ወለክሙ ለእለ ተሐምሙ ዕረፍት ምስሌነ በምጽአቱ ለእግዚእነ ኢየሱስ ክርስቶስ እምሰማያት ፤ ምስለ መላእክተ ኃይሉ ። | መከራ ለምትቀበሉ ለእናንተስ ጌታችን ኢየሱስ ክርስቶስ ከሃሊነቱን የሚገልጥባቸው መላእክትን አስከትሎ በመጣ ጊዜ ፤ ከእኛ ጋራ ዕረፍት አላችሁ ። |
| **፰** | ከመ ይትበቀሎሙ በነደ እሳት ለእለ ኢየአምርዎ ለእግዚአብሔር ፤ ወለእለ ኢይሰምዑ ትምህርተ ወንጌሉ ለእግዚእነ ኢየሱስ ክርስቶስ ። | እግዚአብሔርን በማያውቁት ፤ የጌታችን የኢየሱስ ክርስቶስ የወንጌሉን ትምህርት የማይሰሙትን በሚያቃጥል እሳት ይበቀላቸው ዘንድ ። |
| **፱** | ወይረክቡ ፍዳሆሙ ኵነኔ ኅጐል ወተሠርዎ ዘለዓለም ፤ እምቅድመ ገጹ ለእግዚእነ ወእምስብሐተ ኃይሉ ። | ከጌታችን ፊትና ከከሃሊነቱ ጌትነትም የተነሣ ፤ ብድራቸውን የጥፋት ፍዳቸውንና የዘለዓለም መነቀልን ያገኛሉ ። |
| **፲** | አመ ይመጽእ ይሴባሕ በቅዱሳኒሁ ፤ ወይትአኰት በእለ የአምኑ ቦቱ ፤ እስመ ይትአመነነ ስምዕነ በላዕሌክሙ በይእቲ ዕለት ። | በቅዱሳኑ ይገለጽ ዘንድ በሚያምኑበትም ይመሰገን ዘንድ በመጣ ጊዜ ፤ በዚያች ቀን ስለ እናንተ የመሰከርነው ምስክርነታችን ይታመንልናልና ። |
| **፲፩** | በእንተዝ እጼሊ ዘልፈ በእንቲአክሙ ፤ ከመ ይክፍልክሙ ርስቶ ዘጸውዐክሙ እግዚአብሔር ፤ ወይፈጽም ለክሙ ኵሎ ሣህሎ ወሠናይቶ ወምግባረ ሃይማኖት በኃይሉ ። | ስለዚህም ሁልጊዜ ስለ እናንተ እጸልያለሁ ፤ እግዚአብሔር እናንተን የጠራበትን ርስቱን ያድላችሁ ዘንድ ፤ ይቅርታውንና ቸርነቱን ሁሉ በከሃሊነቱ አምናችሁ በምትሠሩበት ሥራ ይፈጽምላችሁ ዘንድ ። |
| **፲፪** | ከመ ይሰባሕ ስሙ ለእግዚእነ ኢየሱስ ክርስቶስ በላዕሌክሙ ወአንትሙሂ ቦቱ ፤ ወበከመ ጸጋሁ ለአምላክነ ወእግዚእነ ኢየሱስ ክርስቶስ ወአንትሙሂ ተሀልዉ ቦቱ ። | የጌታችን የኢየሱስ ክርስቶስ ስም በእናንተ ይገለጽ ዘንድ እናንተም በእርሱ ትጸኑ ዘንድ ፤ ፈጣሪያችን ጌታችን ኢየሱስ ክርስቶስ እንደሚያደርግላችሁ ቸርነት መጠን ፤ እናንተም በእርሱ አምናችሁ ትኖሩ ዘንድ ። |

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፪ ፡ በእንተ ምጽአቱ ለእግዚእነ ።** | **ክፍል ፪ ፡ ስለ ጌታችን መምጣት ።** |
| **፩** | ንነግረክሙ አኀዊነ በእንተ ምጽአተ እግዚእነ ኢየሱስ ክርስቶስ ። | ወንድሞቻችን ስለ ጌታችን ኢየሱስ ክርስቶስ መምጣት እንነግራችኋለን ። |
| **፪** | ወአንትሙሂ ውስተ ማኅበሩ ዑቁ ወኢያደንግፁክሙ ፍጡነ ፤ ወኢትትሀወኩ እምአእምሮ ኢ በመንፈስ ወኢ በነገር ወኢ በመጽሐፍ ከመ ዘእምኀቤነ ፤ ለእመ ትመጽእ ዕለተ እግዚእነ ። | በአንድነቱ ውስጥ ያላችሁ እናንተም ዕወቁ ፤ አሁን ይመጣል ብለው አያስደንግጧችሁ ፤ ከዕውቀት ወጥታችሁ አትሸበሩ ፤ መንፈስ ቅዱስ አናገረን ቢሉ አንደበት አስተማረን ቢሉ መጽሐፍን ቢጽፉ አትሸበሩ ። |
| **፫** | አልቦ ዘያስሕተክሙ ወኢ በምንትኒ ፤ እስመ ኢትመጽእ ይእቲ ዕለት ለእመ ኢቀደመ መጺአ ዘየሀውክ ፤ ወይትከሠት ብእሴ ዐመፃ ወልደ ሕርትምና ። | በምንም በምን የሚያስታችሁ አይኑር ፤ ሕዝብን የሚያውከው (ሐሳዌ መሲሕ) ከመምጣቱ በፊት ያች ቀን አትመጣምና ፤ የዐመፅ ሰው በኃጢአት የተወለደው መጥቶ ካልተገለጠ ። |
