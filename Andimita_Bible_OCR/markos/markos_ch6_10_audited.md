| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፳ወ፫ ፤ በእንተ ስብከቱ በናዝሬት ።** | **ክፍል ፳ወ፫ ፤ በእንተ ስብከቱ በናዝሬት ።** |
| **፩** | ወወፂኦ እምህየ ቦአ ሀገሮ ወተለውዎ አርዳኢሁ። | ከዚያም ወጥቶ ወደ ገዛ አገሩ መጣ፤ ደቀ መዛሙርቱም ተከተሉት። (ማቴ. ፲፫፡፶፫-፶፰፣ ሉቃ. ፬፡፲፮-፴) |
| **፪** | ወበሰንበት መሀሮሙ በምኩራብ ወብዙኃን ያጸምእዎ ወያነክሩ እንዘ ይብሉ እምአይቴ ሎቱ ዝንቱ ኵሉ ትምህርት ወምንትኑ ዛቲ ጥበብ እንተ ተውህበት ሎቱ፤ ወዝኒ ኃይል ዘይትገበር በእደዊሁ። | በሰንበትም በምኩራብ ያስተምር ጀመር፤ ብዙዎችም ሰምተው ተደነቁና፦ «ይህን ሁሉ ከወዴት አገኘው? የተሰጠችው ይህች ጥበብ በእጁም የሚደረጉት እነዚህ ድንቅ ተአምራት ምንድር ናቸው?» አሉ። |
| **፫** | አኮኑ ዝንቱ ውእቱ ወልዱ ለፀራቢ ወወልደ ማርያም፤ ወአኃዊሁሂ ያዕቆብ ወዮሳ ወይሁዳ ወስምዖን፤ ወአኮኑ አኃቲሁኒ ሀለዋ ዝየ ኀቤነ፤ ወተዐቅፉ በአንቲአሁ። | «ይህ ጸራቢው የማርያም ልጅ የያዕቆብም የዮሳም የይሁዳም የስምዖንም ወንድም አይደለምን? እኅቶቹስ በዚህ ከእኛ ጋር ያሉ አይደሉምን?» ተሰናከሉበትም። |
| **፬** | ወይቤሎሙ እግዚእ ኢየሱስ ኢኮነ ምኑነ ነቢይ ዘእንበለ በሀገሩ ወበቤቱ ወበኀበ አዝማዲሁ። | ጌታ ኢየሱስ ግን፦ «ነቢይ ከገዛ አገሩና ከዘመዶቹ ከገዛ ቤቱም በቀር ሳይከበር አይቀርም» አላቸው። |
| **፭** | ወኢገብረ ኃይለ በህየ ዘእንበለ ለኅዳጣን ድዉያን አንበረ እዴሁ ዲቤሆሙ ወፈወሶሙ። | በጥቂቶች በሽተኞች ላይ እጁን ጭኖ ከፈወሳቸው በቀር በዚያ ምንም ተአምር ሊያደርግ አልቻለም። |
| **፮** | ወአንከረ በእንተ ዕበደ ሃይማኖቶሙ፤ ወነዐወ ውስተ አህጉር እንዘ ይሜህር። | ስለ አለማመናቸውም ተደነቀ፤ በመንደሮቹም ሁሉ እያስተማረ ዞረ። |
| **አርእስት** | **ክፍል ፳ወ፬ ፤ በእንተ ፈንዎቱ ሐዋርያተ ይስብኩ ።** | **ክፍል ፳ወ፬ ፤ በእንተ ፈንዎቱ ሐዋርያተ ይስብኩ ።** |
| **፯** | ወጸውዖሙ ለዐሠርቱ ወክልኤቱ ሐዋርያት ወፈነዎሙ በበክልኤቱ ወአብሖሙ ላዕለ አጋንንት እኩያን። | ዐሥራ ሁለቱንም ሐዋርያት ጠርቶ ሁለት ሁለት አድርጎ ይልካቸው ጀመር፤ በርኩሳን መናፍስትም ላይ ሥልጣን ሰጣቸው። (ማቴ. ፲፡፩-፲፭፣ ሉቃ. ፱፡፩-፮) |
| **፰** | ወአዘዞሙ ከመ አልቦ ዘይሰንቁ ወኢይንሥኡ ለፍኖት ዘእንበለ በትር ባሕቲታ፤ ወኢኅብስተ ወኢጽፍነተ ወኢጸሪቀ ውስተ ቅናቶሙ። | ለመንገድም ከበትር በቀር እንጀራም ቢሆን ከረጢትም ቢሆን በመቀነታቸውም መሐለቅ ቢሆን እንዳይዙ አዘዛቸው፤ |
| **፱** | ዘእንበለ አሣእን ዘውስተ እገሪሆሙ ወኢይልበሱ ክልኤ ክዳናተ። | በእግራቸውም ጫማ እንዲያደርጉና ሁለት እጀ ጠባብ እንዳይለብሱ አዘዛቸው። |
| **፲** | ወይቤሎሙ ቤተ ኀበ ቦአክሙ ህየ ንበሩ እስከ አመ ትወፅኡ እምህየ። | አላቸውም፦ «በማናቸውም ስፍራ ወደ ቤት ብትገቡ ከዚያ እስክትወጡ ድረስ በዚያው ተቀመጡ። |
| **፲፩** | ወብሔረ ኀበ ኢተወክፉክሙ ወኢሰምዑክሙ ወፂአክሙ እምህየ ንግፉ ጸበለ እገሪክሙ ከመ ይኩን ስምዐ ላዕሌሆሙ፤ አማን እብለክሙ ከመ ይረክባ ሳሕተ ሰዶም ወገሞራ አመ ዕለተ ደይን እምይእቲ ሀገር። | ከማይቀበሏችሁና ከማይሰሟችሁ ስፍራ ሁሉ ከዚያ ስትወጡ ምስክር እንዲሆንባቸው ከእግራችሁ በታች ያለውን ትቢያ አራግፉ፤ እውነት እላችኋለሁ በፍርድ ቀን ከዚያች ከተማ ይልቅ ለሰዶምና ለገሞራ ይቀልላቸዋል»። |
| **፲፪** | ወወፂኦሙ ሰበኩ ውስተ ኵሉ አህጉር ከመ ኵሉ ይነስሑ። | ወጥተውም ሰዎች ንስሐ እንዲገቡ ሰበኩ። |
| **፲፫** | ወብዙኃነ አጋንንተ ያወፅኡ ወይቀብእዎሙ ቅብአ ለብዙኃን ድዉያን ወየሐይዉ። | ብዙ አጋንንትንም አወጡ፤ ብዙ ድዉያንንም ዘይት እየቀቡ ፈወሷቸው። |
| **አርእስት** | **ክፍል ፳ወ፭ ፤ በእንተ ዮሐንስ ወሄሮድስ ።** | **ክፍል ፳ወ፭ ፤ በእንተ ዮሐንስ ወሄሮድስ ።** |
| **፲፬** | ወሰሚዖ ሄሮድስ ንጉሥ እስመ ክሥተ ኮነ ስሙ፤ ወይቤ ዮሐንስ መጥምቅ ተንሥአ እሙታን ወበእንተዝ ይረድኦ ኃይል፤ | ስሙም ስለ ተገለጠ ንጉሡ ሄሮድስ ሰማ፤ አንዳንዶችም፦ «መጥምቁ ዮሐንስ ከሙታን ተነሥቷል ስለዚህም ተአምራት በእርሱ ይደረጋል» ይሉ ነበር። (ማቴ. ፲፬፡፩-፲፪፣ ሉቃ. ፱፡፯-፱) |
| **፲፭** | ወቦ እለ ይቤሉ ኤልያስ ውእቱ፤ ወቦ እለ ይቤሉ ነቢይ ውእቱ፤ ወእመ አኮ ይቤሉ ከመ አሐዱ እምነቢያት። | ሌሎችም፦ «ኤልያስ ነው» አሉ፤ ሌሎችም፦ «ከቀደሙት ነቢያት እንደ አንዱ ነቢይ ነው» አሉ። |
| **፲፮** | ወሰሚዖ ሄሮድስ ይቤ ዮሐንስ ውእቱ ዘአነ መተርኩ ርእሶ ውእቱ ተንሥአ እሙታን። | ሄሮድስ ግን በሰማ ጊዜ፦ «እኔ ራሱን ያስቆረጥሁት ዮሐንስ እርሱ ከሙታን ተነሥቷል» አለ። |
| **፲፯** | እስመ ውእቱ ሄሮድስ ፈነወ አግብርቲሁ ወአኀዞ ለዮሐንስ ወሞቅሖ በእንተ ሄሮድያዳ ብእሲተ ፊልጶስ እኁሁ እስመ ኪያሃ አውሰበ። | ሄሮድስ ራሱ የፊልጶስን ሚስት ሄሮድያዳን አግብቶ ነበርና በእርሷ ምክንያት መልእክተኞችን ልኮ ዮሐንስን አስይዞ በወህኒ አስሮት ነበርና፤ |
| **፲፰** | እስመ ይቤሎ ዮሐንስ ኢይከውነከ ታውስብ ብእሲተ እኁከ። | ዮሐንስ ሄሮድስን፦ «የወንድምህን ሚስት ልታገባ አልተፈቀደልህም» ይለው ነበርና። (ዘሌ. ፲፰፡፲፮) |
