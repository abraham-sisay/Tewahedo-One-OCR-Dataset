| ፬ | ወዘንተ ንጽሕፍ ለክሙ ከመ ትፍሥሕትክሙ ፍጽምተ ትኩን ብነ ። | ደስታችሁ በእኛ ፍጽምት ትሆን ዘንድ ይህን እንጽፍላችኋለን ። |
| ፭ | ወዛቲ ይእቲ ዜና እንተ ሰማዕናሃ ትካት እምኔሁ ወንዜንወክሙ ከመ እግዚአብሔር ብርሃን ውእቱ ፤ ወጽልመትሰ አልቦ ኀቤሁ ወኢአሐተሂ ። | ይህችም ቀድሞ ከእርሱ የሰማናት ናት ፤ እግዚአብሔር ብርሃን እንደ ሆነ እንነግራችኋለን ፤ በእርሱ ዘንድ ጨለማ ምንም ምን የለም ። |
| ፮ | ወእመሰ ንቤለክሙ ብነ ሱታፌ ምስሌሁ ወውስተ ጽልመት ነሐውር ንሔሱ ወኢንገብራ ለጽድቅ ወለርትዕ ። | ከእርሱ ጋር አንድነት አለን ብንላችሁ ነገር ግን ወደ ጨለማ ብንሄድ እንዋሻለን ፤ እውነትንና ቀናውን ነገር አንሠራም ። |
| ፯ | ወእመሰ ውስተ ብርሃን ነሐውር በከመ ውእቱ ብርሃን ሱቱፋን ንሕነ በበይናቲነ ወደሙ ለኢየሱስ ክርስቶስ ያነጽሐነ እምኵሉ ኃጣውኢነ ። | እርሱ ብርሃን እንደ ሆነ ወደ ብርሃን ብንሄድ ግን እኛ እርስ በርሳችን አንድነት አለን ፤ የኢየሱስ ክርስቶስም ደም ከኃጢአታችን ሁሉ ያነጻናል ። |
| ፰ | ወእመሰ ንብል አልብነ ኃጢአት ንጌጊ ለርእስነ ወአልቦ ርትዕ ኀቤነ ። | ኃጢአት የለንም ብንል ራሳችንን ለመጎዳት እንስታለን ፤ በእኛ ዘንድ እውነት የለም ። |
| ፱ | ወእመሰ ነገርነ ወአመነ ኃጢአተነ ምእመን ውእቱ ወጻድቅ ከመ ይኅድግ ለነ ኃጣውኢነ ወያነጽሐነ እምኵሉ አበሳነ ። | ኃጢአታችንን አምነን ብንናገር ኃጢአታችንን ይቅር ይለን ዘንድ የታመነ እውነተኛ ነው ፤ ከኃጢአታችንም ሁሉ ያነጻናል ። |
| ፲ | ወእመሰ ንቤ ኢአበስነ ሐሳዌ ንሬስዮ ሎቱ ፤ ወቃሉኒ ኢሀሎ ኀቤነ ። | አልበደልንም ብንል ግን እርሱን ሐሰተኛ እናደርገዋለን ፤ ቃሉም ከእኛ ዘንድ የለም ። |

| ፩ | ደቂቅየ ዘንተ እጽሕፍ ለክሙ ከመ ኢተአብሱ ወእመኒቦ ዘአበሰ ጳራቅሊጦስ ብነ ኀበ አብ ኢየሱስ ክርስቶስ ። | ልጆቼ ! እንዳትበድሉ ይህን እጽፍላችኋለሁ ፤ የበደለም ቢኖር ጳራቅሊጦስ ከአብ ዘንድ አለን ኢየሱስ ክርስቶስ ፤ |
| ፪ | ጻድቅ ውእቱ ይኅድግ ለነ ኃጣውኢነ ወአኮ በእንቲአነ ባሕቲቱ አላ በእንተ ዓለምኒ ። | ኃጢአታችንን ያስተሠርይልን ዘንድ ቸር ነው ፤ ስለ እኛ ብቻ አይደለም ስለ ዓለምም ነው እንጂ ። |
| ፫ | ወበእንተዝ ነአምር ከመ አእመርናሁ ለአመ ዐቀብነ ትእዛዞ ። | ስለዚህም ትእዛዙን ብንጠብቅ እንደወደድነው እናውቃለን ። |
| ፬ | ወዘሰ ይብል አእምሮ ወኢየዐቅብ ትእዛዞ ሐሳዊ ውእቱ ወአልቦ ጽድቀ እግዚአብሔር በኀቤሁ ። | ዐውቀዋለሁ የሚል ትእዛዙን የማይጠብቅ ግን ሐሰተኛ ነው ፤ በእርሱም ዘንድ የእግዚአብሔር እውነት የለም ። |
| ፭ | ወዘሰ የዐቅብ ቃሎ አማን ፍቅረ እግዚአብሔር ፍጹም ላዕሌሁ ፤ ወበዝንቱ ነአምር ከመ ቦቱ ሀለውነ ። | ትእዛዙን የሚጠብቅ ግን ፍጹም የእግዚአብሔር ፍቅር አድሮበት ይኖራል ፤ በዚህ በእርሱ አምነን ፀንተን እንደምንኖር እናውቃለን ። |
