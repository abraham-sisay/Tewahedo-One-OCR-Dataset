| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፭ ፡ በእንተ ርሒቅ እምዘዚአሁ ፈቃደ ሥጋ ።** | **ክፍል ፭ ፡ ከልዩ ልዩ ፈቃደ ሥጋ ስለ መራቅ ።** |
| ፩ | ወይእዜኒ አኀዊነ ንነግረክሙ ወናስተበቍዐክሙ በእግዚእነ ኢየሱስ ክርስቶስ ፤ ከመ ተአዘዝክሙ በኀቤነ በዘይደሉ ከመ ትሑሩ ወታሠምርዎ ለእግዚአብሔር ፤ በከመ ሖርክሙ ዓዲ ከመ ታብዝኁ ወታፈድፍዱ በዝንቱ ። | አሁንም ወንድሞቻችን ከእኛ ዘንድ እንደ ታዘዛችሁ ፤ በሚገባ ትኖሩ ዘንድ እግዚአብሔርንም ደስ ታሰኙት ዘንድ እንነግራችኋለን ፤ ከዚያ በፊት እንደ ኖራችሁ እንግዲህ ወዲህም አብዝታችሁ ትሠሩ ዘንድ እንማልዳችኋለን ። |
| ፪ | ወተአምሩ ዘከመ አዘዝናክሙ በእግዚእነ ኢየሱስ ክርስቶስ ። | በጌታችን በኢየሱስ ክርስቶስ እንደ አዘዝናችሁ ታውቃላችሁ ። |
| ፫ | እስመ ዝ ውእቱ ትእዛዙ ለእግዚአብሔር ወፈቃዱ ተቀድሶትክሙ ውእቱ ፤ ወከመ ትትዐቀቡ ወትርሐቁ እምዝሙት ። | የእግዚአብሔር ትእዛዙ ይህ ነውና ፈቃዱም ንጽሕና መያዛችሁ ነውና ፤ ከኃጢአት መራቃችሁ ነው ፤ ከዝሙትም እንድትጠበቁና እንድትርቁ ነውና ። |
| ፬ | ወያእምር ኵሉ ለለአሐዱ ንዋዮ ፤ ወያጥርዮ በቅድሳት ወክብር ። | ሁሉም እያንዳንዱ ገንዘቡን ይወቅ ፤ በንጽሕና በክብር ይጠብቀው ። |
| ፭ | ወኢትትመንሰዉ በፍትወት ከመ አረሚ እለ ኢየአምርዎ ለእግዚአብሔር ። | እግዚአብሔርን እንደማያውቁት እንደ አረሚ ፤ በዝሙት ድል አትነሡ ። |
| ፮ | ወኢትትሀበሉ ትግበሩ ዘንተ ወኢትትዐገሉ ቢጸክሙ ለኵሉ ፤ እስመ መስተበቅል እግዚአብሔር በእንተ ዝንቱ ኵሉ ፤ በከመ አቅደምኩ ነጊሮተክሙ ወአስማዕኩ ለክሙ ። | ይህንንም ልትሠሩ አትድፈሩ አትታበዩ ፤ በሁሉ ባልንጀሮቻችሁን አትቀሙ ፤ አስቀድሜ እንደ ነገርኳችሁ እንደ አስረዳኋችሁ ፤ በዚህ ሁሉ እግዚአብሔር ፈታሒ ነውና ። |
| ፯ | እስመ ኢጸውዐነ እግዚአብሔር ለርኵስ ዘእንበለ ለቅድሳት ። | እግዚአብሔር ለንጽሕና እንጂ ለኃጢአት አልጠራንምና ። |
| ፰ | ወይእዜኒ ዘክሕደ ያእምር ከመ አኮ ለሰብእ ዘይክሕድ ዘእንበለ ለእግዚአብሔር ፤ ዘወሀበክሙ መንፈሶ ቅዱሰ ። | አሁንም የሚክድ ሰው መንፈስ ቅዱስን የሰጣችሁ እግዚአብሔርን እንጂ ፤ ሰውን የሚክድ እንዳይደለ ይወቅ ። |
| ፱ | ወበእንተሰ አፍቅሮ ቢጽክሙ ኢትፈቅዱ ንጽሐፍ ለክሙ ፤ ለሊክሙ ምሁራን በኀበ እግዚአብሔር ከመ ትትፋቀሩ በበይናቲክሙ ። | ባልንጀራችሁን ስለ መውደድ ግን ልንጽፍላችሁ አትሹም ፤ እርስ በርሳችሁ እንድትዋደዱ ራሳችሁ ከእግዚአብሔር የተማራችሁ ናችሁ ። |
| ፲ | ወከማሁ ትግበሩ ዓዲ ምስለ ኵሎሙ አኀዊክሙ እለ በኵሉ መቄዶንያ ፤ ወናስተበቍዐክሙ አኀዊነ ትብዝኁ ወትፈድፍዱ ። | ደግሞ በመቄዶንያ ሁሉ ካሉት ወንድሞቻችሁም ጋር እንዲሁ እንድታደርጉ ፤ ወንድሞቻችን በፍቅር ፈጽማችሁ እንድትበዙ እንማልዳችኋለን ። |
| ፲፩ | ከመ ትኩኑ የዋሃነ ወትትገበሩ ተግበረክሙ ፤ ወትትቀነዩ በእደዊክሙ ዘከመ አዘዝናክሙ ። | ቅኖች ትሆኑ ዘንድ ሥራችሁንም ትሠሩ ዘንድ ፤ እንደ አዘዝናችሁ በእጃችሁ ትሠሩ ዘንድ ። |
| ፲፪ | ከመ ትሑሩ በኂሩት በቅድመ እለ አፍአ ፤ ወኢትጽሐቁ ወኢኀበ መኑሂ ። | ከሃይማኖት አፍአ ባሉ ሰዎች ፊት በቅንነት ትኖሩ ዘንድ ፤ ከማንም ከማን አትፈልጉ ። |
| **ክፍል** | **ክፍል ፮ ፡ ዘከመ ኢይደሉ ኀዘን ዘቀቢጸ ተስፋ በእንተ እለ ሞቱ ።** | **ክፍል ፮ ፡ ስለ ሞቱ ሰዎች የቀቢጸ ተስፋ ኀዘን እንደማይገባ ።** |
| ፲፫ | ወንፈቅድ ታእምሩ አኀዊነ በእንተ እለ ኖሙ ፤ ከመ ኢይደሉ ትተክዙ በላዕሌሆሙ ከመ ኵሉ ሰብእ እለ ቅቡጻን ተስፋሆሙ ። | ወንድሞቻችን ስለ ሞቱ ሰዎች ተስፋ እንደሌላቸው ሰዎች ሁሉ ፤ ልታዝኑ እንደማይገባ ታውቁ ዘንድ እንወዳለን ። |
| ፲፬ | ወእምከመሰ ንትአመን ከመ ሞተ ክርስቶስ ወተንሥአ ፤ ከማሁ ያነሥኦሙ እግዚአብሔር ለምውታን በኢየሱስ ወያመጽኦሙ ምስሌሁ ። | ክርስቶስ ሞቶ እንደ ተነሣ ካመንን ፤ እንዲሁ እግዚአብሔር ሙታንን በኢየሱስ ያስነሣቸዋል ፤ ከእርሱም ጋር ያመጣቸዋል ። |
| ፲፭ | ወዘንተ ንነግረክሙ በቃለ እግዚአብሔር ፤ ንሕነ ሕያዋን እለ ንተርፍ አመ ምጽአተ እግዚእነ ኢንበጽሖሙ ለሙታን ። | ይህንም በእግዚአብሔር ቃል እንነግራችኋለን ፤ ከሞት የምንቀረው እኛ ጌታችን በመጣ ጊዜ ፤ ሙታንን አንቀድማቸውም ። |
| ፲፮ | እስመ ይኤዝዝ እግዚእነ ምስለ ቃለ ሊቀ መላእክት ወንፍሐተ ቀርን ዘእግዚአብሔር ዘይወርድ እምሰማይ ፤ ወይትነሥኡ ምውታን መቅድመ እለ ሞቱ በሃይማኖተ ክርስቶስ ። | ጌታችን በመላእክት አለቃ ቃል ከሰማይ በሚወርድ በእግዚአብሔር መለከት ድምፅ ንቃሕ መዋቲ ብሎ ያዝዛልና ፤ መጀመሪያ በክርስቶስ አምነው የሞቱ ሙታን ይነሣሉ ። |
| ፲፯ | ወእምዝ ንሕነ ሕያዋን እለ ንተርፍ ንትመሠጥ በደመና ምስሌሆሙ ዓቡረ ፤ ከመ ንትቀበሎ ለእግዚእነ ውስተ አየር ፤ ወንሄሉ እንከ ዘልፈ ኀበ እግዚእነ ። | ከዚያ በኋላ ከሞት የምንቀረው እኛ ከእነርሱ ጋራ አንድ ሆነን ፤ ጌታችንን በአየር ላይ እንቀበለው ዘንድ በደመና እንነጠቃለን ፤ ከዚያ ወዲያ ለዘለዓለሙ ከጌታችን ዘንድ እንኖራለን ። |
| ፲፰ | ወይእዜኒ መሀሩ ቢጸክሙ ዘንተ ነገረ ። | አሁንም ይህን ነገር ለወንድሞቻችሁ አስተምሩ ። |
