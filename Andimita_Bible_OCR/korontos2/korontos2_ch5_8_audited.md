## ምዕራፍ ፭

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፮ ፡ በእንተ ዘብነ ተስፋ ሕይወት በሰማያት ።** | **ክፍል ፮ ፡ በሰማያት ስላለን የሕይወት ተስፋ ።** |
| **፩** | እስመ ነአምር ከመ ድንኳነ ሥጋነ ዘበምድር ለእመ ተነሥተ ፤ ሕንፃ ዘእምኀበ እግዚአብሔር ብነ ውስተ ሰማያት ዘኢተገብረ በእደ ሰብእ ዘለዓለም ። | ድንኳን የሚሆነው የምድር መኖሪያችን ቢፈርስ ፤ በሰማይ ያለ በእጅ ያልተሠራ የዘላለም ቤት የሚሆን ከእግዚአብሔር የተሰጠን ሕንፃ እንዳለን እናውቃለንና ። |
| **፪** | ወበእንተዝ ንትኤነህ ወንፈቅድ ንልበስ ማኅደረነ ዘእምሰማይ ። | በዚህ ውስጥ በእውነት እንቃትታለን ፤ ከሰማይ የሚሆነውን መኖሪያችንን በላዩ ልንለብስ እንናፍቃለንና ፤ |
| **፫** | ከመ ኢይርከቡነ ዕራቀነ ሶበ ለበስናሁ ። | ለብሰን ግን ዕራቁታችንን አንገኝም ። |
| **፬** | እስመ ንሕነ እለ ውስተ ዝንቱ ድንኳን ንትኤነህ ወይከብደነ ፤ እስመ ኢነፈቅድ ንግፈፍ አላ ንልበስ ፤ ከመ ይትወሐጥ መዋቲ በሕይወት ። | በዚህ ድንኳን ሳለን ከብዶን እንቃትታለን ፤ የሚሞተው በሕይወት ይዋጥ ዘንድ ልንለብስ እንጂ ልንገፈፍ አንወድምና ። |
| **፭** | ወዘሰ አዳለወነ ለዝንቱ ግብር እግዚአብሔር ውእቱ ፤ ዘወሀበነ አረቦነ መንፈስ ቅዱስ ። | ለዚህ ነገር ያዘጋጀን እግዚአብሔር ነው ፤ እርሱም የመንፈሱን መያዣ የሰጠን ነው ። |
| **፮** | ወበእንተዝ ንትአመን ዘልፈ ወነአምር ፤ ከመ እንዘ ሀሎነ ውስተ ሥጋ ርሑቃን ንሕነ እምእግዚአብሔር ። | ስለዚህ ሁልጊዜ ታምነን በሥጋ ስንኖር ከጌታ ተለይተን በስደት እንደ ሆንን እናውቃለን ፤ |
| **፯** | እስመ በሃይማኖት ነሐውር ወአኮ በርእይ ። | በእምነት እንመላለሳለን እንጂ በማየት አይደለምና ፤ |
| **፰** | ወንትአመን ባሕቱ ወንፈቅድ ንፍልስ እምሥጋ ፤ ወንሑር ኀበ እግዚአብሔር ። | ታምነናል ፤ ይልቁንም ከሥጋ ተለይተን ወደ ጌታ መሄድ ደስ ይለናል ። |
| **፱** | ወበእንተዝ ንትጋደል እመኒ ሀሎነ ወእመኒ ፈለስነ ፤ ከመ ናሥምሮ ሎቱ ። | ስለዚህ ደግሞ ብንኖር ወይም ብንሄድ እርሱን ደስ ልናሰኘው እንተጋለን ። |
| **፲** | እስመ ሀለወነ ኵልነ ንቁም ቅድመ መንበረ ክርስቶስ ፤ ከመ ይትፈደይ ለለአሐዱ በዘገብረ በሥጋሁ ፤ እመኒ ሠናየ ወእመኒ እኩየ ። | መልካም ቢሆን ወይም ክፉ እንዳደረገ በሥጋው የተቀበለውን እያንዳንዱ በብድራት ይቀበል ዘንድ ፤ ሁላችን በክርስቶስ የፍርድ ወንበር ፊት ልንገለጥ ይገባናልና ። |
| **፲፩** | ወሶበ ነአምር እንከ ፍርሃቶ ለእግዚአብሔር ናረድእ ሰብአ ፤ ወለእግዚአብሔርሰ ክሡታን ንሕነ ፤ ወእትአመን ከመ ክሡታን ንሕነ ውስተ ሕሊናክሙኒ ። | እንግዲህ የጌታን ፍርሃት እያወቅን ሰዎችን እናሳምናለን ፤ ለእግዚአብሔር ግን የተገለጥን ነን ፤ በሕሊናችሁም ደግሞ የተገለጥን እንደ ሆንን ተስፋ አደርጋለሁ ። |
| **፲፪** | ወአኮ ዳግመ ርእሰነ ዘንሴብሕ ኀቤክሙ ፤ አላ ምስካየ ንሁበክሙ በእንቲአነ ፤ ከመ ትኩኑ ድልዋነ ለእለ ይትመክሑ በገጽ ወአኮ በልብ ። | በልብ ሳይሆን በውጭ መልክ ለሚመኩ መልስ የሚሆን ትምክህት በእኛ እንድታገኙ ምክንያት እንሰጣችኋለን እንጂ ፤ እንደ ገና ራሳችንን ለእናንተ አናመሰግንም ። |
| **፲፫** | እመኒ አብድነ ለእግዚአብሔር ውእቱ ፤ ወእመኒ ጠበብነ ለክሙ ውእቱ ። | እብዶች ብንሆን ለእግዚአብሔር ነው ፤ ባለ አእምሮዎችም ብንሆን ለእናንተ ነው ። |
| **፲፬** | እስመ ፍቅረ ክርስቶስ የኀይለነ ፤ እንዘ ነሐሊ ዘንተ ከመ አሐዱ ሞተ በእንተ ኵሉ ፤ ወበእንተዝ ኵሎሙ ሞቱ ። | ይህን ስለ ቈረጥን የክርስቶስ ፍቅር ግድ ይለናልና ፤ አንዱ ስለ ሁሉ ሞተ ፤ እንግዲያስ ሁሉ ሞቱ ፤ |
| **፲፭** | ውእቱ ሞተ በእንተ ኵሉ ፤ ከመ እለሂ የሐይዉ አኮ ለርእሶሙ ዘየሐይዉ ፤ ዘእንበለ ለዝኩ ዘበእንቲአሆሙ ሞተሂ ወሐይወሂ ። | በሕይወትም ያሉት ስለ እነርሱ ለሞተውና ለተነሣው እንጂ ፤ ወደ ፊት ለራሳቸው እንዳይኖሩ ስለ ሁሉ ሞተ ። |
| **፲፮** | ወይእዜሰ አልቦ ዘነአምሮ በሥጋነ ፤ ወእመሂ አእመርናሁ ለክርስቶስ በሥጋነ ፤ እምይእዜሰ አልቦ ዘነአምሮ እንከ ። | ስለዚህ እኛ ከአሁን ጀምሮ ማንንም በሥጋ እንደ ሆነ አናውቅም ፤ ክርስቶስንም በሥጋ እንደ ሆነ ያወቅነው እንኳ ብንሆን ፤ አሁን ግን ከእንግዲህ ወዲህ እንደዚህ አናውቀውም ። |
| **አርእስት** | **ክፍል ፯ ፡ በእንተ ዘከመ ተሐደሰ ኵሉ በክርስቶስ ።** | **ክፍል ፯ ፡ ሁሉ በክርስቶስ እንደ ታደሰ ።** |
| **፲፯** | ወይእዜሰ በክርስቶስ ተሐደሰ ኵሉ ዘኮነ ፤ ወኀለፈ ዘትካት ። | ስለዚህ ማንም በክርስቶስ ቢሆን አዲስ ፍጥረት ነው ፤ አሮጌው ነገር አልፏል ፤ |
| **፲፰** | ወናሁ ኮነ ኵሉ ሐዲሰ እምኀበ እግዚአብሔር ፤ ዘአቅረበነ ኀቤሁ በክርስቶስ ወወሀበነ መልእክተ ሥምረቱ ። | እነሆ ሁሉም አዲስ ሆኗል ፤ ይህም ሁሉ በክርስቶስ ከራሱ ጋር ካስታረቀንና የማስታረቅንም አገልግሎት ከሰጠን ከእግዚአብሔር ነው ፤ |
| **፲፱** | እስመ ተዋለጠ እግዚአብሔር ዓለመ በክርስቶስ ፤ አናሕስዮ ኃጢአቶሙ ወኢነጺሮ ጌጋዮሙ ፤ ወረሰየ ላዕሌነ ቃለ ሥምረቱ ወወሀበነ መልእክተ ሣህሉ ። | እግዚአብሔር በክርስቶስ ሆኖ ዓለሙን ከራሱ ጋር ያስታርቅ ነበርና ፤ በደላቸውን አይቆጥርባቸውም ነበር ፤ በእኛም የማስታረቅን ቃል አኖረ ። |
| **፳** | ወንሕነሰ ንተነብል በአምሳለ ክርስቶስ ፤ ወይሁበክሙ እግዚአብሔር ፍሥሓ በላዕሌነ ፤ ወንስእለክሙ በክርስቶስ ከመ ታሥምርዎ ለእግዚአብሔር ። | እንግዲህ እግዚአብሔር በእኛ እንደሚለምን ስለ ክርስቶስ መልክተኞች ነን ፤ «ከእግዚአብሔር ጋር ታረቁ» ብለን ስለ ክርስቶስ እንለምናለን ። |
| **፳፩** | እስመ ዘኢየአምር ኃጢአተ ረሰዮ ርእሶ ኃጥአ በእንቲአነ ፤ ከመ ንሕነ ንኩን ጽድቀ እግዚአብሔር ቦቱ ። | እኛ በእርሱ ሆነን የእግዚአብሔር ጽድቅ እንሆን ዘንድ ፤ ኃጢአት ያላወቀውን እርሱን ስለ እኛ ኃጢአት አደረገው ። |
