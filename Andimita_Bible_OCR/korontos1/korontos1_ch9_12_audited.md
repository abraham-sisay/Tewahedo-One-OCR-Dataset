## ምዕራፍ ፱

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፳ወ፩ ፡ በእንተ ርእሱ ወለበርናባስ ።** | **ክፍል ፳፩ ፡ ስለ ራሱና ስለ በርናባስ ።** |
| **፩** | ኢኮንኩኑ እግአዜ ወኢኮንኩኑ ሐዋርያ ፤ አኮኑ እግዚእነ ኢየሱስ ዘርኢኩ ፤ ወኢኮንክሙኑ አንትሙ ግብርየ በእግዚእነ ። | ነፃ ሰው አይደለሁምን? ሐዋርያስ አይደለሁምን? ጌታችን ኢየሱስ ክርስቶስንስ ያየሁት አይደለሁምን? እናንተስ በጌታችን ያፈራኋችሁ ፍሬዬ አይደላችሁምን? |
| **፪** | ወእመኒ ለባዕዳን ኢኮንኩ ሐዋርያሆሙ ለክሙሰ አነ ሐዋርያክሙ ፤ እስመ ማኅተማ ለመጽሐፍየ አንትሙ ውእቱ በእግዚእነ ። | ለሌሎች ሐዋርያ ባልሆን እንኳ ለእናንተስ ሐዋርያችሁ ነኝ ፤ የሐዋርያነቴ ማረጋገጫ በጌታችን እናንተ ናችሁና ። |
| **፫** | ወከመዝ ቅስትየ ለእለ ይትዋቀሡኒ ። | ለሚከራከሩኝ መልሴ ይህ ነው ። |
| **፬** | ቦኑ ኢይከውነነ ንብላዕሂ ወንስተይሂ ። | በውኑ ልንበላና ልንጠጣ አይገባንምን? |
| **፭** | ወትትልወነ እኅትነ እምአንስት ከመ ኵሉ ሐዋርያት ከመ አኃዊሁ ለእግዚእነ ወከመ ኬፋ ። | እንደ ሌሎች ሐዋርያትና እንደ ጌታ ወንድሞች እንደ ጴጥሮስም ሚስቶቻችንን ይዘን ልንዞር አይገባንምን? |
| **፮** | ሊተኒ ዳእሙ ወለበርናባስ አሕረሙ ለነ ሥራሐ ። | ወይስ ለእኔና ለበርናባስ ብቻ ነውን ሥራ መሥራት የተከለከለብን? |
| **አርእስት** | **ክፍል ፳ወ፪ ፡ በእንተ ጽሙዳን ወምርካቦሙ ።** | **ክፍል ፳፪ ፡ ስለ አገልጋዮችና ስለሚያገኙት ።** |
| **፯** | ወዘኒ ይጸመድ ከመ ይርከብ ሲሳዮ ፤ መኑ ዘይተክል ወይነ ወኢይበልዕ ቀምሖ ፤ ወመኑ ዘይርዒ መርዔቶ ወኢይሰቲ ሐሊቦ ። | የሚያገለግልም ምግቡን ያገኝ ዘንድ ነው ፤ ወይን ተክሎ ፍሬውን የማይበላ ማነው? መንጋውን ጠብቆ ወተቱን የማይጠጣ ማነው? |
| **፰** | ቦኑ ለአድልዎ ለሰብእ እብል ፤ አኮኑ ኦሪትኒ መጽሐፈ ሙሴ ይቤ ከመዝ ፤ ኢትፍጽሞ አፉሁ ለላሕም ሶበ ታከይድ እክለከ ። | በውኑ ለሰው ይምሰል እናገራለሁን? የሙሴ መጽሐፍ ኦሪትስ እንዲሁ «እህልህን በምታበራይበት ጊዜ የበሬውን አፉን አትሰረው» ብሎ የለምን? |
| **፱** | ላሕምኑ እንከ አዕሐቆ ለእግዚአብሔር ዘዘንተ ይጽሕፍ ። | እንግዲህ ይህን የጻፈ ለእግዚአብሔር ላም አሳዝኖት ነውን? |
| **፲** | አላ አርአየ ከመ በእንቲአነ ይቤ ወበእንቲአነ ጸሐፈ ፤ እስመ ርቱዕ ዘኒ የሐርስ እንዘ ይሴፎ ምርካቦ የሐርስ ፤ ወዘኒ ያከይድ እክለ እንዘ ይሴፎ ምርካቦ ያከይድ ። | ስለ እኛ እንደ ተናገረ እንደ ጻፈ አስረዳ እንጂ ፤ የሚገባ ነውና የሚያርስ የሚያገኘውን ተስፋ አድርጎ ያርሳል ፤ እህልን የሚያበራየውም የሚያገኘውን ተስፋ አድርጎ ያበራያል ። |
| **፲፩** | ወእመሰ ንሕነ ዘራእነ ለክሙ ዘመንፈስ ቅዱስ ዐቢይኑ ውእቱ ሶበ ንሕነ ነአርር ለክሙ ዘሥጋ ሰብእ ። | እኛ የመንፈስ ቅዱስን ዘር ከዘራንላችሁ ለቁመተ ሥጋ ያህል የሚሆነውን ብንመገብ ታላቅ ነገር ነውን? |
| **፲፪** | ወእመሰ ባዕድ ይቀድመነ በሚመተ ዚአነ ለሊክሙ ተአምሩ ዘይኄይሰክሙ ፤ ወአንሰ ኢፈቀድክዎ ለዝንቱ ወባሕቱ በኵሉ እትዔገሥ ከመ ኢያዕቅፍ ትምህርቶ ለክርስቶስ ። | በእኛ ሹመት ሌላ የሚቀድመን ከሆነ ግን የሚሻላችሁን እናንተ ታውቃላችሁ ፤ እኔ ይህን አልፈለግሁትም ፤ ነገር ግን የክርስቶስን ትምህርት እንዳላሰናክል በሁሉ እታገሣለሁ እንጂ ። |
| **አርእስት** | **ክፍል ፳ወ፫ ፡ በእንተ ሲሳዮሙ ።** | **ክፍል ፳፫ ፡ ስለ ምግባቸው ።** |
| **፲፫** | ኢተአምሩኑ ከመ ገነውተ አማልክት ይሴሰዩ መባኦሙ ለአማልክት ፤ ወእለሂ ይጸመዱ ምሥዋዐ ይትካፈሉ መሥዋዕተ ፤ ወለሡዩማነ ቤተ እግዚአብሔር መባአ ቤተ እግዚአብሔር ምርካቦሙ ። | የጣዖታቱ ካህናት ለጣዖታት የገባውን መባ እንዲመገቡ አታውቁምን? መሠውያውን የሚያገለግሉም መሥዋዕቱን እንደሚካፈሉ አታውቁምን? ለቤተ እግዚአብሔር ሹማምንትም ምግባቸው የቤተ እግዚአብሔር መባ ነው ። |
| **፲፬** | ወእግዚእነሂ ከማሁ አዘዘ ይሜህሩ ትምህርተ ወንጌል በውእቱ ምህሮ ወንጌል ይኩኖሙ ምርካቦሙ ለሕይወቶሙ ። | ጌታችንም እንደዚሁ ወንጌልን ለሚያስተምሩ ሰዎች ለሕይወታቸው የሚሆነውን ምግባቸው በዚያው ወንጌልን በማስተማር ይሆን ዘንድ አዘዘ ። |
| **፲፭** | ወአንሰ ለዝሂ ኢፈቀድክዎ ወአኮ ዘንተ ብሂልየ እርከብ ዘጸሐፍኩ ዘንተ ፤ ወሊተሰ ይኄይሰኒ መዊት እምይትበሀነነኒ ምዝጋናየ ። | እኔ ይህንም አልሻሁትም ፤ ይህን የጻፍኩ ይህን እንዳገኝ ብዬ አይደለም ፤ እኔ ግን ዋጋዬ ከሚቀርብኝ ሞት ይሻለኛል ። |
| **፲፮** | ወእመሂ መሀርኩ ኢይከውነኒ ምዝጋና እስመ በትእዛዝ ገበርኩ ፤ ወእመሂ ኢመሀርኩ አሌ ሊተ ። | ባስተምርም መመስገን አይገባኝም ፤ ታዝዤ አድርጌዋለሁና ፤ ባላስተምርም ወዮልኝ ። |
| **፲፯** | ወእመሰ ዘእምፈቃድየ ገበርክዎ ለዝንቱ እምረከብኩ ዐስብየ ፤ ወእመሰ ዘበግብር ምግባ በዘአመገቡኒ ተልእኩ ምንት እንከ ዕሴትየ ። | ይህንስ በፈቃዴ አድርጌው ብሆን ዋጋዬን ባገኘሁ ነበር ፤ በግድ ከሆነ ግን ሹመቱን ስለ ሾመኝ አገለግላለሁ ፤ እንግዲህ ዋጋዬ ምንድር ነው? |
| **፲፰** | ለእመ መሀርኩ እሬሲ ከመ እምሀር ዘእንበለ ዐስብ ዘአልብየ ምርካብ በውስተ ሢመትየ ። | ባስተምርም በሹመቴ አበል እንደሌለኝ ሆኜ ያለ ዋጋ እንዳስተምር አደርጋለሁ ። |
