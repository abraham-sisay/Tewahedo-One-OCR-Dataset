| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፳ወ፱ ፡ በእንተ ፍቅር ።** | **ክፍል ፳፱ ፡ ስለ ፍቅር ጠቃሚነት ።** |
| **፩** | ለእመ ተናገርኩ በነገረ ሰብእ ወበነገረ መላእክት ፤ ወተፋቅሮሰ አልብየ ፤ ከንቱ አነ ከመ ናስ ዘይነቁ ወከመ ቃጭል ዘይስምዕ ። | በሰዎችና በመላእክት ልሳን ብናገር ፤ ፍቅር ግን ከሌለኝ እንደሚጮኽ ናስ ወይም እንደሚንሽዋሽዋ ጸናጽል ሆኛለሁ ። |
| **፪** | ወለእመ ብየ ተነብዮ ወአእመርኩ ኵሎ ምሥጢራተ ወኵሎ ጥበበ ፤ ወለእመ ብየ ኵሉ ሃይማኖት እስከ አንዕስ አድባረ ፤ ወተፋቅሮሰ አልብየ ፤ ከንቱ አነ ። | ትንቢት የመናገር ሀብት ቢኖረኝ ፤ ምሥጢርንም ሁሉና ዕውቀትን ሁሉ ባውቅ ፤ ተራሮችን እስካፈልስ ድረስ ፍጹም እምነት ቢኖረኝ ፤ ፍቅር ግን ከሌለኝ ከንቱ ነኝ ። |
| **፫** | ወለእመ መገብኩ ነዳያነ በኵሉ ንዋይየ ፤ ወለእመ አግብእኩ ሥጋየ ከመ እትወቀድ በእሳት ፤ ወተፋቅሮሰ አልብየ ፤ አልቦ ዘይበቍዐኒ ። | ድሆችን ለመመገብ ያለኝን ሁሉ ባካፍል ፤ ሥጋዬንም በእሳት ለመቃጠል አሳልፌ ብሰጥ ፤ ፍቅር ግን ከሌለኝ ምንም አይጠቅመኝም ። |
| **፬** | ተፋቅሮሰ የዓርግ ወየዋህ ውእቱ ፤ ተፋቅሮሰ ኢይቀንእ ወኢይትዐበይ ፤ ወኢይዛወር ። | ፍቅር ይታገሣል ፤ ቸርነትንም ያደርጋል ፤ ፍቅር አይቀናም ፤ ፍቅር አይመካም ፤ አይታበይም ፤ |
| **፭** | ወኢይገብር ዘኢይደሉ ፤ ወኢየኀሥሥ ዘርእሱ ፤ ወኢይትመዐዕ ፤ ወኢይሔሊ እኩየ ። | የማይገባውን አያደርግም ፤ የራሱንም አይፈልግም ፤ አይበሳጭም ፤ ክፉ ነገርን አያስብም ፤ |
| **፮** | ወኢይትፌሣሕ በዐመፃ ፤ አላ ይትፌሣሕ በጽድቅ ። | ከእውነት ጋር ደስ ይለዋል እንጂ ስለ ዓመፃ ደስ አይለውም ፤ |
| **፯** | ኵሎ ይጸውር ፤ ወኵሎ ያአምን ፤ ወኵሎ ይሴፎ ፤ ወኵሎ ይትዔገሥ ። | ሁሉን ይታገሣል ፤ ሁሉን ያምናል ፤ ሁሉን ተስፋ ያደርጋል ፤ በሁሉ ይጸናል ። |
| **፰** | ተፋቅሮሰ ኢይወድቅ ለግሙራ ፤ ወዘሂ ተነበየ ኀላፊ ወይሠዐር ፤ ወዘሂ ነበበ በነገረ በሐውርት ኀላፊ ወይትፌጸም ፤ ወዘሂ ጠበበ ኀላፊ ወይሠዐር ። | ፍቅር ለዘላለም አይወድቅም ፤ ትንቢት ግን ቢሆን ያልፋል ፤ ልሳናትም ቢሆኑ ይቀራሉ ፤ ዕውቀትም ቢሆን ይሻራል ። |
| **፱** | እስመ ነአምር ንስቲተ ፤ ወንትኔበይ ንስቲተ በበገጹ ። | ከዕውቀት ከፍለን እናውቃለንና ፤ ከትንቢትም ከፍለን እንናገራለንና ፤ |
| **፲** | ወአመ በጽሐ ፍጻሜሁ ሎቱ ፤ ይሠዐር ውእቱኒ ። | ፍጹም የሆነ ሲመጣ ግን ያ በከፊል የሆነው ይሻራል ። |
| **፲፩** | ወአመሰ ደቂቅ አነ ተናገርኩ ከመ ደቂቅ ፤ ወሐለይኩ ከመ ደቂቅ ፤ ወመከርኩ ከመ ደቂቅ ፤ ወአመሰ ልሕቁ ሠዐርኩ ኵሎ ሕገ ደቂቅ ። | ሕፃን ሳለሁ እንደ ሕፃን እናገር ነበር ፤ እንደ ሕፃንም አስብ ነበር ፤ እንደ ሕፃንም እቈጥር ነበር ፤ ጎልማሳ በሆንኩ ጊዜ ግን የሕፃንነትን ጠባይ ሽሬአለሁ ። |
| **፲፪** | ወይእዜሰ ተዐውቀኒ ወአስተርአየኒ ክሥተ እስመ በተሐዝቦ ንሬኢ ከመ ዘበመጽሔት ፤ ወአሜሃ ንሬኢ ገጸ በገጽ ፤ ወይእዜሰ አአምር እምአሐዱ ኅብር ፤ ወድኅረኒ አአምር ኵሎ ዘከመ ተዐውቀኒ ። | ዛሬስ በመስተዋት በድንግዝግዝ እንደምናይ ነን ፤ በዚያን ጊዜ ግን ፊት ለፊት እናያለን ፤ ዛሬስ ከዕውቀት ከፍዬ አውቃለሁ ፤ በዚያን ጊዜ ግን እኔ ደግሞ እንደ ታወቅሁ አውቃለሁ ። |
| **፲፫** | ወይእዜኒ እሉ ሠለስቱ ዘይነብሩ እሙንቱ ፤ ሃይማኖት ወትውክልት ወተፋቅሮ ፤ ወእምኵሉሰ የዐቢ ተፋቅሮ ። | አሁንም እምነት ፤ ተስፋ ፤ ፍቅር እነዚህ ሦስቱ ጸንተው ይኖራሉ ፤ ከእነዚህም የሚበልጠው ፍቅር ነው ። |

## ምዕራፍ ፲፬

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፴ ፡ በእንተ ትንቢት ወነጊር በነገድ ።** | **ክፍል ፴ ፡ ትንቢት ስለ መናገርና በልሳናት ስለ መናገር ።** |
| **፩** | ደግንዋ ለተፋቅሮ ወተቃሀዉ ዘመንፈስ ፤ ከመ ትትነበዩ ። | ፍቅርን ተከታተሉ ፤ መንፈሳዊ ስጦታንም በብርቱ ፈልጉ ፤ ይልቁንም ትንቢት መናገርን ። |
| **፪** | እስመ ዘይነብብ በነገረ በሐውርት አኮ ለሰብእ ዘይነብብ ፤ አላ ለእግዚአብሔር ፤ እስመ አልቦ ዘይሰምዖ ወበመንፈስሰ ይነብብ ምሥጢረ ። | በልሳን የሚናገርስ ለእግዚአብሔር እንጂ ለሰው አይናገርምና ፤ ማንም አያስተውለውምና ፤ በመንፈስ ግን ምሥጢርን ይናገራል ። |
| **፫** | ወዘሰ ይትኔበይ ለሰብእ ይነብብ ፤ ለሐኒጽ ወለተግሣጽ ወለንሥሐ ። | ትንቢት የሚናገር ግን ለማነጽና ለመምከር ለማጽናናትም ለሰው ይናገራል ። |
| **፬** | ዘይነብብ በነገረ በሐውርት ርእሶ የሐንጽ ፤ ወዘሰ ይትኔበይ ማኅበረ የሐንጽ ። | በልሳን የሚናገር ራሱን ያንጻል ፤ ትንቢት የሚናገር ግን ማኅበሩን (ቤተ ክርስቲያንን) ያንጻል ። |

| **፲፱** | ይስእሉ ሰላምክሙ አብያተ ክርስቲያናት ዘእስያ ፤ ወፈድፋደሰ አቂላ ወጵርስቂላ ይስእሉ ሰላምክሙ በእግዚእነ ምስለ ቤተ ክርስቲያኖሙ እንተ ውስተ ቤቶሙ ። | የእስያ አብያተ ክርስቲያናት ሰላምታ ያቀርቡላችኋል ፤ አቂላና ጵርስቅላ በቤታቸው ካለች ማኅበር ጋር በጌታ እጅግ ሰላምታ ያቀርቡላችኋል ። |
| **፳** | ይስእሉ ሰላምክሙ ኵሎሙ አኃው ፤ ተሳለሙ በበይናቲክሙ በስዕመት ቅድስት ። | ወንድሞች ሁሉ ሰላምታ ያቀርቡላችኋል ፤ በተቀደሰ አሳሳም እርስ በርሳችሁ ሰላምታ ተሰጣጡ ። |
| **፳፩** | ሰላምየ በዕደውየ ዘአነ ጳውሎስ ። | ይህ ሰላምታ በእኔ በጳውሎስ እጅ የተጻፈ ነው ። |
| **፳፪** | ዘኢያፈቅሮ ለእግዚእነ ኢየሱስ ክርስቶስ ውጉዘ ይኩን ፤ ማራን አታ ። | ጌታችንን ኢየሱስ ክርስቶስን የማይወድ ቢኖር ውጉዝ ይሁን ፤ ጌታችን ይመጣል (ማራን አታ) ። |
| **፳፫** | ጸጋሁ ለእግዚእነ ኢየሱስ ክርስቶስ ምስሌክሙ ። | የጌታችን የኢየሱስ ክርስቶስ ጸጋ ከእናንተ ጋር ይሁን ። |
| **፳፬** | ፍቅርየ ምስለ ኵልክሙ በኢየሱስ ክርስቶስ አሜን ። | ፍቅሬ በክርስቶስ ኢየሱስ ከሁላችሁ ጋር ይሁን ፤ አሜን ። |

### ተፈጸመ (Colophon)

**ግዕዝ** ፡ ተፈጸመት ቀዳማዊት መልእክተ ጳውሎስ ኀበ ሰብአ ቆሮንቶስ ዘተጽሕፈት በኤፌሶን ፤ በእደ ጢሞቴዎስ ወእስጢፋኖስ ወፈርዶናጥስ ወአካይቆስ ። ስብሐት ለእግዚአብሔር ። አሜን ።

**አማርኛ** ፡ በኤፌሶን ተጽፋ በጢሞቴዎስ በእስጢፋኖስ በፈርዶናጥስ በአካይቆስ እጅ ወደ ቆሮንቶስ ሰዎች የተላከች የመጀመሪያይቱ መልእክት ተፈጸመች ። ለእግዚአብሔር ምስጋና ይሁን ። አሜን ።
