| **አርእስት** | **ክፍል ፲ወ፫ ፡ በእንተ ግብር ዘኢይደሉ ።** | **ክፍል ፲፫ ፡ ስለማይገባ ሥራ ።** |
| **፩** | እስመ ይሰማዕ በላዕሌክሙ ዝሙት ወዝሙትሂ ዘከመዝ ዘኢይገብርዎ አረሚ ጥቀ ፤ ሀሎ ዘአውሰበ ብእሲተ አቡሁ ። | በእናንተ ላይ ዝሙት ይሰማል ፤ እንደዚህ ያለውም ዝሙት አረማውያን እንኳ የማያደርጉት ነው ፤ የአባቱን ሚስት ያገባ አለ ። |
| **፪** | ወአንትሙሰ ምስለ ዝኒ ዕቡያን ፤ ወበእንተዝ ለምንት ፈድፋደ ኢለሀውክምዎ ከመ ይእተት እምኔክሙ ዘገብረ ዘንተ ። | እናንተስ ከዚህም ጋር ትዕቢተኞች ናችሁ ፤ ስለዚህ ይህን ያደረገው ከእናንተ ይለይ ዘንድ ለምን እጅግ ያላዘናችሁለት? |
| **፫** | ወአንሰ እመ ኢሀለውኩ በሥጋየ ምስሌክሙ በመንፈስየ ሀሎኩ ምስሌክሙ ፤ ወናሁ እኬንኖ ከመ ዘሀሎኩ ለዘገብሮ ለዝንቱ ግብር ። | እኔ በሥጋዬ ከእናንተ ጋር ባልኖር በመንፈሴ ከእናንተ ጋር አለሁ ፤ እነሆ ከእናንተ ጋር እንዳለሁ ሆኜ ይህን ሥራ የሠራውን እፈርድበታለሁ ። |
| **፬** | አንተሊክሙ በስመ እግዚእነ ኢየሱስ ክርስቶስ ምስለ መንፈስየ ወምስለ ኃይለ እግዚእነ ኢየሱስ ክርስቶስ መጥውዎ ለሰይጣን ። | በጌታችን በኢየሱስ ክርስቶስ ስም ተሰብስባችሁ ከእኔ ሥልጣን ከጌታችን ከኢየሱስ ክርስቶስ ኃይል ጋር ሆናችሁ ለሰይጣን አሳልፋችሁ ስጡት ። |
| **፭** | ከመ ይሥርዎ ሥጋሁ ወትድኃን መንፈሱ በዕለተ እግዚእነ ኢየሱስ ። | ሥጋውን ጎድቶት ጌታችን ኢየሱስ ክርስቶስ በሚመጣበት ቀን ነፍሱ ትድን ዘንድ ። |
| **አርእስት** | **ክፍል ፲ወ፬ ፡ በእንተ ብሑእ ።** | **ክፍል ፲፬ ፡ ስለ እርሾ ።** |
| **፮** | ኢኮነኬ ትዝህርትክሙ ሠናየ ፤ እንዘ ተአምሩ ከመ ኅዳጥ ብሑእ ብዙኃ ሐሪጸ ያብሕእ ። | እንግዲያስ ጥቂቱ እርሾ ብዙውን ዱቄት እንደሚያመጣ እያወቃችሁ መታበያችሁ መልካም አይደለም ። |
| **፯** | አንጽሑ እንከ ብሑአ ብሉየ እምኔክሙ ከመ ትኩኑ ለሐዲስ ሐሪጽ ፤ እስመ ዓዲክሙ ናእት አንትሙ ፤ አኮኑ በፋሲካነ ተሰቅለ ክርስቶስ ። | እንግዲህ አሮጌውን እርሾ ከእናንተ አርቁ ፤ ለአዲስ ብሆ ትሆኑ ዘንድ ገና ቂጣ ናችሁና ፤ ክርስቶስ በፋሲካችን ተሰቅሎ የለምን? |
| **፰** | ይእዜ ግበሩ በዓለክሙ ወአኮ በብሑእ ብሉይ ፤ ወአኮ በብሑእ እኩይ ዘኃጢአት ፤ አላ በብሑእ ዘቅድሳት ወበጽድቅ ። | አሁንም በዓላችሁን አድርጉ ፤ ግን በአሮጌው እርሾ አይደለም ፤ የኃጢአት ምክንያት በሚሆን በተበላሸ እርሾ አይደለም ፤ እውነትና ንጽሕና ባለው እርሾ ነው እንጂ ። |
| **አርእስት** | **ክፍል ፲ወ፭ ፡ በእንተ ምኵናን ።** | **ክፍል ፲፭ ፡ ስለ ፍርድ ።** |
| **፱** | ጸሐፍኩ ለክሙ ውስተ ዝንቱ መጽሐፍ ከመ ኢትደመሩ ምስለ ዘማውያን ። | ከዘማውያን ጋር እንዳትተባበሩ በዚህ መጽሐፍ ጻፍኩላችሁ ። |
| **፲** | ወአኮ ዝሙተ ዝ ዓለም ባሕቲቱ ፤ ሀለዉ ዓዲ መስተዐግላን ወሀያድያን ወእለሂ ያመልኩ ጣዖተ ፤ ወእመአኮሰ ይደልወክሙ ትፃኡ እምዝንቱ ዓለም ። | የዚህ ዓለም ዝሙት ብቻ አይደለም ፤ ቀማኞች ፡ ዘራፊዎች ፡ ጣዖትን የሚያመልኩ ደግሞ አሉ ፤ ያለዚያስ ከዚህ ዓለም ልትለዩ ይገባል ። |
| **፲፩** | ወይእዜሂ ጸሐፍኩ ለክሙ ከመ ኢትደመሩ ምስለ ዘማውያን ፤ ወእመቦ እምአኃው ዘያጣዕቡ አው ዓጣሂ አው ሀያዲ አው ረጋሚ አው ሰካሪ አው መስተዐግል ፤ ወምስለ ዘከመዝ ኢትትሐወሱ ። | አሁንም ከአመንዝሮች ጋር እንዳትገናኙ ጻፍኩላችሁ ፤ ከወንድሞቻችን መካከል ጣዖት የሚያመልክ ቢኖር ፤ ወይም ዐመፀኛ ወይም ቀማኛ ወይም ተሳዳቢ ወይም ሰካሪ ወይም የሚቀማ ቢኖር እንደዚህ ካሉ ሰዎች ጋር አትገናኙ ። |
| **፲፪** | ምንት ተልሒይየ አኮኑ ምስለ እለ በአፍአ ይትኬነኑ ፤ ወአንትሙሰ ኰንንዎሙ ለእለ ውስተ እለ ምስሌክሙ ወፍትሑ ላዕሌሆሙ ። | ምን አገባኝ ! ካልአመኑት ሰዎች ጋር ይፈረድባቸው የለምን? እናንተስ በውስጥ ያሉትን ከእናንተ ጋር የሚኖሩትን ፈርዳችሁ ቅጧቸው ። |
| **፲፫** | ወለእለ አፍአስ ይኬንኖሙ እግዚአብሔር ወይፈትሕ ላዕሌሆሙ ፤ ወባሕቱ አትቱ እምላዕሌክሙ እኩየ ። | ከሃይማኖት ውጪ ያሉትን ግን እግዚአብሔር ይፈርድባቸዋል ፤ በነፍስ በሥጋ ይቀጣቸዋል ፤ ብቻ ክፉውን ከእናንተ አርቁ ። |

## ምዕራፍ ፮

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፲ወ፮ ፡ በእንተ ዘኢይደሉ ተዋቅሦ በኀበ ዐማፅያን ።** | **ክፍል ፲፮ ፡ በዐመፀኞች ዳኝነት መከራከር ስለማይገባ ።** |
| **፩** | ወኢትትሀበሉ እንከ ትትዋቀሡ በኀበ ጸአልያን ፤ ቦኑ ዘይክል ይትዋቀሥ ምስለ ካልኡ በኀበ ዐማፅያን አኮኑ በኀበ ኄራን ፤ ወለእመቦ ዘቦ ትስናን ምስለ ቢጹ ለይትዋቀሥ በኀበ ቅዱሳን ወአኮ በኀበ ጸአልያን ወዐማፅያን ። | በዐመፀኞች ዘንድ ልትከራከሩ አትደፈሩ ፤ ከባልንጀራው ጋር ክርክር ያለው ሰው በዐመፀኞች ዘንድ ሊከራከር የሚችል አለን? በደጎች ዘንድ አይደለምን? ከባልንጀራው ጋር ክርክር ያለው ቢኖር በቅዱሳን ዘንድ ይከራከር እንጂ በተሳዳቢዎችና በዐመፀኞች ዘንድ አይደለም ። |
| **፪** | ወኢተአምሩኑ ከመ ቅዱሳን ይኬንንዎሙ ለዓለም ፤ ወእመሰኬ አንትሙ ትኬንንዎሙ ለዓለም ኢይደልወክሙኑ ትኬንንዎ ለዝንቱ ትሑት ምኵናን ። | ቅዱሳን ዓለምን እንዲፈርዱባቸው አታውቁምን? እናንተስ ዓለምን የምትፈርዱባቸው ከሆናችሁ ለዚህ ለተናቀ ፍርድ ልትፈርዱ አይገባችሁምን? |
