## ምዕራፍ ፩

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **አርእስት** | **ክፍል ፩ ፡ በእንተ ማኅበረ እግዚአብሔር ዘብሔረ ቆሮንቶስ ።** | **ክፍል ፩ ፡ በቆሮንቶስ ስላሉ የእግዚአብሔር ማኅበሮች ።** |
| **፩** | እምጳውሎስ ዘተሠይመ ሐዋርያሁ ለእግዚእነ ኢየሱስ ክርስቶስ በፈቃደ እግዚአብሔር ወስቴንስ እጉነ ። | በእግዚአብሔር ፈቃድ የጌታችን የኢየሱስ ክርስቶስ ሐዋርያ ሁኖ ከተሾመ ከጳውሎስና ከወንድማችን ከስቴንስ ። |
| **፪** | ለማኅበረ እግዚአብሔር ዘብሔረ ቆሮንቶስ እለ ተቀደሱ በኢየሱስ ክርስቶስ ወተሰምዩ ቅዱሳነ ወለኵሎሙ እለ ይጼውዑ ስሞ ለእግዚእነ ኢየሱስ ክርስቶስ ውስተ ኵሉ በሐውርቲሆሙ ። | በቆሮንቶስ አገር በኢየሱስ ክርስቶስ ለከበሩና ቅዱሳን ለተባሉ ለእግዚአብሔር ማኅበር በያገራቸው የጌታችን የኢየሱስ ክርስቶስን ስም ለሚጠሩ ሁሉ ትድረስ ። |
| **፫** | ወለነሂ ምስሌሆሙ ጸጋ ወሰላም እምኀበ እግዚአብሔር አቡነ ወእግዚእነ ኢየሱስ ክርስቶስ ። | እኛም ከነርሱ ጋር ከአባታችን ከእግዚአብሔር ከጌታችን ከኢየሱስ ክርስቶስ ዘንድ ጸጋና ሰላም ይሁንልን ። |
| **፬** | ዘልፈ አአኵቶ ለእግዚአብሔር በእንቲአክሙ ወበእንተ ጸጋሁ ለእግዚአብሔር ዘተውህበ ለክሙ በኢየሱስ ክርስቶስ ። | ስለ እናንተ በኢየሱስ ክርስቶስ ለእናንተ ስለ ተሰጠው ጸጋም ዘወትር እግዚአብሔርን አመሰግነዋለሁ ። |
| **፭** | እስመ ብዕልክሙ ቦቱ በኵሉ ቃል ወበኵሉ ጥበብ ። | በአነጋገር በዕውቀት ሁሉ ከብራችሁበታልና ። |
| **፮** | ወበከመ ጸንዐ ላዕሌክሙ ስምዑ ለክርስቶስ ። | የክርስቶስ ምስክርነቱ በእናንተ ላይ እንደ ጸና መጠን ። |
| **፯** | ከመ ኢትዕጥኡ ኵሎ ጸጋ ወትኩኑ ፍጹማነ እንዘ ትሴፈዉ ምጽአቶ ለእግዚእነ ኢየሱስ ክርስቶስ ። | የጌታችን የኢየሱስ ክርስቶስን መምጣት ተስፋ አድርጋችሁ ፍጹማን እንድትሆኑ ጸጋን ሁሉ እንዳታጡ ። |
| **፰** | ዘያጸንዐክሙ ለዝሉፉ ዘእንበለ ነውር በዕለተ እግዚእነ ኢየሱስ ክርስቶስ ። | ጌታችን ኢየሱስ ክርስቶስ በሚመጣበት ቀን ያለ ነውር ትገኙ ዘንድ ለዘላለሙ የሚያጸናችሁ እርሱ ነው ። |
| **፱** | ጻድቅ እግዚአብሔር ዘጸውዐክሙ ትኩኑ ሱቱፋነ ወልዱ ኢየሱስ ክርስቶስ እግዚእነ ። | ከልጁ ከጌታችን ከኢየሱስ ክርስቶስ ጋር አንድ ትሆኑ ዘንድ የጠራችሁ እግዚአብሔር እውነተኛ ነው ። |
| **አርእስት** | **ክፍል ፪ ፡ በእንተ ዘኢይደሉ ተጋዕዞ ።** | **ክፍል ፪ ፡ መነቃቀፍ እንደማይገባ ።** |
| **፲** | አስተበቍዐክሙ አኃዊነ በስሙ ለእግዚእነ ኢየሱስ ክርስቶስ ከመ ትበሉ ኵልክሙ አሐደ ቃለ ፤ ወኢትተክዙ ወትኩኑ ፍጹማነ ወኢትትፋለጡ ወሀልዉ በአሐዱ ምክር ወበአሐዱ ልብ ። | ወንድሞቻችን ! ሁላችሁ አንድ ቃል እንድትናገሩ እንዳታዝኑና ፍጹማን ትሆኑ ዘንድ ሳትለያዩ በአንድ ልብ ፤ በአንድ ሐሳብ ትኖሩ ዘንድ በጌታችን በኢየሱስ ክርስቶስ ስም እማልዳችኋለሁ ። |
| **፲፩** | ነገሩኒ በእንቲአክሙ አኃዊነ እምቤተ ቀለዮጳ ከመ ትትካሐዱ ወትትጋዐዙ ። | ወንድሞቻችን ! እንደምትጣሉና እንደምትከራከሩ ከቀለዮጳ ወገን ሰዎች ስለ እናንተ ነግረውኛል ። |
| **፲፪** | ወናሁ እነግረክሙ ዘትብሉ በበይናቲክሙ አነ ዘጳውሎስ ፤ ወአነ ዘአጵሎስ ፤ ወአነ ዘኬፋ ፤ ወአነ ዘክርስቶስ ። | እነሆ እርስ በርሳችሁ የምትሉትን ልንገራችሁ ፤ «እኔ የጳውሎስ ነኝ ፤ እኔ የአጵሎስ ነኝ ፤ እኔ የጴጥሮስ ነኝ ፤ እኔ የክርስቶስ ነኝ» ትላላችሁ ። |
| **፲፫** | ተናፈቀኑ ክርስቶስ ፤ ወቦኑ ጳውሎስ ተሰቅለ በእንቲአክሙ ፤ ወበስመ ጳውሎስኑ ተጠመቅሙ ። | ክርስቶስ ተከፋፈለን? ወይስ በውኑ ጳውሎስ ስለ እናንተ ተሰቀለን? በጳውሎስ ስምስ ተጠምቃችኋልን? |
| **፲፬** | አአኵቶ ለእግዚአብሔር ዘኢያጥመቅሁ እምውስቴትክሙ ዘእንበለ ቀርስጶስ ወጋይዮስ ። | ከቀርስጶስና ከጋይዮስ በቀር ከመካከላችሁ ማንንም ስላላጠመቅሁ እግዚአብሔርን አመሰግነዋለሁ ። |
| **፲፭** | ከመ አልቦ ዘይብል በስመ ዚአሁ ተጠመቅነ ። | በርሱ ስም ተጠመቅን የሚል እንዳይኖር ። |
| **፲፮** | ወባሕቱ አጥመቅሁ ቤተ እስጢፋኖስ ፤ ወኢየአምር እንከ ለእመቦ ባዕድ ዘአጥመቅሁ ። | ነገር ግን የእስጢፋኖስን ወገን አጥምቄአለሁ ፤ ሌላም ያጠመቅሁት እንዳለ አላውቅም ። |
| **፲፯** | እስመ ኢፈነወኒ ክርስቶስ ለአጥምቆ ዳእሙ ለምህሮ ። | ክርስቶስ ለማስተማር እንጂ ለማጥመቅ አልላከኝምና ። |
| **አርእስት** | **ክፍል ፫ ፡ በእንተ ነገረ መስቀል ።** | **ክፍል ፫ ፡ ስለ መስቀል ነገር ።** |
| **፲፰** | ወኢኮነ በጥበበ ነገር ከመ ኢንስዐር መስቀሎ ለክርስቶስ ፤ እስመ ነገረ መስቀሉሰ ዕበድ ውእቱ በኀበ ኅጉላን ፤ ወበኀቤነሰ ለእለ ድኅነ ኃይለ እግዚአብሔር ውእቱ ። | በነገር ልባምነት አይደለም ፤ የክርስቶስን መስቀሉን እንዳንሽር ፤ የመስቀሉ ነገር በጥፉዎች ዘንድ ስንፍና ነውና ፤ በዳንነው በኛ ዘንድ ግን የእግዚአብሔር ኃይል ነው ። |
| **፲፱** | እስመ ከመዝ ይቤ መጽሐፍ አነ አኀጕል ጥበቦሙ ለጠቢባን ወእሜንን ምክሮሙ ለመካርያን ። | «እኔ የጥበበኞችን ዕውቀት አጠፋለሁ ፤ የመካሮችንም ምክር እንቃለሁ» ብሎ መጽሐፍ ተናግሯልና ። |
| **፳** | መኑ እንከ ጠቢብ ወመኑ እንከ ጸሐፊ ፤ ወመኑ ዘየኀሥሦ ለዝ ዓለም ፤ አኮኑ አዕበዳ እግዚአብሔር ለጥበበ ዝ ዓለም ። | እንግዲህ ጥበበኛ ማነው? ከንግዲህ መካሬው ማነው? ይህንን ዓለም የሚሻውስ ማነው? እግዚአብሔር የዚህን ዓለም ጥበብ ስንፍና አድርጓታልና ። |
