| **ክፍል** | **ክፍል ፩ ፡ ዘከመ ጸለየ ለሰብአ ፊልጵስዩስ ።** | **ክፍል ፩ ፡ ለፊልጵስዩስ ሰዎች እንደ ጸለየላቸው ።** |
| **፩** | እምጳውሎስ ወጢሞቴዎስ አግብርተ ኢየሱስ ክርስቶስ ፤ ለኵሎሙ ቅዱሳን እለ ተቀደሱ በኢየሱስ ክርስቶስ እለ ህለዉ ፊልጵስዩስ ፤ ምስለ ቀሳውስት ወዲያቆናት ። | የኢየሱስ ክርስቶስ ባሪያዎች የሆኑ ጳውሎስና ጢሞቴዎስ ፤ በፊልጵስዩስ ለሚኖሩ ከኤጲስ ቆጶሳትና ከዲያቆናት ጋር በክርስቶስ ኢየሱስ ላሉት ቅዱሳን ሁሉ ፤ |
| **፪** | ሰላም ለክሙ ወጸጋ እግዚአብሔር አቡነ ወእግዚእነ ኢየሱስ ክርስቶስ ። | ከእግዚአብሔር ከአባታችን ከጌታም ከኢየሱስ ክርስቶስ ጸጋና ሰላም ለእናንተ ይሁን ። |
| **፫** | አእኵቶ ለእግዚአብሔር ዘልፈ በኵሉ ትዝክርክሙ ኪያየ ። | እናንተን ባሰብሁበት ጊዜ ሁሉ አምላኬን አመሰግናለሁ ፤ |
| **፬** | ወእጼሊ በኵሉ ጊዜ በእንቲአክሙ ፤ ወአገብር ጸሎተ ፍሥሐ ። | ሁልጊዜ በጸሎቴ ሁሉ ስለ እናንተ ሁሉ በደስታ እጸልያለሁ ፤ |
| **፭** | በእንተ ተሳትፎትክሙ ኪያየ በትምህርተ ወንጌል ፤ እምቀዳሚት ዕለት እስከ ይእዜ ። | ከፊተኛው ቀን ጀምሮ እስከ ዛሬ ድረስ ወንጌልን በማገልገል አብራችሁ ስለ ሠራችሁ ፤ |
| **፮** | እስመ እትአመን ከመ ውእቱ ዘወጠነ ለክሙ ግብረ ሠናየ ፤ ውእቱ ይፌጽም ለክሙ እስከ ዕለተ ኢየሱስ ክርስቶስ ። | በእናንተ መልካሙን ሥራ የጀመረው እስከ ኢየሱስ ክርስቶስ ቀን ድረስ እንዲፈጽመው ፤ ይህንኑ እርግጠኛ ሆኜ አምናለሁና ፤ |
| **፯** | እስመ ርቱዕ ሊተ ዘንተ አሐሊ በእንቲአክሙ ፤ እስመ ሀሎክሙ ውስተ ልብየ በመዋቅሕትየ ወበቅስትየ ወበትምህርተ ጽድቅ ፤ እስመ ኀበርክሙ ምስሌየ በጸጋ ። | በእስራቴም ወንጌልንም በመመከቴና በማጽናቴ ሁላችሁ ከእኔ ጋር በጸጋ ተካፋዮች ስለ ሆናችሁ ፤ በልቤ ስላላችሁ ስለ ሁላችሁ ይህን እንዳስብ ይገባኛልና ። |
| **፰** | ወእግዚአብሔር ሰማዕትየ ፤ ከመ አፈቅረክሙ በፍቅረ ክርስቶስ ። | በክርስቶስ ኢየሱስ ፍቅር ሁላችሁን እንዴት እንደምናፍቃችሁ ፤ እግዚአብሔር ምስክሬ ነውና ። |
| **፱** | ወእጼሊ በእንተ ዝንቱ ፤ ከመ ይብዛኅ ወይፈድፍድ ተፋቅሮትክሙ በአእምሮ ወበኵሉ ጥበበ መንፈስ ። | ለዚህም እጸልያለሁ ፤ ፍቅራችሁ በእውቀትና በማስተዋል ሁሉ ከፊት ይልቅ እያደገ እንዲበዛ ፤ |
| **፲** | ከመ ትፍትኑ ወታመክሩ ዘይኄይስ ወዘይሜሂ ግብረ ፤ ከመ ትኩኑ ቅዱሳነ ዘእንበለ ዕቅፍት በዕለተ ክርስቶስ ። | የሚሻለውን ነገር ፈትናችሁ እንድትመርጡ ፤ ለክርስቶስም ቀን ቅኖችና ያለ ዕንቅፋት እንድትሆኑ ፤ |
| **፲፩** | እንዘ ምሉአን አንትሙ ፍሬ ጽድቅ በኢየሱስ ክርስቶስ ፤ ለስብሐተ እግዚአብሔር ወአኵቴቱ ። | ለእግዚአብሔር ክብርና ምስጋና በኢየሱስ ክርስቶስ የሚገኘውን የጽድቅ ፍሬ ተሞልታችሁ ። |
| **ክፍል** | **ክፍል ፪ ፡ በእንተ ተሞቅሖቱ ለጳውሎስ ።** | **ክፍል ፪ ፡ ስለ ጳውሎስ መታሰር ።** |
| **፲፪** | ወእፈቅድ አኃውየ ታእምሩ ዜናየ ፤ ከመ ፈድፋደ ተለዐለ ውስተ ትምህርተ ወንጌሉ ለክርስቶስ ። | ነገር ግን ወንድሞች ሆይ ! ይህ የደረሰብኝ ነገር ይልቁን ወንጌልን ለማስፋፋት እንደ ሆነ እንድታውቁ እወዳለሁ ፤ |
| **፲፫** | ወተዐውቀ መዋቅሕትየ በክርስቶስ ፤ በኀበ ኵሉ ምኵናን ወበኀበ ኵሉ ሰብእ ። | እንዲሁም እስራቴ በክርስቶስ ምክንያት እንደ ሆነ በንጉሥ ግቢ ሁሉና በሌሎችም ሁሉ ዘንድ ተገልጦአል ፤ |
| **፲፬** | ወከመ ብዙኃን እምአኃዊነ ምእመናን በእግዚእነ ተዐገሡ በመዋቅሕትየ ፤ ወፈድፋደ ተኀበሉ አጥቢዖሙ ይንግሩ ቃለ እግዚአብሔር ዘእንበለ ፍርሃት ። | በጌታም ካሉት ወንድሞች የሚበዙት በእስራቴ ታምነው ፤ የእግዚአብሔርን ቃል ያለ ፍርሃት ለመናገር ከፊት ይልቅ ይደፍራሉ ። |
| **፲፭** | ወቦ እለ በቅንአቶሙ ወቦ እለ በተቃኅዎቶሙ ፤ ወቦ እለ ፈቀዱ ይስብኩ በፍቅር ሠናይ ወይምሀሩ በእንተ ክርስቶስ ። | አንዳንዶች በቅንአትና በክርክር እንኳ ክርስቶስን ይሰብኩታል ፤ አንዳንዶች ግን በበጎ ፈቃድ ይሰብኩታል ፤ |
| **፲፮** | እስመ የአምሩ ከመ ለምህሮ ወንጌል ተሠየምኩ ዓዲ ። | እነዚህ ወንጌልን ለመከላከል እንደ ተሾምኩ አውቀው በፍቅር ይሰብካሉ ፤ |
| **፲፯** | ወእለሰ በትዝዕርቶሙ ይነግሩ በእንተ ክርስቶስ አኮ በንጽሕ ፤ ዳእሙ ይትሐዘቡ ከመ ገቢሮሙ ኪያሁ ይወስኩ ሊተ ሕማመ በመዋቅሕትየ ። | እነዚያ ግን በእስራቴ ላይ መከራን ሊያመጡብኝ አስበው በቅን ልብ ሳይሆን በክፋት ክርስቶስን ያወራሉ ። |
| **፲፰** | ወናሁ ተፈሣሕኩ በዝንቱ ወእትፌሣሕኒ ቦቱ ፤ ከመ በኵሉ ምክንያት ይንግሩ በእንተ ክርስቶስ ፤ አመሂ በአድልዎ ወእመኒ በአማን ወይጸውዑ ኀቤሁ ኵሎ ሰብአ ። | ምን ቸገረኝ ? በግብዝነት ቢሆን ወይም በእውነት በማናቸውም መንገድ ቢሆን ክርስቶስ ይሰበካል ፤ በዚህም ደስ ይለኛል ፤ ወደ ፊትም ደግሞ ደስ ይለኛል ። |
| **፲፱** | ወአነ አአምር ከመ ዛቲ ግብር ታበጽሐኒ ኀበ ሕይወት ፤ በጸሎትክሙ ወበሀብተ መንፈሱ ለኢየሱስ ክርስቶስ ። | ይህ በጸሎታችሁና በኢየሱስ ክርስቶስ መንፈስ ረዳትነት ለመዳኔ እንዲሆንልኝ አውቃለሁና ፤ |

## መደምደሚያ (Colophon)

| ክፍል | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **መደምደሚያ** | **ተፈጸመት መልእክት ኀበ ሰብአ ፊልጵስዩስ ዘተጽሕፈት በሮሜ ወተፈነወት በእደ ጢሞቴዎስ ወአፍሮዲጡ ፤ ወስብሐት ለእግዚአብሔር ፤ አሜን ።** | **በሮም ተጽፋ በጢሞቴዎስና በአፍሮዲጡ እጅ ወደ ፊልጵስዩስ የተላከች መልእክት ተፈጸመች ። ለእግዚአብሔር ክብር ምስጋና ይሁን ፤ አሜን ።** |

---

**ተፈጸመት መልእክት ኀበ ሰብአ ፊልጵስዩስ ፡ ወስብሐት ለእግዚአብሔር ለዓለመ ዓለም ፡ አሜን ።**
