# የዮሐንስ ራእይ አንድምታ ትርጓሜ (ሙሉእ ኦዲት)

*The Revelation of St. John Complete Verified Edition — (405 Verses + Colophon)*

---

## ምዕራፍ ፩

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :---: | :--- | :--- |
| ፩ | ራእዩ ለዮሐንስ ዘከመ ርእዮ ለኢየሱስ ክርስቶስ ዘወሀቦ እግዚአብሔር ከመ ያርእዮሙ ለአግብርቲሁ ዘሀለዎ ይኩን ፍጡነ ወዘይከውን እምድኅረዝ ። | ኢየሱስ ክርስቶስን እንዳየው ፈጥኖ ይደረግ ዘንድ ያለውን ፤ ከዚያም በኋላ የሚመጣውንም ለባለሟሎቹ ይገልጥላቸው ዘንድ እግዚአብሔር የገለጠለት ። |
| ፪ | ወፈነወ ምስለ መልአኩ ኀበ ዮሐንስ ገብሩ ዘኮነ ስምዐ በእንተ ቃለ እግዚአብሔር ወበእንተ ስምዑ ለኢየሱስ ክርስቶስ ወበእንተ ኵሉ ዘርእየ ። | በመልአኩ ወደ አገልጋዩ ዮሐንስ የላከው ፤ ስለ እግዚአብሔር ቃልና ስለ ኢየሱስ ክርስቶስ ምስክር ባየው ሁሉ ላይ ምስክር የሆነ ። |
| ፫ | ወብፁዕ ውእቱ ዘያነብቦ ወዘይሰምዕ ቃለ ተነብዮቱ ለዝንቱ መጽሐፍ ወዘየዐቅብ ዘጽሑፍ ውስቴቱ እስመ ቅሩብ ዘመኑ ። | የሚያነበው ንዑድ ክቡር ነው ፤ የዚህን መጽሐፍ የትንቢቱን ቃል የሚሰማ ፤ በውስጡ የተጻፈውንም የሚጠብቅ ንዑድ ክቡር ነው ዘመኑ ቅርብ ነውና ። |
| ፬ | ዘጸሐፈ ዮሐንስ ለሰብዐቱ አብያተ ክርስቲያናት እለ ውስተ እስያ ፤ ሞገስ ለክሙ ወሰላም እምኀበ ዘሀሎ ወይሄሉ ዘመጽአ ወዘይመጽእ ወእምነ ሰብዐቱ መንፈስ ዘቅድመ መንበሩ ለኢየሱስ ክርስቶስ ። | በእስያ ውስጥ ለሚገኙ ለሰባቱ አብያተ ክርስቲያናት ዮሐንስ የጻፈው ይህ ነው ፤ ቀድሞ ከነበረው ከሚኖረው ወደዚህ ዓለም ከመጣው ወደፊትም ከሚመጣው ፤ በኢየሱስ ክርስቶስ በዙፋኑ ፊት ካለው ፍጹም መንፈስ ምስጋናው ሰላሙ ለእናንተ ይሁን ። |
| ፭ | ዘውእቱ ስምዕ መሃይምን ወውእቱ ቀደመ በኵረ ከዊነ እምነ ምውታን ዘተንሥአ ወውእቱ መኰንኖሙ ለነገሥተ ምድር ፤ ውእቱ ዘአፍቀረክሙ ወሐፀበክሙ እምኃጣውኢክሙ በደሙ ። | የታመነ ምስክር በኵር መሆንን ጀምሮ ቀድሞ ከሙታን የተነሣ ፤ የምድር ነገሥታትንም የሚገዛቸው የወደዳችሁ ፤ ከኃጢአታችሁም በደሙ ያነጻችሁ እርሱ ነው ። |
| ፮ | ወረሰየክሙ ውስተ መንግሥተ ቅድሳተ አቡሁ እግዚአብሔር ዘሎቱ ስብሐት ወኃይል ለዓለመ ዓለም አሜን ። | አባቱ እግዚአብሔር በሚመሰገንበት መንግሥተ ሰማይ እንድትኖሩ አደረጋችሁ ፤ ምስጋና ኃይል ለዘለዓለሙ ለእርሱ ይሁን አሜን ። |
| ፯ | ናሁ ይመጽእ በደመና ሰማይ ወትሬእዮ ኵላ ዐይን ወእልክቱሂ እለ ወግእዎ ወይበክዩ በእንቲአሁ ኵሎሙ አሕዛበ ምድር ፤ እወ ወአማን ። | እነሆ በሰማይ ደመና ይመጣል ፤ ዓይን ሁሉ ያየዋል ፤ እነዚያ የወጉትም ያዩታል ፤ የምድር አሕዛብም ሁሉ ያለቅሳሉ ፤ አዎን እውነት ነው ። |
| ፰ | አነ ውእቱ አልፋ ወኦ ይቤ እግዚአብሔር ዘሀሎ ወይሄሉ ዘመጽአ ወዘይመጽእ ዘውእቱ ይመልክ ኵሎ ። | ቅድመ ዓለም የነበረው ዓለምን አሳልፎ የሚኖረው ፤ ወደዚህ ዓለም የመጣው ወደፊትም የሚመጣው ፤ ሁሉን የሚገዛ እግዚአብሔር አልፋ ወኦ ቀዳማዊ ደኃራዊም እኔ ነኝ አለ ። |
| ፱ | ወአነ ዮሐንስ እኁክሙ ወሱታፌክሙ በሕማምክሙ ወበመንግሥትክሙ ወበትዕግሥትክሙ በእንተ ትዕግሥቱ ለኢየሱስ ክርስቶስ ፤ ወእንዘ ሀሎኩ ውስተ ደሴት እንተ ስማ ፍጥሞ በእንተ ቃለ እግዚአብሔር ወበእንተ ስምዑ ለኢየሱስ ። | ስለ ኢየሱስ ክርስቶስ መታገሥ በትዕግሥታችሁና በመከራችሁ በመንግሥታችሁም ተባባሪያችሁና ወንድማችሁ የምሆን እኔ ዮሐንስ ፤ ስለ እግዚአብሔር ቃልና ስለ ኢየሱስ ክርስቶስ መመስከር ፍጥሞ በሚሏት ደሴት ሳለሁ ። |
| ፲ | መጽአ ላዕሌየ መንፈስ በዕለተ እሑድ ወሰማዕኩ ቃለ ዐቢየ እምድኅሬየ ከመ ቃለ ቀርን ። | በዕለተ እሑድ መንፈስ ቅዱስ አደረብኝ ፤ ከኋላዬም እንደ መለከት ድምፅ ያለ ታላቅ ቃል ሰማሁ ። |
| ፲፩ | ወይቤለኒ ጸሐፍ እንከ ዘትሬኢ ወዘትሰምዕ ውስተ መጽሐፍ ወፈኑ ለአብያተ ክርስቲያናት ሰብዐቱ እለ ውስተ እስያ ፤ ዘኤፌሶን ወዘሴሜርኔስ ወዘጴርጋሞን ወዘተያጥሮን ወዘሰርዴስ ወዘፊልድልፍልያ ወዘሎዶቅያ ። | እንግዲህ የምታየውንና የምትሰማውን በዚህ መጽሐፍ ጽፈህ በእስያ በኤፌሶን በሴሜርኔስ በጴርጋሞን በተያጥሮን በሰርዴስ በፊልድልፍልያ በሎዶቅያ ላሉት ሰባቱ አብያተ ክርስቲያናት ላክ አለኝ ። |
| ፲፪ | ወተመየጥኩ እርአይ ዝኩ ቃለ ዘይትናገር ምስሌየ ወሶበ ተመየጥኩ ናሁ እሬኢ ሰብዐ መኃትወ ዘወርቅ ። | የሚነግረኝን ቃል እሰማ ዘንድ ወደ ኋላዬ ተመለስኩ ፤ በተመለስኩም ጊዜ ሰባት የወርቅ ፋናዎችን አየሁ ። |
| ፲፫ | ወማእከለ ሰብዑ መኃትው ይነብር ከመ ወልደ እጓለ እመሕያው ወይለብስ ልብሰ ኔዴር ወቅኑት ውስተ ሐቋሁ በቅናት ዘወርቅ ። | በሰባቱም የወርቅ ፋና መካከል እንደ ሰው ልጅ ተቀምጧል ፤ ኔዴር የሚባል ልብስ ለብሷል ፤ በወገቡም የወርቅ መታጠቂያ ታጥቋል ። |
| ፲፬ | ወፀዐዳ ርእሱ ወሥዕርቱ ከመ ፀምር ፀዐዳ ወአዕይንቲሁ ከመ ነደ እሳት ። | ራሱም ነጭ ነው ፤ ጠጕሩም እንደ ነጭ ሐር ነው ፤ ዓይኖቹም እንደ እሳት ነበልባል ናቸው ። |
| ፲፭ | ወእገሪሁ ከመ ብርተ ሊባኖስ ዘአርሰንዎ በእሳት ፤ ወቃሉ ከመ ቃለ ማይ ብዙኅ ። | እግሮቹም በእሳት እንዳጋሉት እንደ ደጋ ብረት ናቸው ፤ ቃሉም እንደ ፈፋቴ ውኃ ድምፅ ነው ። |
| ፲፮ | ወውስተ እዴሁ ዘየማን ሰብዐቱ ኮከብ ፤ ወይወጽእ እምነ አፉሁ ሰይፍ በሊሕ ዘክልኤ አፉሁ ወገጹ ከመ ፀሐይ ብሩህ ዘያስተርኢ በኃይሉ ። | በቀኝ እጁ ሰባት ከዋክብት ተይዘዋል ፤ ከአፉም የተሳለ ሁለት አፍ ያለው ሰይፍ ይወጣል ፤ ፊቱም በኃይል እንደሚታይ ብሩህ ፀሐይ ነው ። |
| ፲፯ | ወሶበ ርኢክዎ ወደቁ ውስተ እገሪሁ ወኮንኩ ከመ በድን ፤ ወአኀዘኒ በየማኑ ወአንሥአኒ ወይቤለኒ ኢትፍራህ አነ ውእቱ ቀዳማዊ ወደኃራዊ ዘሕያው ። | ባየሁትም ጊዜ ከእግሩ በታች ወድቄ እንደ በድን ሆንኩ ፤ በቀኝ እጁ ይዞ አስነሣኝ ፤ ቀዳማዊ ደኃራዊ የምሆን ሕያው እኔ ነኝ አትፍራ አለኝ ። |

## ምዕራፍ ፭

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |

| ፩ | ወእምዝ ርኢኩ ውስተ የማኑ ለውእቱ ዘይነብር ዲበ መንበር መጽሐፈ ጽሕፍተ እንተ ውሥጣ ወእንተ አፍአሃ ፤ ወኅትምት በሰብዐቱ ማኅተም ። | በዙፋኑም ላይ በተቀመጠው በቀኝ እጁ ላይ በውስጥና በኋላ የተጻፈበት በሰባትም ማኅተም የተዘጋ መጽሐፍን አየሁ ። |
| ፪ | ወርኢኩ መልአክ ዐቢይ ይጸርሕ ወይብል በቃል ዐቢይ ፤ መኑ ይደልዎ ይክሥታ ለዛቲ መጽሐፍ ወይፍታሕ ማኅተሚሃ ። | ብርቱም መልአክ ፤ መጽሐፉን ይዘረጋ ዘንድ ማኅተሞቹንም ይፈታ ዘንድ የሚገባው ማን ነው ? ብሎ በታላቅ ድምፅ ሲሰብክ አየሁ ። |
| ፫ | ወአልቦ ዘክህለ ከሢቶታ ለይእቲ መጽሐፍ ወኢርእዮታ ፤ ኢበሰማይ ወኢበምድር ። | በሰማይም ቢሆን በምድርም ላይ ቢሆን ከምድርም በታች ቢሆን መጽሐፉን ሊዘረጋ ወይም ሊያየው ማንም አልተቻለውም ። |
| ፬ | ወብዙኃን እለ በከዩ ወአነሂ ምስሌሆሙ እስመ አልቦ ዘተረክበ ዘይደልዎ ይክሥታ ለይእቲ መጽሐፍ ወይርአያ ። | መጽሐፉን ሊዘረጋ ወይም ሊያየው የሚገባው ማንም ስላልተገኘ እጅግ አለቀስሁ ። |
| ፭ | ወይቤለኒ አሐዱ እምውስተ እልክቱ ሊቃናት ኢትብኪ ፤ ናሁ ሞዐ አንበሳ ዘእምነገደ ይሁዳ ዘእምውስተ ሥርዉ ለዳዊት ከመ ይፍታሓ ለይእቲ መጽሐፍ ወለማኅተሚሃ ። | ከሽማግሌዎቹም አንዱ ፤ አታልቅስ ፤ እነሆ ከይሁዳ ነገድ የሆነው አንበሳ እርሱም የዳዊት ሥር መጽሐፉን ይዘረጋ ዘንድ ሰባቱንም ማኅተም ይፈታ ዘንድ ድል ነሥቷል አለኝ ። |

| ፲፪ | ወይብሉ በቃል ዐቢይ ይደልዎ ለውእቱ በግዕ ዘተቀትለ ከመ ይንሣእ ኃይለ ወብዕለ ወጥበበ ወጽንዐ ወመንግሥተ ወክብረ ወስብሐተ ወበረከተ ። | በታላቅም ድምፅ ፤ የታረደው በግ ኃይልና ባለጠግነት ጥበብም ብርታትም ክብርም ምስጋናም በረከትም ሊቀበል ይገባዋል አሉ ። |
