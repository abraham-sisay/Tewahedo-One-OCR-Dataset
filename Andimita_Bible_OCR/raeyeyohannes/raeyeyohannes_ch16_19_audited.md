# የዮሐንስ ራእይ አንድምታ ትርጓሜ (ምዕራፍ ፲፮ - ፲፱)

*Revelation Chapters 16-19 Audited & Verified Edition — (84 Verses)*

---

## ምዕራፍ ፲፮

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :---: | :--- | :--- |
| ፩ | ወሰማዕኩ ቃለ ዐቢየ እምነ ቤተ መቅደስ ዘይብሎሙ ለእልክቱ ሰብዐቱ መላእክት ፤ ሑሩ ወከዐዉ ጽዋዐ መዐቱ ለእግዚአብሔር ውስተ ኵላ ምድር ። | ታላቅም ድምፅ ከመቅደሱ ለሰባቱ መላእክት ፤ ሂዱ ፤ የእግዚአብሔርን የቍጣውን ጽዋዎች ወደ ምድር አፍስሱ ሲል ሰማሁ ። |
| ፪ | ወሖረ መልአክ ቀዳማዊ ወከዐወ ጽዋዖ ውስተ ምድር ፤ ወመጽአ ላዕለ እልክቱ ሰብእ እለ ጸሐፉ ትእምርቶ ለዝክቱ አርዌ ወሰገዱ ለምስሉ ፤ ወመጽአ ላዕሌሆሙ ቍስል እኩይ ። | ፊተኛውም ሄደ ጽዋውንም በምድር ላይ አፈሰሰ ፤ የአውሬውም ምልክት ባለባቸው ለምስሉም በሰገዱት ሰዎች ላይ ክፉና የሚመርጥ ቍስል ሆነባቸው ። |
| ፫ | ወከዐወ ካልእ መልአክ ጽዋዖ ውስተ ባሕር ፤ ወኮነት ባሕር ደመ ከመ ደመ በድን ወሞተ ኵሉ ነፍሰ ሕይወት ዘውስተ ባሕር ። | ሁለተኛውም መልአክ ጽዋውን በባሕር ላይ አፈሰሰ ፤ እንደ ሙተ ሰው ደም ደም ሆነ ፤ በባሕርም ከሚኖሩት ሕይወት ያለበት ነፍስ ሁሉ ሞተ ። |
| ፬ | ወከዐወ ሣልስ መልአክ ጽዋዖ ውስተ አፍላግ ወውስተ አፍላጋተ ማይ ፤ ወኮኑ ደመ ። | ሦስተኛውም መልአክ ጽዋውን በወንዞችና በውኃዎች ምንጮች ላይ አፈሰሰ ፤ ደምም ሆኑ ። |
| ፭ | ወሰማዕኩ መልአከ ማያት እንዘ ይብል ፤ ጻድቅ አንተ እግዚኦ ዘሀሎ ወዘሀለወ ቅዱስ እስመ ከመዝ ፈተንከ ። | የውኃዎችም መልአክ ፤ ያለህና የነበርህ ጌታ ሆይ ፤ ቅዱስ ሆይ ፤ እንዲህ ስለ ፈረድህ ጻድቅ ነህ ፤ |
| ፮ | እስመ ከዐዉ ደመ ቅዱሳን ወነቢያት ፤ ወወሀብኮሙ ደመ ይስተዩ እስመ ደለዎሙ ። | የቅዱሳንንና የነቢያትን ደም ስላፈሰሱ ደምን ደግሞ አጠጣሃቸው ፤ የሚገባቸው ነውና ሲል ሰማሁ ። |
| ፯ | ወሰማዕኩ እምነ ምሥዋዕ ዘይብል ፤ እወ እግዚኦ አምላክ አኃዜ ኵሉ ፤ ጽድቅ ወርትዕ ፍትሕከ ። | ከመሠዊያውም ፤ አዎን ፤ ሁሉን የምትገዛ ጌታ አምላክ ሆይ ፤ ፍርድህ እውነትና ቅን ነው ሲል ሰማሁ ። |
| ፰ | ወከዐወ ራብዕ መልአክ ጽዋዖ ዲበ ፀሐይ ፤ ወተውህበ ሎቱ ከመ ያውዒ ሰብአ በእሳት ። | አራተኛውም መልአክ ጽዋውን በፀሐይ ላይ አፈሰሰ ፤ ሰዎችንም በእሳት እንዲያቃጥል ሥልጣን ተሰጠው ። |
| ፱ | ወተውዕዩ ሰብእ በውዑይ ዐቢይ ፤ ወጸረፉ ስመ እግዚአብሔር ዘቦ ሥልጣን ላዕለ እሉ መቅሠፍት ፤ ወኢነስሑ ከመ የሀብዎ ስብሐተ ። | ሰዎችም በታላቅ ትኩሳት ተቃጠሉ ፤ በእነዚህም መቅሠፍቶች ላይ ሥልጣን ያለውን የእግዚአብሔርን ስም ተሳደቡ ፤ ክብርንም እንዲሰጡት ንስሐ አልገቡም ። |
| ፲ | ወከዐወ ኃምስ መልአክ ጽዋዖ ዲበ መንበሩ ለውእቱ አርዌ ፤ ወጸልመት መንግሥቱ ወይነክሱ ልሳናቲሆሙ እምነ ፃማሆሙ ። | አምስተኛውም መልአክ ጽዋውን በአውሬው ዙፋን ላይ አፈሰሰ ፤ መንግሥቱም ጨለመች ፤ ሰዎችም ከሥቃይ የተነሣ መላሳቸውን በሉ ፤ |
| ፲፩ | ወጸረፉ ለአምላከ ሰማይ እምፃማሆሙ ወእምቍስሎሙ ፤ ወኢነስሑ እምነ ምግባሮሙ ። | ከሥቃያቸውና ከቍስላቸውም የተነሣ የሰማይን አምላክ ተሳደቡ ፤ ከሥራቸውም ንስሐ አልገቡም ። |
| ፲፪ | ወከዐወ ሳድስ መልአክ ጽዋዖ ዲበ ዐቢይ ፈለገ ኤፍራጥስ ፤ ወነጽፈ ማዩ ከመ ይትደለው ፍናሆሙ ለነገሥት እለ እምሥራቀ ፀሐይ ። | ስድስተኛውም መልአክ ጽዋውን በታላቁ ወንዝ በኤፍራጥስ ላይ አፈሰሰ ፤ ከፀሐይ መውጫ ለሚመጡ ነገሥታት መንገድ እንዲዘጋጅላቸው ውኃው ደረቀ ። |
| ፲፫ | ወርኢኩ እምአፉሁ ለውእቱ ከይሲ ወእምአፉሁ ለውእቱ አርዌ ወእምአፉሁ ለውእቱ ሐሳዊ ነቢይ ሠለስቱ መናፍስተ ርኩሳነ ዘከመ ጐርዖት ። | ከዘንዶውም አፍና ከአውሬው አፍ ከሐሰተኛውም ነቢይ አፍ ጓጉንቸሮች የሚመስሉ ሦስት ርኩሳን መናፍስት ሲወጡ አየሁ ፤ |
| ፲፬ | እስመ መናፍስተ አጋንንት እሙንቱ እለ ይገብሩ ተአምራተ ፤ ወየሐውሩ ኀበ ነገሥተ ምድር ከመ ያከብትዎሙ ለፀብዕ በእንተ ዕለተ ኵነኔሁ ለእግዚአብሔር ዐባይ አኃዜ ኵሉ ። | ምልክት እያደረጉ የአጋንንት መናፍስት ናቸውና ፤ በሁሉ ላይ በሚገዛ በታላቁ በእግዚአብሔር ቀን ወደሚሆነው ጦር እንዲያሰባስቧቸው ወደ ምድር ሁሉ ነገሥታት ይወጣሉ ። |
| ፲፭ | ናሁ እመጽእ ከመ ሰራቂ ፤ ብፁዕ ዘይተግህ ወየዐቅብ አልባሲሁ ከመ ኢየሐውር ዕሩቆ ወኢይርአዩ ኃፍረቶ ። | እነሆ እንደ ሌባ ሆኜ እመጣለሁ ፤ ዕራቁቱን እንዳይሄድ እፍረቱንም እንዳያዩ ነቅቶ ልብሱን የሚጠብቅ ብፁዕ ነው ። |
| ፲፮ | ወአስተጋብእዎሙ ውስተ መካን ዘይሰመይ በዕብራይስጢ አርማጌዶን ። | በዕብራይስጥም አርማጌዶን ወደሚባለው ስፍራ አሰባሰቧቸው ። |
| ፲፯ | ወከዐወ ሳብዕ መልአክ ጽዋዖ ዲበ አየር ፤ ወወፅአ ቃል ዐቢይ እምነ ቤተ መቅደስ እምነ መንበሩ ዘይብል ፤ ተገብረ ። | ሰባተኛውም መልአክ ጽዋውን በአየር ላይ አፈሰሰ ፤ ከመቅደሱም ከዙፋኑ ፤ ተፈጸመ የሚል ታላቅ ድምፅ ወጣ ። |
| ፲፰ | ወኮነ መብረቅ ወደምፅ ወነጐድጓድ ወኮነ ደልቀታ ዐቢይ ዘኢኮነ ከመዝ እምአመ ተፈጥረ ሰብእ ውስተ ምድር ከመዝ ደልቀታ ዐቢይ ። | መብረቅና ድምፅም ነጐድጓድም ሆኑ ፤ ሰው በምድር ላይ ከሆነ ጀምሮ እንዲህ ያለ ታላቅ መናወጥ ሆኖ የማያውቅ ብርቱ የምድር መናወጥ ሆነ ። |
| ፲፱ | ወተከፍለት ይእቲ ሀገር ዐባይ በሠለስቱ መካን ወወድቁ አህጉረ አሕዛብ ፤ ወተዘከረት ባቢሎን ዐባይ በቅድመ እግዚአብሔር ከመ የሀባ ጽዋዐ ወይነ መዐቱ ። | ታላቂቱም ከተማ በሦስት ተከፈለች ፤ የአሕዛብም ከተሞች ወደቁ ፤ ታላቂቱም ባቢሎን የብርቱ ቍጣውን የወይን ጠጅ ጽዋ እንዲሰጣት በእግዚአብሔር ፊት ታሰበች ። |
| ፳ | ወጐዩ ኵሉ ደስያት ወአድባርኒ ኢተረክቡ ። | ደሴቶችም ሁሉ ሸሹ ፤ ተራራዎችም አልተገኙም ። |
| ፳፩ | ወወረደ እምሰማይ ላዕለ ሰብእ በረድ ዐቢይ ዘከመ መክሊት ፤ ወጸረፉ ሰብእ ለእግዚአብሔር እምነ መቅሠፍተ ዝኩ በረድ እስመ ዐባይ ጥቀ ይእቲ መቅሠፍቱ ። | እንደ አንድ ታላቅ መክሊት የሚያህል ታላቅ በረድ ከሰማይ በሰዎች ላይ ወደቀ ፤ መቅሠፍቱ እጅግ ታላቅ ነበረና ሰዎች ከበረዱ መቅሠፍት የተነሣ እግዚአብሔርን ተሳደቡ ። |
