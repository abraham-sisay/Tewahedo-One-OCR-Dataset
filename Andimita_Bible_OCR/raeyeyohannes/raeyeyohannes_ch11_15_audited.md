# የዮሐንስ ራእይ አንድምታ ትርጓሜ (ምዕራፍ ፲፩ - ፲፭)

*Revelation Chapters 11-15 Audited & Verified Edition — (83 Verses)*

---

## ምዕራፍ ፲፩

| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :---: | :--- | :--- |
| ፩ | ወተውህበኒ ዘንጋ ዘይመስል በትረ ከመ እለክዕ ቤተ መቅደስ ፤ ወይቤለኒ ተንሥእ ወለክዖ ለቤተ መቅደሰ እግዚአብሔር ወለምሥዋዕ ወለእለ ይሰግዱ ውስቴቱ ። | መሰንበቻንም የሚመስል መለኪያ ሸምበቆ ተሰጠኝ ፤ እርሱም ፤ ተነሥተህ የእግዚአብሔርን ቤተ መቅደስና መሠዊያውን በውስጡም የሚሰግዱትን ለካ አለኝ ። |
| ፪ | ወዐጸደ ቤተ መቅደስ እንተ አፍአ ኅድጋ ወኢትለክዓ እስመ ተውህበት ለአሕዛብ ፤ ወይከይድዋ ለቅድስት ሀገር አርብዓ ወክልኤተ አውራኀ ። | ከመቅደሱም ውጭ ያለው ግቢ ለአሕዛብ ተሰጥቷልና ተወው አትለካውም ፤ እነርሱም ቅድስቲቱን ከተማ አርባ ሁለት ወር ይረግጡአታል ። |
| ፫ | ወእሁቦሙ ለክልኤቱ ስምዕየ ከመ ይትነበዩ ፲ወ፪ተ ምእተ ወ፷ተ መዋዕለ ልቡሳነ ሠቀ ። | ለሁለቱም ምስክሮቼ ማቅ ለብሰው ሺህ ከሁለት መቶ ስድሳ ቀን ትንቢት ሊናገሩ እሰጣቸዋለሁ ። |
| ፬ | እሉ እሙንቱ ክልኤቱ ዕፀወ ዘይት ወክልኤቱ መኃትው እለ ይቀውሙ ቅድመ እግዚአ ኵሉ ምድር ። | እነዚህ በምድር ጌታ ፊት የሚቆሙት ሁለቱ የወይራ ዛፎችና ሁለቱ መቅረዞች ናቸው ። |
| ፭ | ወእመ ቦ ዘይፈቅድ ይጕድዮሙ ይወፅእ እሳት እምአፉሆሙ ወይውዒ ፀሮሙ ፤ ወእመሂ ቦ ዘፈቀደ ይጕድዮሙ ከማሁ ይደልዎ ይሙት ። | ማንም ሊጐዳቸው ቢወድድ እሳት ከአፋቸው ይወጣል ጠላቶቻቸውንም ይበላል ፤ ማንም ሊጐዳቸው ቢወድድ እንዲሁ ሊገደል ይገባዋል ። |
| ፮ | ወእሉ ቦሙ ሥልጣን ከመ ይዕፅዉ ሰማየ ከመ ኢይዝንም ዝናም በመዋዕለ ተነብዮቶሙ ፤ ወቦሙ ሥልጣን ዲበ ማያት ከመ ይሚጥዎ ደመ ወከመ ይቅሥፍዋ ለምድር በኵሉ መቅሠፍት በዘፈቀዱ ። | እነዚህ ትንቢት በሚናገሩበት ወራት ዝናም እንዳይዘንብ ሰማይን ሊዘጉ ሥልጣን አላቸው ፤ ውኃዎችንም ወደ ደም ሊለውጡ በሚሹበትም ጊዜ ሁሉ ምድርን በመቅሠፍት ሁሉ ሊመቱ ሥልጣን አላቸው ። |
| ፯ | ወሶበ ፈጸሙ ስምዖሙ አርዌ ዘይወፅእ እምቀላይ ይትቃተሎሙ ወይመውኦሙ ወይቀትሎሙ ። | ምስክራቸውንም ከፈጸሙ በኋላ ከጥልቁ የሚወጣው አውሬ ይዋጋቸዋል ድልም ይነሣቸዋል ይገድላቸውማል ። |
| ፰ | ወይደቅዩ በድንሆሙ ውስተ አደባባያ ለዐባይ ሀገር እንተ ትሰመይ በመንፈስ ሰዶም ወግብጽ ኀበ ተሰቅለ እግዚእነሂ ። | በድናቸውም በመንፈሳዊ ትርጓሜ ሰዶምና ግብጽ በተባለች ጌታቸው ደግሞ በተሰቀለባት በታላቂቱ ከተማ አደባባይ ይወድቃል ። |
| ፱ | ወይሬእዩ እምነ ሕዝብ ወነገድ ወቋንቋ ወአሕዛብ በድንሆሙ ሠለስተ መዋዕለ ወመንፈቀ ፤ ወኢየኀድግዎሙ ይቅብርዎሙ ውስተ መቃብር ። | ከሕዝብና ከነገድ ከቋንቋም ከአሕዛብም የሆኑ ሰዎች ሦስት ቀን ተኵል በድናቸውን ያያሉ ፤ በድናቸውንም በመቃብር እንዲቀመጥ አይፈቅዱም ። |
| ፲ | ወይትፌሥሑ እለ የኀድሩ ውስተ ምድር ላዕሌሆሙ ወይትሐሠዩ ወይፌንዉ አምኃ በበይናቲሆሙ ፤ እስመ እሉ ክልኤቱ ነቢያት አሣቀይዎሙ ለእለ የኀድሩ ውስተ ምድር ። | እነዚህ ሁለት ነቢያት በምድር የሚኖሩትን ስላሠቃዩ ፤ በምድር የሚኖሩት በእነርሱ ላይ ደስ ይላቸዋል ፤ ሐሴትም ያደርጋሉ ፤ እርስ በርሳቸውም ስጦታ ይሰጣጣሉ ። |
| ፲፩ | ወእምድኅረ ሠለስቱ መዋዕል ወመንፈቁ ቦአ መንፈሰ ሕይወት እምነ እግዚአብሔር ላዕሌሆሙ ወቆሙ በእገሪሆሙ ፤ ወወድቀ ፍርሃት ዐቢይ ላዕለ እለ ርእይዎሙ ። | ከሦስቱ ቀናትና ከእኵሉ በኋላም ከእግዚአብሔር የወጣ የሕይወት መንፈስ ገባባቸው በእግሮቻቸውም ቆሙ ፤ ላዩአቸውም ታላቅ ፍርሃት ወደቀባቸው ። |
| ፲፪ | ወሰማዕኩ ቃለ ዐቢየ እምሰማይ ዘይብሎሙ ዕርጉ ዝየ ፤ ወዐርጉ ውስተ ሰማይ በደመና ወርእይዎሙ ፀሮሙ ። | በሰማይም ፤ ወደዚህ ውጡ የሚላቸውን ታላቅ ድምፅ ሰሙ ፤ በደመናም ወደ ሰማይ ወጡ ጠላቶቻቸውም አዩአቸው ። |
| ፲፫ | ወበይእቲ ሰዓት ኮነ ደልቀታ ዐቢይ ወወድቀ ዐሥራይታ እዲሃ ለሀገር ፤ ወሞቱ በውእቱ ደልቀታ ሰብዐቱ አዕላፈ ሰብእ ፤ ወእለ ተረፉ ፈርሁ ወሰብሕዎ ለአምላከ ሰማይ ። | በዚያችም ሰዓት ታላቅ የምድር መናወጥ ሆነ ፤ የከተማይቱም ዐሥረኛው እጅ ወደቀ ፤ በመናወጡም ሰባት ሺህ ሰዎች ተገደሉ ፤ የቀሩትም ፈሩ ፤ ለሰማዩም አምላክ ክብር ሰጡ ። |
| ፲፬ | ኀለፈ ካልእ ወይ ፤ ወናሁ ሣልስ ወይ ይመጽእ ፍጡነ ። | ሁለተኛው ወዮ አልፏል ፤ እነሆ ሦስተኛው ወዮ ፈጥኖ ይመጣል ። |
| ፲፭ | ወነፍሐ ሳብዕ መልአክ በቀርኑ ወኮነ ቃላት ዐበይት ውስተ ሰማይ ዘይብሉ ፤ ኮነት መንግሥተ ዓለም ለእግዚአብሔርነ ወለመሲሑ ወይነግሥ ለዓለመ ዓለም ። | ሰባተኛው መልአክ ነፋ ፤ በሰማይም ፤ የዓለም መንግሥት ለጌታችንና ለእርሱ ክርስቶስ ሆነች ፤ እርሱም ከዘለዓለም እስከ ዘለዓለም ድረስ ይነግሣል የሚሉ ታላላቅ ድምፆች ሆኑ ። |
| ፲፮ | ወእልክቱ ዕሥራ ወአርባዕቱ ሊቃናት እለ ይነብሩ ቅድመ እግዚአብሔር ዲበ መንበራቲሆሙ ወድቁ በገጾሙ ወሰገዱ ለእግዚአብሔር ፤ | በእግዚአብሔርም ፊት በዙፋኖቻቸው የተቀመጡት ሃያ አራቱ ሽማግሌዎች በግምባራቸው ተደፍተው ለእግዚአብሔር ሰገዱ ፤ |
| ፲፯ | ወይቤሉ ነአኵተከ እግዚኦ አምላክ አኃዜ ኵሉ ዘሀሎ ወዘሀለወ ፤ እስመ ነሣእከ ኃይለከ ዐቢየ ወነገሥከ ። | እንዲህም አሉ ፤ ያለህና የነበርህ ሁሉን የምትገዛ ጌታ አምላክ ሆይ ፤ ታላቁን ኃይልህን ስለ ያዝህ ስለ ነገሥህም እናመሰግንሃለን ፤ |
| ፲፰ | ወተምዕዑ አሕዛብ ወመጽአ መዐትከ ወበጽሐ ዘመኖሙ ለምውታን ከመ ይትኴነኑ ፤ ወከመ ትፈድዮሙ ዕሴቶሙ ለአግብርቲከ ነቢያት ወለቅዱሳን ወለእለ ይፈርሁ ስመከ ለንዑሳን ወለዐበይት ፤ ወከመ ታጥፍኦሙ ለእለ ያማስንዋ ለምድር ። | አሕዛብም ተቈጡ ፤ ቍጣህም መጣ ፤ በሙታንም ትፈርድ ዘንድ ፤ ለባሪያዎችህም ለነቢያትና ለቅዱሳን ስምህንም ለሚፈሩት ለታናናሾችና ለታላላቆችም ዋጋቸውን ትሰጥ ዘንድ ፤ ምድርንም የሚያጠፉትን ታጠፋ ዘንድ ዘመኑ ደረሰ ። |
