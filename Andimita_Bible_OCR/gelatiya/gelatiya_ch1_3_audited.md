| ቍጥር | ግዕዝ (ንባብ) | አማርኛ (አንድምታ ትርጓሜ) |
| :--- | :--- | :--- |
| **ክፍል** | **ክፍል ፩ ፡ በእንተ ዘከመ ተሠይመ ጳውሎስ በፈቃደ እግዚአብሔር ።** | **ክፍል ፩ ፡ ጳውሎስ በእግዚአብሔር ፈቃድ እንደተሾመ ።** |
| ፩ | እምጳውሎስ ሐዋርያ ዘኢኮነ በእንተ ሰብእ ወኢኮነ እምኀበ ሰብእ ፤ ዘእንበለ በእግዚእነ ኢየሱስ ክርስቶስ ወእግዚአብሔር አብ ዘአንሥኦ እሙታን ። | በጌታችን በኢየሱስ ክርስቶስ ከሙታን ለይቶ ባስነሣው በእግዚአብሔር አብ እንጂ ከሰው ዘንድ ካልተሾመ ስለ ሰውም ካልተሾመ ከሐዋርያው ጳውሎስ ፤ |
| ፪ | ወእምኵሎሙ አኃዊነ እለ ምስሌየ ፤ ለቤተ ክርስቲያን ዘገላትያ ። | ከእኔ ጋር ካሉ ከወንድሞቻችንም ሁሉ የተላከ ፤ በገላትያ ላለችው ቤተ ክርስቲያን ትድረስ ። |
| ፫ | ሰላም ለክሙ ወጸጋ እግዚአብሔር አቡነ ወእግዚእነ ኢየሱስ ክርስቶስ ። | ሰላም ለእናንተ ይሁን ፤ የአባታችን የእግዚአብሔር የጌታችን የኢየሱስ ክርስቶስም ጸጋ ይሁንላችሁ ። |
| ፬ | ዘመጠወ ርእሶ በእንተ ኃጢአትነ ፤ ከመ ያድኅነነ እምዝንቱ ዓለም ዘይትቃወም በእኩይ በፈቃደ እግዚአብሔር አቡነ ። | በክፉ ግብር ከሚቃወም ከዚህ ዓለም በአባታችን በእግዚአብሔር ፈቃድ ያድነን ዘንድ ስለ ኃጢአታችን ራሱን አሳልፎ የሰጠን ፤ |
| ፭ | ዘሎቱ ስብሐት ወኃይል ለዓለመ ዓለም አሜን ። | ጌትነት ኃይል ለዘለዓለሙ ገንዘቡ የሚሆን አሜን ። |
| ፮ | አነክረክሙ እፎ ከመዝ ፍጡነ ያፈልሱክሙ ፤ እምሃይማኖተ ክርስቶስ ዘጸውዐክሙ በጸጋሁ ውስተ ካልእ ትምህርት ። | በቸርነቱ የጠራችሁ ክርስቶስን ከማመን አውጥተው ወደ ሌላ ትምህርት እንዲህ ፈጥነው ወሰዷችሁ ብዬ አደንቃችኋለሁ ። |
| ፯ | ዘኢኮነ ህልወ ዘእንበለ ዘየሀውኩክሙ ፤ ወይፈቅዱ ይዕልዉ ትምህርቶ ለክርስቶስ ። | ያውኳችኋል የክርስቶስንም ወንጌል ሊለውጡ ይወዳሉ እንጂ ቀዋሚ ወንጌል ኖሮ አይደለም ። |
| ፰ | ወባሕቱ አንትሙ አሠረ ዚአነ ትልዉ አንትሙሰ ፤ መልአክ እምሰማይ ለእመ መሀረክሙ ካልአ እምዘመሀርናክሙ ውጉዝ ለይኩን ። | እናንተ ግን የእኛን ፍለጋ ተከተሉ ፤ እናንተስ መልአክ ከሰማይ ወርዶ እኛ ካስተማርናችሁ ሌላ ቢያስተምራችሁ ውጉዝ ይሁን ። |
| ፱ | በከመ እቤ ቀዳሚ ወይእዜኒ ካዕበ እብል ፤ ለእመቦ ዘመሀረክሙ ካልአ እምዘመሀርናክሙ ውጉዝ ለይኩን ። | አስቀድሜ እንደ ተናገርኩ አሁንም ደግሞ ካስተማርናችሁ ትምህርት ሌላ ያስተማራችሁ ቢኖር ውጉዝ ይሁን ። |
| ፲ | ወይእዜሰ ለሰብእኑ ነአምን ወአኮ ለእግዚአብሔር ፤ ወእመሰኬ እፈቅድ ለሰብእ አድሉ ኢኮንኩኬ ገብሮ ለክርስቶስ ። | አሁንም ለእግዚአብሔር ያይደለ ለሰው ብለን እናምናለን ? ለሰው የማደላ ከሆንኩስ የክርስቶስ ተገዢ አይደለሁማ ! ። |
| ፲፩ | እነግረክሙ አኃዊነ ፤ እስመ ትምህርት ዘመሀርኩክሙ ኢኮነ በእንተ ሰብእ ። | ወንድሞቻችን ! ልንገራችሁ ያስተማርኳችሁ ትምህርት ስለ ሰው አይደለም ። |
| ፲፪ | ወአነሂ አኮ እምኀበ ሰብእ ዘነሣእክዎ ወኢሂ መሀሩኒ ፤ ዘእንበለ በዘከሠተ ሊተ እግዚእየ ኢየሱስ ክርስቶስ ። | እኔም ያገኘሁት ከሰው አይደለም ሰዎችም አላስተማሩኝም ፤ ጌታዬ ኢየሱስ ክርስቶስ በገለጠልኝ ነው እንጂ ። |
| ፲፫ | ወሰማዕክሙ ግዕዝየ ዘትካት ዘአመ ሀሎኩ ውስተ አይሁድ ፤ ከመ ፈድፋደ ሰደድኩ ቤተ ክርስቲያኑ ለእግዚአብሔር ወአመንዘዝክዎሙ ። | በአይሁድ መካከል በነበርኩ ጊዜ የእግዚአብሔርን ማኅበር እጅግ እንዳሳደድኩ መከራም እንዳጸናሁባቸው የቀድሞ ግብሬን ሰምታችኋል ። |
| ፲፬ | ወከበርኩ በውስተ አይሁድ ፈድፋደ እምኵሉ ቢጽየ በውስተ ሕዝብየ ፤ እስመ ፈድፋደ ኮንኩ ቀናኤ ለሕገ አበውየ ። | በአይሁድ ዘንድ ከጓደኞቼ ሁሉ ይልቅ እጅግ ከበርኩ ፤ በወገኖቼ ዘንድ ለአባቶቼ ሕግ እጅግ ቀናተኛ ነበርኩና ። |
| ፲፭ | ወአመ ሠምረ ወፈቀደ እግዚአብሔር ዘፈለጠኒ ፤ አውፅአኒ እምከርሠ እምየ ወጸውዐኒ በጸጋሁ ። | የመረጠኝ እግዚአብሔር በወደደ ጊዜ ከእናቴ ማኅፀን አውጥቶ በጸጋው ጠራኝ ፤ |
| ፲፮ | ወከሠተ ሊተ ወልዶ ከመ ይትዐወቅ ስብሐተ ወልዱ በእዴየ ከመ እስብክ ለአሕዛብ በስሙ ፤ ወኢተለውኩ ሶቤሃ ዘሥጋ ወደም ። | የልጁ ጌትነት በቃሌ ይገለጥ ዘንድ በስሙ ለአሕዛብ እንዳስተምር እግዚአብሔር ልጁን ገለጠልኝ ፤ ያን ጊዜ ሥጋዊ ደማዊ ሰውን አልተከተልኩም ። |
| ፲፯ | ወኢዐረግኩ ኢየሩሳሌም ኀበ ሐዋርያት ቀደምትየ ፤ ወሖርኩ ብሔረ ዐረብ ወካዕበ ተመየጥኩ ደማስቆ ። | ወደ ቀደሙኝ ወደ ሐዋርያትም ወደ ኢየሩሳሌም አልወጣሁም ፤ ወደ ዐረብ አገር ሄድኩ ፤ ዳግመኛም ወደ ደማስቆ ተመለስኩ ። |
| ፲፰ | ወእምድኅረ ሠለስቱ ዓመት ዐረግኩ ኢየሩሳሌም እርዓዮ ለኬፋ ፤ ወነበርኩ ኀቤሁ ዐሠርተ ወኀምስተ መዋዕለ ። | ከሦስት ዓመት በኋላ ጴጥሮስን ላየው ወደ ኢየሩሳሌም ወጣሁ ፤ ከእሱም ዘንድ ዐሥራ አምስት ቀን ተቀመጥኩ ። |
| ፲፱ | ወኢየአምር ባዕደ ሐዋርያተ ፤ ዘእንበለ ያዕቆብ እኅሁ ለእግዚእነ ። | ከጌታችን ወንድም ከያዕቆብ በቀር ከሐዋርያት ሌላ አላውቅም ። |
| ፳ | ወዘኒ ዘጸሐፍኩ ለክሙ ፤ ናሁ ቅድመ እግዚአብሔር ሀሎኩ ወኢይሔሱ ። | ይህን የጻፍኩላችሁ እነሆ በእግዚአብሔር ፊት ነኝ አልዋሽም ። |
| ፳፩ | ወእምድኅረዝ በጻሕኩ ደወለ ቂልቅያ ወሶርያ ። | ከዚህም በኋላ ወደ ቂልቅያና ወደ ሶርያ አውራጃ ደረስሁ ። |
| ፳፪ | ወኢያእመሩኒ አብያተ ክርስቲያናት ዘብሔረ ይሁዳ ፤ እለ በክርስቶስ በገጽየ ። | በክርስቶስ ያመኑ በይሁዳ አገር ያሉ ማኅበረ ክርስቲያን ፊቴን አይተው አላወቁኝም ። |
| ፳፫ | ወዳእሙ ሰምዑ ዜናየ ፤ ዝኩ ዘትካት ይሰድድ ይእዜ ይሰብክ ትምህርተ ሃይማኖት ። | ቀድሞ ምእመናንን ያሳድድ የነበረው ያ ዛሬ የሃይማኖትን ትምህርት ይሰብካል ሲባል ወሬዬን ሰሙ እንጂ ። |
| ፳፬ | ወይሴብሕዎ ለእግዚአብሔር በእንቲአየ ። | በእኔ ምክንያትም እግዚአብሔርን ያመሰግኑታል ። |
