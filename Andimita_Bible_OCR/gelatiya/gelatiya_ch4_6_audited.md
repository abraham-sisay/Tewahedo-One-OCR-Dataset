| ፪ | ወባሕቱ ላዕለ እምሔው ወላዕለ መገብት ይትዐቀብ ፤ እስከ ይበጽሕ ዕድሜሁ ዘአደሞ አቡሁ ። | አባቱ የወሰነው ዕድሜው እስኪደርስ ድረስም በሞግዚቶችና በመጋቢዎች እጅ ይጠበቃል እንጂ ። |

| ፬ | ወአመ በጽሐ ዕድሜሁ ፈነወ እግዚአብሔር ወልዶ ፤ ወተወልደ እምብእሲት ወገብረ በሕገ ኦሪት ። | የዘመኑ ፍጻሜ በደረሰ ጊዜ ግን እግዚአብሔር ከሴት የተወለደውን ከሕግም በታች የተወለደውን ልጁን ላከ ፤ |
| ፭ | ከመ ይሣየጦሙ ለእለ ውስተ ኦሪት ፤ ከመ ንርከብ ትርሲተ ውሉድ ። | በሕግ በታች ያሉትን ይዋጅ ዘንድ ፤ እኛም የልጅነትን ክብር እናገኝ ዘንድ ። |
| ፮ | ወእምከመሰ ውሉድ አንትሙ ናሁ ፈነወ እግዚአብሔር መንፈሰ ወልዱ ውስተ ልብክሙ ፤ ውእቱ ዘይጼውዑ ወትብሉ አባ ወአቡየ ። | ልጆች እንደ መሆናችሁ መጠን እግዚአብሔር አባ አባት ብሎ የሚጮኽ የልጁን መንፈስ በልባችሁ አሳደረ ። |
| ፯ | እንከሰኬ ውሉድ አንትሙ ወኢኮንክሙ አግብርተ ፤ ወእመሰኬ ውሉድ አንትሙ ወራስያኒሁኬ ለእግዚአብሔር አንትሙ በኢየሱስ ክርስቶስ ። | እንኪያስ እናንተ ልጆች ናችሁ እንጂ ከእንግዲህ ወዲህ ባሪያ አይደላችሁም ፤ ልጆችም ከሆናችሁ ደግሞ በእግዚአብሔር ፈቃድ የክርስቶስ ወራሾች ናችሁ ። |
| ፰ | ወባሕቱ ትካትሰ በኢያእምሮትክሙ ፤ ተቀነይክሙ ለእለ ኢኮኑ አማልክተ ። | ቀድሞማ እግዚአብሔርን ሳታውቁ አማልክት ላልሆኑት ተገዝታችሁ ነበር ። |
| ፱ | ወይእዜሰ አእመርክምዎ ለእግዚአብሔር ወፈድፋደ ውእቱ አእመረክሙ ፤ እፎ ካዕበ ኀበ ዝኩ ድኩም ወጽኑስ ጣዖተ ዝ ዓለም ትፈቅዱ ዳግመ ትትቀነዩ ሎሙ ። | ዛሬ ግን እግዚአብሔርን አውቃችኋል ፤ ይልቁንም በእግዚአብሔር ታውቃችኋል ፤ እንደ ገና ወደ ደካማ ወደማይረባም ወደ ዓለም ትምህርት ልትመለሱ እንደ ገናስ ባሪያዎች ልትሆኑ እንዴት ትወዳላችሁ ? |
| ፲ | ወትትዐቀቡ ዕለተ ወወርኀ ወጊዜ ወዓመታተ ። | ቀንንና ወርንም ጊዜንም ዓመታትንም በዓላትን ትጠብቃላችሁ ። |
| ፲፩ | እፈርሀክሙ እንዳዒ ለእመ ለከንቱ ፃመውኩ በእንቲአክሙ ፤ | ስለ እናንተ ምናልባት በከንቱ ደክሜ እንደ ሆነ ብዬ እፈራችኋለሁ ። |

| ፲፬ | ወእንዘሂ አሐምም ኢተቄጣዕክሙኒ ወኢመነንክሙኒ በሥጋየ ፤ ወተወከፍክሙኒሂ ከመ መልአከ እግዚአብሔር ወከመ ክርስቶስ ኢየሱስ ። | በሥጋዬም የነበረውን መከራዬን አልናቃችሁትም አልሰለቻችሁትም ፤ ነገር ግን እንደ እግዚአብሔር መልአክ እንደ ክርስቶስ ኢየሱስ ተቀበላችሁኝ ። |

| **ክፍል** | **ክፍል ፯ ፡ በእንተ ይስሐቅ ወይስማኤል ፤ ሣራ ወአጋር ።** | **ክፍል ፯ ፡ ስለ ይስሐቅና ይስማኤል ፤ ስለ ሣራና አጋር ።** |

| ፲፯ | እምይእዜሰ አልቦ ዘያነጥየኒ ፤ አንሰ ሕማሞ ለክርስቶስ አፀውር በሥጋየ ። | እኔ የኢየሱስን ማኅተም በሥጋዬ ተሸክሜአለሁና ፤ ከእንግዲህ ወዲህ ማንም አያድክመኝ (አያነጥበኝ) ። |
| ፲፰ | ጸጋሁ ለእግዚእነ ኢየሱስ ክርስቶስ ምስለ መንፈስክሙ አኃውየ አሜን ። | ወንድሞች ሆይ ! የጌታችን የኢየሱስ ክርስቶስ ጸጋ ከመንፈሳችሁ ጋር ይሁን ፤ አሜን ። |

## ተፈጸመ (Colophon)

**ግዕዝ** : ተፈጸመት መልእክት ኀበ ሰብአ ገላትያ ዘተጽሕፈት በሮሜ ወተፈነወት በእደ ቲቶ ፤ ወስብሐት ለእግዚአብሔር ለዓለመ ዓለም ። አሜን ።

**አማርኛ** : በሮም ተጽፋ በቲቶ እጅ ወደ ገላትያ ሰዎች የተላከች መልእክት ተፈጸመች ፤ ለእግዚአብሔር ምስጋና ይሁን ። አሜን ።
